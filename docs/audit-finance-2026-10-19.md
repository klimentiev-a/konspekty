Только анализ, код не менялся. Замеры: размеры файлов реальные; LCP/INP — оценка, на реальном телефоне не мерили; синхронизация между устройствами не проверялась.

## Резюме
1. finance.html = 3,4 МБ (gzip ≈ 1 МБ): тексты 50 глав, секторов и терминов (3 МБ) вшиты в страницу → вынести в отдельные JSON с ленивой подгрузкой.
2. Навигация нормальная; нет хлебных крошек и общего поиска по главам/терминам/новостям.
3. Таблицы 120–500 строк тяжёлые для телефона → виртуализация/пагинация.
4. SEO нет (meta description, OG, robots, sitemap, Schema.org) — важно только для превью ссылок, если сайт личный.
5. «Замок» на сайте клиентский → не защита; проверить права токена в sync.js.
6. a11y слабая: 11 role, 1 tabindex, графики недоступны с клавиатуры.
7. Контент сильный, вовлечения нет: избранное, связанные материалы, тесты после глав.
