# Курс английского A1 → B1 для Насти (48 уроков по ~60 минут)

Файл урока: `lessons/NN_<slug>.md`, где NN — двузначный номер. Заголовок `# Урок N. …`; поля level / unit / theme / minutes (60).

## Общие правила качества
- Объяснения на русском, примеры на английском с переводом. Британский вариант по умолчанию, но не перегружать различиями с американским.
- Уровень примеров: A1 — самые простые слова (до ~800 слов), A2 — до ~1500, B1 — до ~2500; не вводить редкую лексику.
- В каждом уроке часть упражнений (1–2 набора) повторяет прошлые уроки (спираль).
- Лексика в «Слова» — ровно по теме урока, без дублей слов из предыдущих уроков, если можно избежать.
- Ответы в `=>` должны перечислять ВСЕ допустимые варианты (полная и сокращённая форма, синонимы). Проверка в браузере нормализует регистр, пробелы, конечную точку/вопросительный знак и апострофы, но не синонимы.
- Нельзя выдумывать «факты о языке»: только то, в чём уверен. Если сомневаешься — выбери более безопасный пример.
