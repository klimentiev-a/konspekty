# Словообразование: суффиксы, приставки, сложные слова
short: суффиксы и приставки существительных, прилагательных, глаголов и наречий, пары -ed/-ing, 60 неисчисляемых существительных и сложные слова

## 1. Зачем знать словообразование

Зная один корень и несколько суффиксов, можно понять десять слов: *teach → teacher → teaching*, *help → helpful → helpless → helpfully*. Это самый быстрый способ расширить словарь.

| Часть слова | Что делает | Пример |
|---|---|---|
| **Корень** | Основное значение | **happy** (счастливый) |
| **Приставка** (prefix) | Меняет значение, часть речи обычно та же | **un**happy (несчастный) |
| **Суффикс** (suffix) | Часто меняет часть речи | happi**ness** (счастье), happi**ly** (счастливо) |

> **Запомни.** Приставки обычно **не** меняют часть речи (happy → unhappy, оба прилагательные). Суффиксы **чаще** меняют часть речи (happy → happiness, существительное).

### Орфографические изменения при добавлении суффикса

| Правило | Пример | Результат |
|---|---|---|
| Беззвучная **-e** отпадает перед гласной | create + ive | creative |
| **-e** остаётся перед согласной | care + ful | careful |
| **-y** после согласной меняется на **-i** | happy + ness | happiness |
| Удвоение конечной согласной (краткая гласная, ударение на последнем слоге) | run + er, big + er | runner, bigger |
| **-le** → **-ly** | simple + ly | simply |
| **-ic** → **-ically** | basic + ly | basically |
| **-ful** → **-fully** | careful + ly | carefully |
| Конечная **l** сохраняется | real + ly | really |

## 3. Суффиксы прилагательных

| Суффикс | Значение | Примеры (перевод) |
|---|---|---|
| **-ful** | полный чего-то | beautiful (красивый), helpful (полезный), careful (осторожный), colourful (красочный), wonderful (замечательный), useful (полезный) |
| **-less** | без чего-то | careless (небрежный), homeless (бездомный), hopeless (безнадёжный), useless (бесполезный), endless (бесконечный), harmless (безвредный) |
| **-able / -ible** | можно | comfortable (удобный), enjoyable (приятный), possible (возможный), flexible (гибкий), terrible (ужасный), available (доступный) |
| **-ous** | обладающий качеством | famous (известный), dangerous (опасный), nervous (нервный), delicious (вкусный), generous (щедрый), serious (серьёзный) |
| **-y** | имеющий качество | sunny (солнечный), rainy (дождливый), windy (ветреный), healthy (здоровый), lucky (удачливый), noisy (шумный) |
| **-al** | относящийся к | national (национальный), musical (музыкальный), traditional (традиционный), personal (личный), medical (медицинский) |
| **-ic** | относящийся к | artistic (артистичный), economic (экономический), historic (исторический), romantic (романтичный), fantastic (фантастический) |
| **-ive** | склонный к | active (активный), creative (творческий), attractive (привлекательный), expensive (дорогой), impressive (впечатляющий) |
| **-ish** | вроде, слегка; характер | childish (детский), foolish (глупый), reddish (красноватый), selfish (эгоистичный), British (британский) |
| **-ly** | как (у людей и времени) | friendly (дружелюбный), lovely (прелестный), lonely (одинокий), daily (ежедневный), weekly (еженедельный) |
| **-ern / -ward** | направление | northern (северный), eastern (восточный), backward (отсталый) |
| **-ant / -ent** | качество | important (важный), pleasant (приятный), different (разный), intelligent (умный), confident (уверенный) |
| **-ed / -ing** | чувство или причина | см. раздел 7 |

> **Запомни.** **-ful** и **-less** образуют пары-антонимы: careful / careless, helpful / helpless, hopeful / hopeless, useful / useless, painful / painless, colourful / colourless. Но не у всех слов есть обе формы: beautiful есть, а *beautyless* не бывает.

## 4. Суффиксы глаголов

| Суффикс | Значение | Примеры (перевод) |
|---|---|---|
| **-ise / -ize** | делать | organise (организовать), realise (осознать), modernise (модернизировать), apologise (извиниться), recognise (узнать), criticise (критиковать) |
| **-ify** | делать | simplify (упростить), clarify (прояснить), identify (опознать), purify (очистить) |
| **-en** | делать каким-то | widen (расширить), shorten (сократить), strengthen (усилить), lengthen (удлинить), brighten (осветлить), weaken (ослабить), soften (смягчить) |
| **-ate** | делать | activate (активировать), celebrate (праздновать), educate (обучать), create (создавать), decorate (украшать), communicate (общаться) |

Британский вариант: **-ise**, американский: **-ize**. Оба варианта правильные, главное быть последовательной в тексте: *organise* и *recognise* (британский), *organize* и *recognize* (американский).

### Приставки, образующие глаголы

| Приставка | Значение | Примеры |
|---|---|---|
| **en-** | сделать, ввести в | enjoy (наслаждаться), enable (позволять), enlarge (увеличить), encourage (поощрять) |
| **be-** | сделать, обеспечить | befriend (подружиться), belittle (принижать) |
| **dis-** | отменить | disagree (не соглашаться), disappear (исчезнуть), dislike (не любить) |
| **un-** | отменить действие | undo (отменить), unlock (отпереть), unpack (распаковать), untie (развязать) |
| **mis-** | неправильно | misunderstand (неправильно понять), misspell (неправильно написать), mislead (ввести в заблуждение) |
| **re-** | снова | rewrite (переписать), rebuild (перестроить), redo (переделать), replay (переиграть) |

## 5. Суффиксы наречий

| Способ | Примеры (перевод) | Правило |
|---|---|---|
| прилагательное + **-ly** | slowly (медленно), quickly (быстро), carefully (осторожно), loudly (громко), quietly (тихо) | добавляем -ly |
| согласная **y** → **ily** | happily (счастливо), easily (легко), angrily (сердито), heavily (тяжело) | y меняется на i |
| **-le** → **-ly** | simply (просто), gently (нежно), possibly (возможно) | убираем e |
| **-ic** → **-ically** | basically (в основном), automatically (автоматически), tragically (трагически) | |
| **-ful** → **-fully** | carefully (осторожно), beautifully (красиво), gratefully (с благодарностью) | двойная l |
| **-ward(s)** | forward (вперёд), backward (назад), upward (вверх), homeward (домой) | направление |
| **-wise** | clockwise (по часовой стрелке), otherwise (иначе), likewise (подобным образом) | |
| Неправильное | good → **well** (хорошо) | исключение |

### Наречие совпадает с прилагательным

| Слово | Прилагательное | Наречие (то же) | Наречие с -ly (другой смысл) |
|---|---|---|---|
| fast | a fast car | He drives fast. | нет |
| hard | a hard exam | She works hard. | hardly = едва ли |
| late | a late train | We arrived late. | lately = в последнее время |
| early | an early start | I get up early. | нет |
| high | a high mountain | The bird flew high. | highly = очень (highly recommended) |
| near | a near station | Don't come near. | nearly = почти |
| daily | daily news | It happens daily. | нет |
| straight | a straight road | Go straight on. | нет |

> **Запомни.** *Hard* и *hardly* значат разное: *He works hard* (он усердно работает), *He hardly works* (он почти не работает). То же с *late / lately* и *near / nearly*.

## 7. Пары -ed / -ing

Это прилагательные, образованные от глаголов чувств. Правило простое:

| Окончание | Значение | Вопрос | Пример |
|---|---|---|---|
| **-ed** | человек **чувствует** | Что я чувствую? | I'm bored. (Мне скучно.) |
| **-ing** | предмет или человек **вызывает** чувство | Какой он? | The film is boring. (Фильм скучный.) |

| -ed (чувствую) | -ing (вызывает) | Перевод | Пример |
|---|---|---|---|
| bored | boring | скучающий / скучный | The lesson was boring, so I was bored. |
| interested | interesting | заинтересованный / интересный | I'm interested in history. It's interesting. |
| excited | exciting | взволнованный / захватывающий | We're excited about the exciting trip. |
| tired | tiring | уставший / утомительный | I'm tired after a tiring day. |
| surprised | surprising | удивлённый / удивительный | I was surprised by the surprising news. |
| confused | confusing | растерянный / запутанный | The map is confusing, so I'm confused. |
| annoyed | annoying | раздражённый / раздражающий | He's annoying, and I'm annoyed. |
| frightened | frightening | испуганный / пугающий | The dog is frightening. I'm frightened. |
| shocked | shocking | шокированный / шокирующий | The shocking news left us shocked. |
| relaxed | relaxing | расслабленный / расслабляющий | I feel relaxed after a relaxing bath. |
| disappointed | disappointing | разочарованный / разочаровывающий | The result was disappointing. We were disappointed. |
| embarrassed | embarrassing | смущённый / неловкий | It was an embarrassing question. I was embarrassed. |
| amazed | amazing | поражённый / потрясающий | I'm amazed by this amazing view. |
| worried | worrying | обеспокоенный / тревожный | She's worried about the worrying news. |
| exhausted | exhausting | измотанный / изматывающий | A long flight is exhausting. I'm exhausted. |
| depressed | depressing | подавленный / угнетающий | The weather is depressing. It makes me depressed. |
| fascinated | fascinating | очарованный / увлекательный | I'm fascinated by this fascinating story. |
| satisfied | satisfying | довольный / удовлетворяющий | A satisfying meal left us satisfied. |
| terrified | terrifying | в ужасе / ужасающий | A terrifying film left her terrified. |

> **Запомни.** Ошибка *I'm boring* значит «я скучный человек». Хотите сказать «мне скучно», говорите *I'm bored*.

Другие причастия в роли прилагательных: *broken window* (разбитое окно), *closed door* (закрытая дверь), *boiling water* (кипящая вода), *boiled egg* (варёное яйцо), *sleeping baby* (спящий ребёнок), *used car* (подержанная машина).

## 8. Исчисляемые и неисчисляемые существительные

**Исчисляемые** можно посчитать (*one apple, two apples*), у них есть множественное число. **Неисчисляемые** нельзя посчитать напрямую (*water, money*); у них нет множественного числа и нет a / an.

| | Исчисляемые | Неисчисляемые |
|---|---|---|
| Артикль a/an | a book | ❌ a water |
| Множественное число | books | ❌ waters (в обычной речи) |
| Количество | many, few, a few | much, little, a little |
| Вопрос о количестве | How many books? | How much water? |
| Глагол | These books are new. | This water is cold. |
| Общее: some / any | some books | some water |
| Универсальное | a lot of / lots of | a lot of / lots of |

### Как посчитать неисчисляемое

| Конструкция | Примеры |
|---|---|
| a glass / cup / bottle of | a glass of water, a cup of tea, a bottle of milk |
| a piece / slice of | a piece of advice, a slice of bread, a piece of news |
| a bar / bag / packet of | a bar of chocolate, a bag of rice, a packet of sugar |
| a bowl / plate of | a bowl of soup, a plate of pasta |
| a pinch / spoonful of | a pinch of salt, a spoonful of sugar |

## 9. Сложные слова

Сложное слово состоит из двух (или более) слов, вместе образующих новое значение.

### Три способа написания

| Написание | Примеры |
|---|---|
| Слитно | toothbrush (зубная щётка), bedroom (спальня), football (футбол), notebook (тетрадь), sunflower (подсолнух), classroom (класс) |
| Через дефис | mother-in-law (свекровь, тёща), check-in (регистрация), part-time (на неполный день), well-known (известный) |
| Раздельно | ice cream (мороженое), post office (почта), bus stop (остановка), credit card (кредитная карта), washing machine (стиральная машина) |

Если не уверены, как писать, проверьте в словаре. Правила для всех слов нет.

### Типы сложных существительных

| Модель | Примеры (перевод) |
|---|---|
| существительное + существительное | toothpaste (зубная паста), bus stop, airport (аэропорт), bookshop (книжный магазин) |
| прилагательное + существительное | blackboard (доска), greenhouse (теплица), hot dog (хот-дог), fast food (фастфуд) |
| глагол + существительное | pickpocket (карманный вор), playground (игровая площадка) |
| -ing + существительное | swimming pool (бассейн), washing machine, driving licence (водительские права), living room (гостиная) |
| существительное + глагол | haircut (стрижка), sunrise (восход), rainfall (осадки) |
| глагол + предлог | takeaway (еда на вынос), checkout (касса), breakdown (поломка), grown-up (взрослый) |
| предлог + глагол | income (доход), outcome (результат), upset (расстройство) |

### Сложные прилагательные

| Модель | Примеры (перевод) |
|---|---|
| наречие + причастие | well-known (известный), badly-paid (плохо оплачиваемый) |
| существительное + причастие | man-made (искусственный), home-made (домашний) |
| прилагательное + существительное + -ed | kind-hearted (добросердечный), blue-eyed (голубоглазый) |
| прилагательное + причастие | old-fashioned (старомодный), good-looking (красивый), hard-working (трудолюбивый) |
| число + существительное | a ten-minute walk (десятиминутная прогулка), a five-year-old girl (пятилетняя девочка) |

> **Запомни.** В сложных прилагательных с числом существительное стоит в **единственном числе**: ✅ *a ten-minute walk*, ❌ *a ten-minutes walk*. Но: *The walk takes ten minutes. She is five years old.*

### Множественное число сложных слов

| Слово | Множественное число | Правило |
|---|---|---|
| toothbrush | toothbrushes | -s к последнему слову |
| bus stop | bus stops | -s к последнему слову |
| mother-in-law | mothers-in-law | -s к главному слову |
| passer-by | passers-by | -s к главному слову |
| runner-up | runners-up | -s к главному слову |
| policeman | policemen | меняется man → men |

### Сложные наречия и местоимения

| Группа | Слова |
|---|---|
| Наречия места | somewhere, anywhere, nowhere, everywhere |
| Местоимения | something, anything, nothing, everything, someone, anyone, no one, everyone, somebody, nobody |
| Союзные наречия | meanwhile (тем временем), however (однако), nevertheless (тем не менее), therefore (поэтому) |
| Прочее | maybe, always, sometimes, anyway, indeed |

### Ударение

| Тип | Ударение | Пример |
|---|---|---|
| Сложное слово | на первом слове | a ˈgreenhouse (теплица), a ˈblackboard (доска) |
| Словосочетание | на втором слове | a green ˈhouse (зелёный дом), a black ˈboard (чёрная доска) |

### Смешанные слова и сокращения

| Тип | Примеры |
|---|---|
| Слияние двух слов | brunch (breakfast + lunch), motel (motor + hotel), smog (smoke + fog), podcast (iPod + broadcast) |
| Сокращения | phone (telephone), bus (omnibus), flu (influenza), fridge (refrigerator), ad (advertisement) |

## 11. Типичные ошибки

| Ошибка | Правильно | Пояснение |
|---|---|---|
| ❌ I'm very boring. | ✅ I'm very bored. | -ed о чувстве |
| ❌ an advice | ✅ a piece of advice / some advice | advice неисчисляемое |
| ❌ informations | ✅ information | нет множественного числа |
| ❌ The news are bad. | ✅ The news is bad. | единственное число |
| ❌ a ten-years boy | ✅ a ten-year-old boy | число + существительное в единственном числе |
| ❌ unpossible | ✅ impossible | по правилу im- перед p |
| ❌ happyness | ✅ happiness | y → i |
| ❌ She works hardly. | ✅ She works hard. | hardly значит «едва» |
| ❌ carefuly | ✅ carefully | -ful + -ly = -fully |
| ❌ beautifuly | ✅ beautifully | то же |
| ❌ I have many money. | ✅ I have a lot of money. / much money | money неисчисляемое |
| ❌ furnitures | ✅ furniture / pieces of furniture | нет множественного числа |
| ❌ a hairs | ✅ hair / a hair | hair неисчисляемое |

> **Запомни.** Четыре самых частых источника ошибок: (1) -ed и -ing (**bored / boring**); (2) неисчисляемые (**news, advice, information, money**); (3) приставка отрицания (**im-possible, ir-regular, il-legal**); (4) наречия на -ly (**carefully, happily, hardly ≠ hard**).
