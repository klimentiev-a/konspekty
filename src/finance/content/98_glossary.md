# Глоссарий
short: Термины и сокращения от A до Я. В алфавитном порядке: сначала латиница, потом кириллица. У терминов с расчётом есть формула и расшифровка обозначений

| Термин | Расшифровка | Значение | Формула и расшифровка |
|---|---|---|---|
| **2P reserves** | Запасы 2P | Доказанные и вероятные запасы: те, что можно извлечь с вероятностью не ниже 50%. |  |
| **ABB** | Accelerated Bookbuilding | Быстрая (за 1–2 дня) продажа крупного пакета акций крупным инвесторам, например фондам и банкам. Банк быстро собирает заявки и продаёт всё оптом, как распродажа партии товара одному-двум крупным покупателям |  |
| **ABS** | Asset-Backed Security | Бумага, обеспеченная пулом других кредитов или платежей (автокредиты, потребкредиты, лизинг). |  |
| **Accretion / Dilution** |  | Насколько вырастет или упадёт прибыль на акцию (EPS) у покупателя после сделки. «Accretion» — прибавка, «dilution» — разбавление. Если прибыль на акцию выросла, сделка выгодна акционерам покупателя | <code>EPS<sub>после</sub> − EPS<sub>до</sub></code><br><span class="fx">где: EPS — прибыль на акцию. Если после сделки EPS выше, это accretion (прирост), если ниже, dilution (размытие)</span> |
| **Accrual accounting** | Метод начисления | Доходы и расходы записывают, когда они случились, а не когда пришли или ушли деньги. Продал товар в долг — выручка есть сразу, хотя денег ещё нет. |  |
| **Accrued interest** |  | См. НКД | <code>Accrued = Купон × Дней с выплаты / Дней в периоде</code><br><span class="fx">где: То же, что НКД</span> |
| **Add-backs** | Корректировки EBITDA | Статьи, которые добавляют к EBITDA, чтобы получить Adjusted EBITDA. Часть нормальна (разовые расходы), часть завышает базу. | Проверяйте детализацию и лимиты в договоре |
| **Add-on** | Добавочная покупка | Покупка небольшой компании, чтобы присоединить её к уже купленной платформе. |  |
| **Adjusted EBITDA** | Скорректированная EBITDA | EBITDA без разовых и нетипичных статей (реструктуризация, судебные издержки). Компании любят «приукрасить», поэтому корректировки надо проверять. |  |
| **ADR / GDR** | Депозитарные расписки | Бумаги, которые торгуются на иностранной бирже и представляют акции российской или другой компании. ADR — на американской, GDR — на других. |  |
| **AFFO** | Adjusted FFO | FFO за вычетом обязательных вложений в содержание объектов. Лучше показывает, сколько REIT может раздать. |  |
| **Alpha** | Альфа | Доходность управляющего сверх той, которую можно было ожидать при его уровне риска. Показывает мастерство. | <code>α = Доходность портфеля − (Rf + β × (Rm − Rf))</code> |
| **Amortization** | Амортизация (нематериальных активов) | То же списание, но для нематериальных вещей: программ, лицензий, патентов. |  |
| **Anti-dilution** | Защита от размытия | Если следующий раунд проходит дешевле предыдущего, инвестор получает дополнительные акции, чтобы сохранить свою долю. |  |
| **APT** | Arbitrage Pricing Theory | Теория арбитражного ценообразования: доходность определяется несколькими факторами (инфляция, ВВП и т. п.), а не одной бетой. |  |
| **APV** | Adjusted Present Value | Сначала считают стоимость компании так, будто долга нет, потом прибавляют сегодняшнюю стоимость (PV) налоговой экономии от процентов по долгу (налогового щита). Проценты по кредиту уменьшают налог, и эту выгоду учитывают отдельной строкой | <code>APV = NPV<sub>без долга</sub> + PV(налоговый щит)</code><br><span class="fx">где: NPV без долга — стоимость бизнеса, будто долгов нет. PV налогового щита — приведённая выгода от вычета процентов из налога</span> |
| **Arbitrage** | Арбитраж | Покупка и продажа одного и того же актива на разных рынках, чтобы без риска забрать разницу цен. Такие возможности быстро исчезают. |  |
| **ARPU** | Average Revenue Per User | Сколько выручки в среднем приносит один пользователь (телеком, интернет). Если оператор за месяц получил 1000 рублей от 10 абонентов, ARPU равен 100 рублей | <code>ARPU = Выручка / Число пользователей</code><br><span class="fx">где: Выручка за период, делённая на среднее число пользователей за тот же период</span> |
| **ARR** | Annual Recurring Revenue | Выручка за год, которая повторяется из года в год, например по подписке (SaaS — программы по подписке). Похоже на абонемент в спортзал: деньги приходят регулярно, а не разово | <code>ARR = MRR × 12</code><br><span class="fx">где: MRR — ежемесячная повторяющаяся выручка по подпискам. Умножаем на 12 месяцев</span> |
| **Asset turnover** | Оборачиваемость активов | Сколько рублей выручки приносит каждый рубль активов. | <code>Asset turnover = Выручка / Средние активы</code> |
| **Backwardation** | Бэквордация | Фьючерсы на более поздний срок дешевле ближайших. Означает дефицит товара сейчас. |  |
| **Balance sheet** | Баланс | Снимок компании на одну дату: что у неё есть (активы) и откуда это взялось (долг и капитал). | <code>Активы = Обязательства + Капитал</code><br><span class="fx">где: Активы — всё, чем владеет компания. Обязательства — всё, что она должна. Капитал — доля владельцев.</span> |
| **Balloon payment** | Баллонный платёж | Последний платёж по кредиту намного больше предыдущих. До него платят мало. |  |
| **Bankruptcy** | Банкротство | Состояние, когда должник не может платить по долгам. Имущество продают, деньги делят по очереди. |  |
| **Basel III** | Базель III | Международные правила для банков: сколько капитала и ликвидности держать, чтобы пережить кризис. |  |
| **Basis point (б.п.)** |  | Базисный пункт = 0,01%. 50 б.п. = 0,5 п.п. (п.п. — процентный пункт). Это очень мелкая единица, чтобы точно говорить о небольших изменениях ставок | <code>1 б.п. = 0,01% = 0,0001</code><br><span class="fx">где: Сотая доля процента. Рост ставки с 10% до 10,5% — это +50 б.п.</span> |
| **Benchmark** | Бенчмарк | Индекс, с которым сравнивают результат управляющего. Обыграл индекс — молодец. |  |
| **Beta (β)** |  | Показывает, насколько сильно акция реагирует на движения рынка. Бета 1 значит «двигается как рынок», больше 1 — «качается сильнее», меньше 1 — «спокойнее» | <code>β = Cov(R<sub>акции</sub>, R<sub>рынка</sub>) / Var(R<sub>рынка</sub>)</code><br><span class="fx">где: Cov — ковариация доходностей акции и рынка (двигаются вместе или нет). Var — дисперсия доходности рынка. β>1 значит акция колеблется сильнее рынка</span> |
| **Bitcoin** | Биткоин | Первая и крупнейшая криптовалюта. Ограниченное предложение: 21 млн монет. |  |
| **Black-Scholes** | Модель Блэка — Шоулза | Формула справедливой цены европейского опциона. Использует цену актива, страйк, срок, ставку и волатильность. |  |
| **Blue chip** | «Голубые фишки» | Акции крупнейших стабильных компаний с долгой историей. В России: Сбербанк, Газпром, Лукойл. |  |
| **Bond** | Облигация | Долговая бумага: ты одалживаешь деньги эмитенту, он платит проценты (купоны) и в конце возвращает номинал. |  |
| **Book building** | Сбор заявок | Сбор заявок инвесторов по цене и количеству, по которому определяют цену и распределение акций при размещении. | |
| **Book value** | Балансовая стоимость | Сколько стоит актив или вся компания по записям в балансе. | <code>Book value of equity = Активы − Обязательства</code> |
| **Bookrunner** |  | Банк, который собирает заявки инвесторов при размещении акций или облигаций. Он ведёт «книгу заявок»: список, кто сколько готов купить и по какой цене |  |
| **Break fee** | Termination fee | Неустойка, которую платит цель, если выходит из сделки ради другого предложения. Неустойка — это штраф за срыв договорённости. Цель — компания, которую покупают |  |
| **Break-even** | Точка безубыточности | Объём продаж, при котором прибыль равна нулю: маржинальный доход как раз покрыл постоянные расходы. | <code>Break-even (штук) = Постоянные расходы / (Цена − Переменные расходы на штуку)</code> |
| **Brent** | Brent | Эталонный сорт нефти для мировых цен. Его цену берут за основу при оценке других сортов. |  |
| **Broker** | Брокер | Посредник, через которого частный инвестор торгует на бирже. Берёт комиссию. |  |
| **Budget deficit** | Дефицит бюджета | Расходы государства больше доходов. Покрывается займами или резервами. |  |
| **Bull / Bear market** | Рынок быков / медведей | Бычий рынок — растущий, медвежий — падающий (обычно от пика минус 20% и больше). |  |
| **Bullet repayment** | Погашение разом | Весь основной долг возвращают одним платежом в конце срока, до этого платят только проценты. |  |
| **Burn rate** | Скорость сжигания денег | Сколько денег в месяц компания тратит сверх того, что зарабатывает. Характерно для стартапов. | <code>Burn = Расходы − Выручка (в месяц)</code> |
| **CAC** | Customer Acquisition Cost | Сколько стоит привлечь одного клиента: вся реклама и продажи, делённые на новых клиентов. | <code>CAC = Расходы на маркетинг и продажи / Число новых клиентов</code> |
| **CAGR** | Compound Annual Growth Rate | Средний рост за год с учётом «процента на процент»: (Конец/Начало)^(1/n) − 1. Здесь n — число лет. Это та единая годовая скорость роста, которая из начальной суммы даёт конечную | <code>CAGR = (V<sub>кон</sub> / V<sub>нач</sub>)<sup>1/n</sup> − 1</code><br><span class="fx">где: V<sub>кон</sub> — конечное значение, V<sub>нач</sub> — начальное, n — число лет. Показывает среднегодовой темп роста с учётом сложного процента</span> |
| **Call option** | Опцион колл | Право, но не обязанность купить актив по цене страйк в будущем. Выигрыш при росте цены. | <code>Выплата = max(S − K; 0)</code><br><span class="fx">где: S — цена актива. K — страйк.</span> |
| **Callable bond** | Облигация с правом досрочного погашения | Эмитент может выкупить её раньше срока по заранее оговорённой цене. Он делает это, когда ставки упали. |  |
| **Cap rate** | Ставка капитализации | Доходность недвижимости: годовой чистый доход, делённый на цену объекта. Чем ниже cap rate, тем дороже объект. | <code>Cap rate = NOI / Цена</code> |
| **Cap table** | Таблица капитализации | Список всех владельцев компании: кому какая доля принадлежит, включая опционы. |  |
| **CAPEX** | Capital Expenditures | Капитальные затраты: траты на покупку и обновление оборудования и других основных средств (ОС). Основные средства — это то, что служит много лет: станки, здания, машины. Например, пекарня покупает новую печь | <code>CAPEX = ΔОС + Амортизация</code><br><span class="fx">где: ΔОС — изменение основных средств за период (конец минус начало). Амортизация добавляется, потому что она уменьшила стоимость ОС без покупок</span> |
| **Capital call** | Вызов капитала | Фонд не берёт все обещанные деньги сразу: он просит их у LP по мере необходимости, когда находит сделку. |  |
| **Capital market line** | Линия рынка капитала | Прямая из безрисковой ставки в рыночный портфель. Показывает доходность портфелей, смешанных из безрисковых вложений и рынка. |  |
| **Capital rationing** |  | Ограниченный бюджет на инвестиции: проекты выстраивают по PI и берут лучшие, пока деньги не кончатся. Как поход в магазин с ограниченной суммой: сначала берёшь самое выгодное |  |
| **Capital structure** | Структура капитала | Из чего компания финансируется: сколько долга и сколько собственных денег. |  |
| **CAPM** | Capital Asset Pricing Model | Модель, которая считает, какую доходность ждут от акции: Ke = Rf + β × ERP. Ke — требуемая доходность, Rf — безрисковая ставка, β — чувствительность акции к рынку, ERP — премия за риск акций. То есть «надёжная ставка плюс плата за риск» | <code>Ke = Rf + β × (Rm − Rf)</code><br><span class="fx">где: Ke — стоимость собственного капитала. Rf — безрисковая ставка. β — чувствительность акции к рынку. Rm − Rf — премия за риск рынка (ERP)</span> |
| **Carried interest** | Carry | Доля прибыли фонда, которую получает управляющий (GP), обычно 20%, если превышен hurdle rate. |  |
| **Carry trade** | Керри-трейд | Занять в валюте с низкой ставкой, вложить в валюту с высокой и заработать разницу. Рискует резким изменением курса. |  |
| **Carve-out** | Выделение | Компания продаёт часть бизнеса или выводит его на IPO отдельно, оставляя себе контроль. |  |
| **Cash basis** | Кассовый метод | Доходы и расходы записывают только когда деньги реально пришли или ушли. Проще, но картина по прибыли искажается. По МСФО и РСБУ для крупных компаний используют начисление. |  |
| **Cash conversion cycle** | Цикл конверсии денег | Сколько дней деньги «заморожены» в операциях: от оплаты поставщику до получения денег от клиента. | <code>CCC = DIO + DSO − DPO</code><br><span class="fx">где: DIO — дни запасов. DSO — дни дебиторки. DPO — дни кредиторки.</span> |
| **Cash flow statement** | Отчёт о движении денег (ОДДС) | Показывает, откуда пришли и куда ушли реальные деньги за период, в трёх блоках: операционном, инвестиционном и финансовом. |  |
| **Cash ratio** | Коэффициент абсолютной ликвидности | Самая жёсткая проверка: только деньги и их эквиваленты против краткосрочных долгов. | <code>Cash ratio = Деньги / Краткосрочные обязательства</code> |
| **Cash sweep** | Погашение долга из избытка денег | Условие: весь свободный остаток денег идёт на досрочное погашение долга. |  |
| **CDS** | Credit Default Swap | Страховка от дефолта: покупатель регулярно платит, а если заёмщик не вернёт долг, продавец покрывает убыток. Цена CDS показывает, как рынок оценивает риск. |  |
| **CET1** | Common Equity Tier 1 | Самый надёжный капитал банка: акции и нераспределённая прибыль (Базель III). Это собственные деньги банка, которыми он в первую очередь покрывает убытки | <code>CET1 = Основной капитал / RWA</code><br><span class="fx">где: Основной капитал — акции и нераспределённая прибыль. RWA — активы, взвешенные на риск</span> |
| **CEX / DEX** |  | CEX — централизованная криптобиржа, хранит твои деньги (Binance). DEX — децентрализованная, сделки идут прямо из кошелька. |  |
| **CFADS** | Cash Flow Available for Debt Service | Деньги проекта, доступные для платежей по долгу. На них делят платежи, чтобы получить DSCR. | <code>DSCR = CFADS / (Проценты + Основной долг)</code> |
| **CFF** | Cash Flow from Financing | Финансовый поток: движение денег по долгу, дивидендам, байбэкам (выкупу своих акций) и выпуску новых акций. Это деньги, которые пришли от кредиторов и акционеров или ушли к ним |  |
| **CFI** | Cash Flow from Investing | Инвестиционный поток: деньги на CAPEX, а также от покупки и продажи активов и компаний. Обычно он отрицательный: компания тратит деньги на развитие |  |
| **CFO** | Cash Flow from Operations | Операционный денежный поток: деньги, которые компания получила от основной работы. Например, деньги магазина от продажи товаров за вычетом оплаты поставщикам и зарплат | <code>CFO = Чистая прибыль + D&A ± ΔNWC</code><br><span class="fx">где: D&A — амортизация (не денежные расходы, возвращаем). ΔNWC — изменение чистого оборотного капитала (рост NWC уменьшает денежный поток)</span> |
| **Churn** | Отток клиентов | Доля клиентов, которые ушли за период. | <code>Churn = Ушедшие клиенты / Клиенты в начале периода</code> |
| **CIM** | Confidential Information Memorandum | Подробное закрытое описание продаваемой компании для покупателей. Как подробное объявление о продаже квартиры с планом, документами и историей, которое показывают только серьёзным покупателям |  |
| **CIR** | Cost-to-Income Ratio | Какую долю доходов банка съедают его расходы: расходы / доходы. Если на каждые 100 рублей дохода уходит 40 рублей расходов, CIR равен 40% | <code>CIR = Операционные расходы / Операционные доходы</code><br><span class="fx">где: Расходы банка (персонал, офисы, IT) делим на его доходы. Чем ниже, тем эффективнее банк</span> |
| **Circularity** | Циклическая ссылка | В модели проценты зависят от долга, а долг от денежного потока, который зависит от процентов. Excel зацикливается, поэтому включают итерации или упрощают. |  |
| **Clean / Dirty price** | Чистая / грязная цена | Чистая цена — без накопленного купонного дохода. Грязная — вместе с ним, то есть реально платишь. | <code>Dirty = Clean + НКД</code> |
| **Clearing** | Клиринг | Сверка и расчёт взаимных обязательств по сделкам, чтобы обе стороны выполнили условия. На Мосбирже этим занимается НКЦ. |  |
| **CLO** | Collateralized Loan Obligation | Бумаги, обеспеченные пулом корпоративных кредитов и разделённые на транши с разным риском. |  |
| **Club deal** |  | Кредит нескольких банков без широкой синдикации (то есть без привлечения множества участников). Узкий круг банков договаривается между собой, как в закрытом клубе |  |
| **Collateral** | Залог | Имущество, которое банк заберёт, если заёмщик не вернёт кредит. |  |
| **Combined ratio** |  | (Убытки + расходы) / премии у страховщика. Если меньше 100%, страхование само по себе прибыльно. Премии — взносы клиентов. Собрали 100, выплатили и потратили 90: показатель 90% | <code>Combined = Убыточность + Расходность</code><br><span class="fx">где: Убыточность — выплаты / премии. Расходность — расходы на ведение дела / премии. Ниже 100% — страховщик в прибыли</span> |
| **Common stock** | Обыкновенные акции | Главный вид акций: даёт право голоса и долю в прибыли, но при ликвидации платят после кредиторов и держателей привилегированных. |  |
| **Comps** | Comparable companies | Таблица похожих компаний и их мультипликаторов. Мультипликатор — это «во сколько раз цена больше показателя» (прибыли, выручки). Так оценивают компанию по аналогии, как квартиру по цене соседних | <code>Цена = Метрика цели × Медианный мультипликатор аналогов</code><br><span class="fx">где: Метрика — например, EBITDA. Мультипликатор берётся у похожих публичных компаний</span> |
| **Consolidation** | Консолидация | Сложение отчётов материнской компании и дочерних в один, как будто это одна компания. Взаимные сделки внутри группы вычёркивают. |  |
| **Contango** | Контанго | Фьючерсы на более поздний срок дороже ближайших. Нормальная ситуация, когда хранение стоит денег. |  |
| **Contingent liability** | Условное обязательство | Возможный долг, который появится, только если случится событие (например, проиграют суд). Его описывают в примечаниях, а в баланс не ставят, если вероятность невысокая. |  |
| **Contribution margin** | Маржинальный доход | Что остаётся от выручки после переменных расходов. Идёт на покрытие постоянных расходов и на прибыль. | <code>Маржинальный доход = Выручка − Переменные расходы</code> |
| **Convertible bond** | Конвертируемая облигация | Облигация, которую можно обменять на акции эмитента по заранее оговорённой цене. Поэтому купон у неё ниже обычного. |  |
| **Convexity** | Выпуклость | Поправка к дюрации: показывает, что цена облигации реагирует на падение ставки сильнее, чем на такой же рост. |  |
| **CoR** | Cost of Risk | Цена кредитного риска: сколько денег банк отложил на возможные потери по кредитам (резервы / кредиты). Это «страховой запас» на случай, что часть клиентов не вернёт долг | <code>CoR = Резервы под потери за год / Средний кредитный портфель</code><br><span class="fx">где: Резервы — сумма, отложенная на плохие кредиты. Показывает, какая доля портфеля «сгорает» за год</span> |
| **Core inflation** | Базовая инфляция | Инфляция без самых скачущих цен (еда, энергия). Показывает устойчивый тренд. |  |
| **Cornerstone investor** | Якорный инвестор | Крупный инвестор, который заранее обещает купить большую долю в IPO. Его участие успокаивает остальных. |  |
| **Correlation** | Корреляция | Нормированная ковариация от −1 до +1. +1 — активы двигаются синхронно, 0 — независимо, −1 — зеркально. Чем меньше корреляция, тем сильнее диверсификация. | <code>ρ = Cov(A,B) / (σA × σB)</code> |
| **Cost of preferred** | Стоимость привилегированных акций | Цена денег от привилегированных акций: дивиденд, делённый на цену акции. | <code>Kp = Дивиденд / Цена</code> |
| **Covariance** | Ковариация | Показывает, движутся ли два актива в одну сторону. Положительная — вместе, отрицательная — в разные стороны. |  |
| **Covenant** |  | Условие кредитного договора, которое заёмщик обязан соблюдать (например, ND/EBITDA ≤ 3×). ND/EBITDA — это чистый долг, делённый на EBITDA. То есть «долг не должен быть больше годовой прибыли в 3 раза». При нарушении банк может потребовать вернуть деньги |  |
| **Covenant-lite** | Кредит без финансовых тестов | Кредит без регулярных (maintenance) ковенантов, остаются только условия при действии (incurrence). | |
| **CPI** | Индекс потребительских цен | Показывает, как изменилась цена корзины товаров, которую покупают семьи. Через него считают инфляцию. |  |
| **Crack spread** | Крэк-спред | Разница между ценой нефтепродуктов и нефти. Показывает маржу нефтепереработки. |  |
| **Credit rating** | Кредитный рейтинг | Оценка способности заёмщика вернуть долг. Агентства: S&P, Moody's, Fitch, в России — АКРА и «Эксперт РА». |  |
| **Credit spread** |  | Кредитный спред: доходность облигации компании минус доходность госбумаги того же срока. Это плата за то, что компания надёжна хуже государства. Чем больше разница, тем рискованнее компания | <code>Spread = Доходность облигации − Доходность госбумаги</code><br><span class="fx">где: Доплата за кредитный риск. Измеряется в б.п.</span> |
| **CRP** | Country Risk Premium | Надбавка к доходности за то, что вложения в конкретной стране рискованнее. Инвестор требует больше за вложения туда, где больше политических и экономических неожиданностей | <code>Ke = Rf + β × ERP + CRP</code><br><span class="fx">где: CRP — добавка к ставке за риск страны. Остальное как в CAPM</span> |
| **Currency peg** | Привязка курса | Центробанк удерживает курс валюты на фиксированном уровне к другой валюте, например к доллару. |  |
| **Current account** | Счёт текущих операций | Разница между тем, сколько страна получила от остального мира за экспорт и доходы, и сколько заплатила. Положительный — экспортёр. |  |
| **Current ratio** | Коэффициент текущей ликвидности | Хватит ли оборотных активов, чтобы закрыть краткосрочные долги. Выше 1 — запас есть. | <code>Current ratio = Оборотные активы / Краткосрочные обязательства</code> |
| **Current yield** | Текущая доходность | Купоны за год, делённые на цену облигации. Не учитывает разницу цены и номинала. | <code>Current yield = Годовой купон / Цена</code> |
| **Custodian** | Депозитарий / кастодиан | Организация, которая хранит бумаги клиентов и фиксирует права на них. В России — НРД. |  |
| **D&A** | Depreciation & Amortization | Амортизация: постепенное списание стоимости основных средств (ОС) и нематериальных активов (НМА) в расходы. Купили станок за 100 на 10 лет: каждый год в расходы идёт по 10, хотя деньги заплатили один раз. НМА — то, что нельзя потрогать: лицензии, программы, бренд |  |
| **DCF** | Discounted Cash Flow | Оценка компании по будущим денежным потокам, пересчитанным в сегодняшние деньги (дисконтированным). Идея: рубль сегодня ценнее рубля через год, поэтому будущие деньги «уценивают» | <code>EV = Σ FCF<sub>t</sub> / (1+WACC)<sup>t</sup> + TV / (1+WACC)<sup>n</sup></code><br><span class="fx">где: FCF<sub>t</sub> — свободный денежный поток года t. WACC — ставка дисконтирования. TV — терминальная стоимость после прогноза. n — последний год прогноза</span> |
| **DCM** | Debt Capital Markets | Рынок, на котором компании занимают деньги, выпуская облигации. Облигация — это долговая расписка: компания берёт деньги у многих людей и обещает вернуть с процентами |  |
| **DDM** | Dividend Discount Model | Оценка акции по будущим дивидендам, пересчитанным в сегодняшние деньги. Дивиденд — это часть прибыли, которую компания платит владельцам акций | <code>P = DPS<sub>1</sub> / (Ke − g)</code><br><span class="fx">где: DPS<sub>1</sub> — дивиденд на акцию в следующем году. Ke — требуемая доходность. g — вечный темп роста дивидендов (модель Гордона)</span> |
| **Debt / Equity** | Долг к капиталу | Сколько долга приходится на рубль собственных денег. Мера финансового рычага. | <code>D/E = Долг / Капитал</code> |
| **Debt capacity** | Долговая ёмкость | Максимум долга, который компания может нести без угрозы платежеспособности. |  |
| **Debt schedule** | График долга | Таблица в модели: сколько долга на начало года, сколько взяли и погасили, сколько осталось и какие проценты. |  |
| **Deferred revenue** | Доходы будущих периодов | Деньги, которые клиент уже заплатил, а услугу или товар компания ещё не отдала. Это обязательство: пока не отдала, выручкой это не считается. |  |
| **DeFi** | Decentralized Finance | Финансовые сервисы на блокчейне без банков: кредиты, обмен, ставки, всё через смарт-контракты. |  |
| **Deflation** | Дефляция | Цены в экономике падают. Выглядит приятно, но люди откладывают покупки и экономика замедляется. |  |
| **Delta** | Дельта | Насколько изменится цена опциона, если цена актива сдвинется на 1. У колла от 0 до 1. |  |
| **Depreciation** | Амортизация (основных средств) | Постепенное списание стоимости оборудования, зданий и т. п. на расходы за все годы их службы. Деньги не уходят, но прибыль уменьшается. | <code>Амортизация в год = (Стоимость − Остаточная стоимость) / Срок службы</code> |
| **Devaluation** | Девальвация | Намеренное или вынужденное снижение курса национальной валюты. |  |
| **Diluted EPS** | Разводнённая прибыль на акцию | EPS с учётом всех бумаг, которые можно превратить в акции: опционов, конвертируемых облигаций. |  |
| **Dilution** | Размытие доли | Когда выпускают новые акции, доля каждого старого акционера уменьшается. | <code>Новая доля = Старая доля × Старое число акций / Новое число акций</code> |
| **Direct listing** | Прямой листинг | Выход на биржу без привлечения новых денег: акции просто начинают торговаться. |  |
| **Distressed debt** | Проблемный долг | Долг компании в тяжёлом положении, торгуется с большим дисконтом. Фонды скупают его, надеясь на выкуп или реструктуризацию. |  |
| **Diversification** | Диверсификация | Не класть все яйца в одну корзину. Разные активы падают не одновременно, поэтому риск портфеля меньше риска отдельных бумаг. |  |
| **Divestiture** | Продажа бизнеса | Компания продаёт неосновной бизнес целиком. Деньги идут на долг, дивиденды или основной бизнес. |  |
| **Dividend policy** | Дивидендная политика | Правила, по которым компания решает, сколько прибыли выплатить акционерам, а сколько оставить. |  |
| **Dividend recap** | Рекапитализация ради дивиденда | Компания берёт новый долг и выплачивает деньги акционерам. Фонд так возвращает часть вложений до продажи. |  |
| **DLOM** | Discount for Lack of Marketability | Скидка за низкую ликвидность: долю в частной компании трудно быстро продать по справедливой цене. |  |
| **Down round** | Раунд по сниженной оценке | Компания привлекает деньги дешевле, чем в прошлый раз. Плохой знак для старых инвесторов и для сотрудников с опционами. |  |
| **DPI / TVPI / RVPI** |  | Метрики фонда. DPI — сколько денег уже вернули инвесторам, RVPI — сколько ещё стоят оставшиеся вложения, TVPI — их сумма. | <code>TVPI = DPI + RVPI</code><br><span class="fx">где: Каждая метрика — на рубль вложенных денег.</span> |
| **DPS** | Dividend Per Share | Сколько дивидендов приходится на одну акцию. Если компания выплатила 1000 и акций 100, то DPS равен 10 | <code>DPS = Дивиденды / Число акций</code><br><span class="fx">где: Все выплаченные дивиденды делим на число акций в обращении</span> |
| **Drag-along** | Право принудительной продажи | Если крупные акционеры продают компанию, они могут заставить продать и миноритариев на тех же условиях. |  |
| **Dry powder** | «Сухой порох» | Деньги, которые фонд уже собрал, но ещё не вложил. |  |
| **DSCR** | Debt Service Coverage Ratio | Денежный поток для обслуживания долга / (проценты + плановое погашение). Показывает, во сколько раз заработок больше платежей по долгу. Если DSCR меньше 1, денег на платёж не хватает | <code>DSCR = CFADS / (Проценты + Погашение основного долга)</code><br><span class="fx">где: CFADS — денежный поток для обслуживания долга. Ниже 1 — денег на платежи не хватает</span> |
| **DSO / DIO / DPO** | Days Sales / Inventory / Payables Outstanding | За сколько дней в среднем оборачиваются: дебиторка (долги клиентов), запасы, кредиторка (долги перед поставщиками). Например, DSO 30 дней значит, что клиенты платят в среднем через месяц после продажи | <code>DSO = Дебиторка / Выручка × 365; DIO = Запасы / COGS × 365; DPO = Кредиторка / COGS × 365</code><br><span class="fx">где: Дебиторка — долги покупателей. Запасы — товары на складе. Кредиторка — долги поставщикам. COGS — себестоимость. Результат в днях. Цикл денег: DSO + DIO − DPO</span> |
| **DSRA** | Debt Service Reserve Account | Резервный счёт проекта: на нём лежат деньги на несколько платежей по долгу. |  |
| **DTA / DTL** | Отложенные налоговые активы / обязательства | Разница между налогом по учёту и налогом по закону. DTL — налог, который заплатят позже; DTA — налог, который заплатили вперёд и потом вернут через уменьшение налога. |  |
| **Due diligence (DD)** |  | Тщательная проверка компании перед сделкой: покупатель смотрит документы, финансы и риски. Как осмотр квартиры и проверка документов перед покупкой |  |
| **DuPont** | Разложение ROE по Дюпону | ROE делят на три части: маржа, оборачиваемость активов, рычаг. Видно, за счёт чего прибыльность: хорошая маржа, быстрые продажи или долг. | <code>ROE = (Прибыль/Выручка) × (Выручка/Активы) × (Активы/Капитал)</code> |
| **Dutch disease** | «Голландская болезнь» | Рост добычи сырья укрепляет валюту и делает остальные отрасли неконкурентными. |  |
| **DV01** |  | Сколько рублей меняется цена позиции при смещении доходности на 1 б.п. |  |
| **EAD** | Exposure at Default | Сумма, которую банк потеряет под риском в момент дефолта заёмщика. |  |
| **Earn-out** |  | Часть цены сделки, которую платят позже, если компания достигнет оговорённых результатов. Продавец получает доплату, только если бизнес оправдает его обещания | <code>Цена = Фиксированная часть + Отложенная часть, если цель достигнута</code><br><span class="fx">где: Отложенная часть зависит от результатов бизнеса после сделки</span> |
| **EBIT** | Earnings Before Interest & Taxes | Операционная прибыль: заработок до вычета процентов и налогов. Показывает, сколько приносит сам бизнес, без влияния кредитов и налогов | <code>EBIT = Выручка − COGS − Операционные расходы</code><br><span class="fx">где: COGS — себестоимость проданного. Операционные расходы — SG&A, R&D и т. п. Прибыль до процентов и налогов</span> |
| **EBITDA** | Earnings Before Interest, Taxes, D&A | Прибыль до вычета процентов, налогов и амортизации; грубо показывает, сколько компания зарабатывает на своей основной работе. Это EBIT, к которому прибавили амортизацию | <code>EBITDA = EBIT + D&A</code><br><span class="fx">где: EBIT — операционная прибыль. D&A — амортизация и износ. Маржа EBITDA = EBITDA / Выручка</span> |
| **EBITDA margin** | Маржа EBITDA | Какая доля выручки превращается в EBITDA. Удобно сравнивать компании одной отрасли. | <code>EBITDA margin = EBITDA / Выручка</code> |
| **EBITDAR** |  | EBITDA до арендных расходов. Нужна для сравнения компаний, где часть бизнеса арендована, а часть куплена (ритейл, авиа, рестораны). | <code>EBITDAR = EBITDA + Аренда</code> |
| **ECL** | Expected Credit Loss | Ожидаемые кредитные потери, которые банк резервирует по МСФО 9 заранее. |  |
| **ECM** | Equity Capital Markets | Рынок, на котором компании привлекают деньги, продавая свои акции (IPO, SPO). Акция — доля в компании, и тот, кто её купил, становится совладельцем |  |
| **Efficient frontier** | Эффективная граница | Линия на графике «риск — доходность»: лучшие портфели, где нельзя поднять доходность без роста риска. |  |
| **EPC** | Engineering, Procurement, Construction | Договор, по которому подрядчик проектирует, закупает и строит объект под ключ за фиксированную цену. |  |
| **EPS** | Earnings Per Share | Сколько чистой прибыли приходится на одну акцию. Чистая прибыль — то, что осталось после всех расходов и налогов | <code>EPS = (Чистая прибыль − Дивиденды по привилегированным) / Средневзвешенное число акций</code><br><span class="fx">где: Прибыль, которая приходится на одну обыкновенную акцию</span> |
| **Equity** | Акционерный капитал / акции | Доля владельцев в компании. Может означать и сам капитал, и ценные бумаги, которые его представляют. |  |
| **Equity method** | Метод долевого участия | Как учитывают долю в компании, где у тебя 20–50% и нет контроля: не складывают её отчёт по строкам, а показывают одну строку «доля в прибыли». |  |
| **Equity Value** |  | Стоимость акционерного капитала (для публичной компании — капитализация). Это цена только той части бизнеса, которая принадлежит владельцам, без долга | <code>Equity Value = EV − Net Debt − NCI − Привилегированные</code><br><span class="fx">где: EV — стоимость бизнеса. Вычитаем долги и права других держателей. Остаток принадлежит акционерам</span> |
| **ERP** | Equity Risk Premium | Дополнительная доходность, которую инвесторы требуют за то, что вкладываются в акции, а не в безрисковые бумаги. Это плата за то, что акции могут и упасть в цене | <code>ERP = Rm − Rf</code><br><span class="fx">где: Rm — ожидаемая доходность рынка акций. Rf — безрисковая ставка. Это доплата за то, что вложились в рынок, а не в госбумаги</span> |
| **ESOP** | Employee Stock Option Plan | Программа, по которой сотрудники получают опционы или акции компании. Привязывает команду к росту стоимости. |  |
| **ETF** | Exchange Traded Fund | Фонд, чьи паи торгуются на бирже как акции. Обычно повторяет индекс и берёт небольшую комиссию. |  |
| **Ethereum** | Эфириум | Блокчейн со смарт-контрактами. Монета ETH платит комиссии за операции. |  |
| **Eurobond** | Еврооблигация | Облигация, выпущенная в иностранной валюте за пределами страны, где живёт эмитент. |  |
| **EV** | Enterprise Value | Стоимость всего бизнеса целиком: капитал + чистый долг + … Представь цену квартиры целиком: и твоя часть, и часть, которую ты ещё должен банку по ипотеке | <code>EV = Капитализация + Долг + NCI + Привилегированные − Деньги</code><br><span class="fx">где: Капитализация — цена всех акций. NCI — доля миноритариев в дочках. Деньги вычитаем, ими можно сразу погасить часть долга</span> |
| **EV/EBIT** |  | Стоимость компании к операционной прибыли. Учитывает амортизацию, поэтому лучше для капиталоёмких отраслей. | <code>EV/EBIT = EV / EBIT</code> |
| **EV/EBITDA** |  | Главный мультипликатор оценки: стоимость компании в целом к её EBITDA. Не зависит от долговой нагрузки, поэтому подходит для сравнения. | <code>EV/EBITDA = EV / EBITDA</code> |
| **EV/Sales** |  | Стоимость компании к выручке. Используют, когда прибыли ещё нет (быстрорастущие компании). | <code>EV/Sales = EV / Выручка</code> |
| **EVA** | Economic Value Added | Экономическая добавленная стоимость: (ROIC − WACC) × Инвестированный капитал. Показывает, сколько денег компания заработала сверх того, что требуют те, кто в неё вложился | <code>EVA = NOPAT − WACC × Инвестированный капитал</code><br><span class="fx">где: NOPAT — операционная прибыль после налога. Вычитаем плату за капитал. Положительная EVA — компания создаёт стоимость</span> |
| **Exit multiple** | Мультипликатор выхода | Мультипликатор, по которому оценивают компанию в последнем году прогноза, чтобы получить терминальную стоимость. Альтернатива модели Гордона. | <code>TV = EBITDA(последний год) × Exit multiple</code> |
| **Expected loss** | Ожидаемые потери | Сколько банк в среднем теряет по кредитам из-за дефолтов. | <code>EL = PD × LGD × EAD</code> |
| **Fair value** | Справедливая стоимость | Цена, по которой актив можно продать в обычной сделке между участниками рынка на дату оценки. |  |
| **Fairness opinion** | Заключение о справедливости цены | Письмо банка совету директоров: цена в сделке справедлива с финансовой точки зрения. Защита совета от претензий акционеров. |  |
| **Fama–French** | Модель Фамы — Френча | Добавляет к CAPM ещё факторы: размер компании и «дешевизну» (value). Лучше объясняет реальную доходность акций. |  |
| **FCF** | Free Cash Flow | Свободный денежный поток: деньги, которые остаются после операционных расходов, налогов и инвестиций. Это деньги, которые можно свободно потратить: выплатить владельцам или вернуть долг | <code>FCF = CFO − CAPEX</code><br><span class="fx">где: CFO — денежный поток от операций. CAPEX — инвестиции в основные средства</span> |
| **FCFE** | Free Cash Flow to Equity | Свободный поток только акционерам (после долга). Дисконтируется по Ke. То есть это деньги, которые могут достаться владельцам, когда кредиторы уже получили своё | <code>FCFE = FCFF − Проценты × (1−t) + Новый долг − Погашение долга</code><br><span class="fx">где: Проценты × (1−t) — проценты после налогового щита. Новый долг и погашение — чистое заимствование. Остаётся акционерам</span> |
| **FCFF** | Free Cash Flow to Firm | Свободный поток всем инвесторам (до долга), то есть и кредиторам, и акционерам: EBIT×(1−t) + D&A − CAPEX − ΔNWC. Здесь t — налоговая ставка, ΔNWC — прирост оборотного капитала. Дисконтируется по WACC | <code>FCFF = EBIT × (1−t) + D&A − CAPEX − ΔNWC</code><br><span class="fx">где: t — ставка налога. D&A — амортизация. CAPEX — инвестиции. ΔNWC — прирост оборотного капитала. Поток, доступный и кредиторам, и акционерам</span> |
| **FDV** | Fully Diluted Valuation | Капитализация криптотокена, если посчитать по максимальному числу токенов, которое можно выпустить. Токен — цифровая единица, которую выпускает проект. FDV показывает «потолок» оценки, когда все токены уже будут выпущены | <code>FDV = Цена токена × Максимальное число токенов</code><br><span class="fx">где: Цена текущая, число токенов — всё, что будет выпущено, включая ещё не выданные</span> |
| **Fed funds rate** | Ставка ФРС | Ключевая ставка США: по ней банки одалживают друг другу деньги на ночь. |  |
| **FFO** | Funds From Operations | Денежная прибыль REIT (фонда, который владеет недвижимостью). Сюда не включают бумажное списание стоимости зданий, поэтому цифра ближе к реальным деньгам от аренды | <code>FFO = Чистая прибыль + D&A − Прибыль от продажи недвижимости</code><br><span class="fx">где: Используется для REIT: амортизацию возвращаем, разовую прибыль от продаж убираем</span> |
| **FIFO** | Первым пришёл — первым ушёл | Способ учёта запасов: при продаже в себестоимость идёт самая ранняя партия. При росте цен прибыль выше, чем по LIFO. |  |
| **Finance lease** | Финансовая аренда (лизинг) | Аренда, по сути равная покупке в рассрочку: актив числится у арендатора, платежи считаются долгом. |  |
| **Financial leverage** | Финансовый рычаг | Использование долга. Увеличивает доходность для владельцев при хорошей работе и усиливает потери при плохой. | <code>Fin. leverage = Активы / Капитал</code> |
| **Fiscal policy** | Бюджетная политика | Налоги и расходы государства. Влияет на экономику через спрос. |  |
| **Football field** | «Футбольное поле» | График на слайде, где полосами показаны диапазоны оценки по разным методам: DCF, мультипликаторы, сделки. Видно, где методы сходятся. |  |
| **Free float** |  | Какая доля акций свободно торгуется на бирже. Остальное держат крупные владельцы и не продают | <code>Free float = Акции в свободном обращении / Все акции</code><br><span class="fx">где: Без долей стратегических держателей, государства и менеджмента</span> |
| **FRN** | Floating Rate Note | Облигация с плавающим купоном: он привязан к ставке, например к ключевой или RUONIA, и растёт вместе с ней. |  |
| **Fulcrum security** |  | Уровень долга, на котором заканчивается стоимость бизнеса. Его держатели получают контроль при реструктуризации. Реструктуризация — это пересмотр долгов, чтобы компания смогла выжить |  |
| **G-spread** |  | Спред доходности облигации к кривой госбумаг (КБД) на том же сроке. Показывает, на сколько облигация доходнее госбумаги с тем же сроком. КБД объяснена ниже | <code>G-spread = YTM облигации − YTM госбумаги того же срока</code><br><span class="fx">где: Спред к кривой гособлигаций</span> |
| **Gamma** | Гамма | Как быстро меняется дельта при движении цены актива. |  |
| **GDP** | Валовой внутренний продукт | Стоимость всех товаров и услуг, произведённых в стране за год. Главный показатель размера экономики. |  |
| **GMV** | Gross Merchandise Value | Общая сумма всех продаж через платформу (маркетплейс). Это не выручка платформы: ей достаётся только комиссия. |  |
| **Golden parachute** | «Золотой парашют» | Крупная компенсация топ-менеджерам при увольнении после поглощения. Делает покупку дороже и снижает интерес врага. |  |
| **Goodwill** |  | Переплата при покупке компании: на сколько цена покупки больше справедливой стоимости её чистых активов. Например, купили за 150 компанию, чьё имущество за вычетом долгов стоит 100: гудвилл равен 50. Это плата за бренд, клиентов, репутацию | <code>Goodwill = Цена покупки − Справедливая стоимость чистых активов</code><br><span class="fx">где: Переплата за бренд, клиентов и команду сверх стоимости активов</span> |
| **GP / LP** | General / Limited Partner | GP — управляющий фондом, принимает решения. LP — инвестор, даёт деньги и не управляет. |  |
| **Green bond** | Зелёная облигация | Облигация, деньги от которой идут на экологические проекты. |  |
| **Greenshoe** |  | Право организатора размещения продать дополнительные акции (до 15%), чтобы удерживать цену на стабильном уровне. Это «запасной» объём: если спрос высокий, продают больше, а если цена падает, организатор выкупает акции и поддерживает цену | <code>Допразмещение ≤ 15% от основного объёма</code><br><span class="fx">где: Опцион андеррайтера выкупить дополнительные акции по цене IPO, чтобы стабилизировать курс</span> |
| **Gross margin** | Валовая маржа | Какая доля выручки остаётся после себестоимости. | <code>Gross margin = Валовая прибыль / Выручка</code> |
| **Gross profit** | Валовая прибыль | Выручка минус себестоимость. Сколько остаётся на всё остальное: зарплаты, аренду, проценты, налоги. | <code>Валовая прибыль = Выручка − Себестоимость</code> |
| **Growth capex** | Инвестиции в рост | Траты на расширение: новые заводы, магазины, мощности. Их можно отложить, не ломая текущий бизнес. |  |
| **Growth investing** | Инвестирование в рост | Покупать быстро растущие компании, даже если мультипликаторы высокие, ожидая, что рост окупит цену. |  |
| **Haircut** |  | Списание части долга: кредитор получает меньше номинала. Номинал — сумма долга по договору. Например, долг 100, а кредитор согласился на 70 | <code>Залог = Рыночная стоимость × (1 − Haircut)</code><br><span class="fx">где: Haircut — скидка к рыночной цене залога. При 20% бумага за 100 принимается как залог на 80</span> |
| **Halving** | Халвинг | Раз в 4 года награда майнерам за блок биткоина падает вдвое. Предложение растёт медленнее. |  |
| **Hedging** | Хеджирование | Сделка, которая страхует от неприятного движения цены: например, продать фьючерс, чтобы защитить стоимость товара на складе. |  |
| **HFT** | High-Frequency Trading | Высокочастотная торговля: алгоритмы совершают тысячи сделок в секунду, зарабатывая на крошечных разницах цен. |  |
| **High yield** | Высокодоходные облигации | Облигации компаний с низким рейтингом и высокой ставкой. Иначе «мусорные». |  |
| **Historical cost** | Первоначальная стоимость | Актив записан по цене покупки и не пересматривается вверх вместе с рынком (только амортизируется). |  |
| **Hostile takeover** | Недружественное поглощение | Покупатель обращается напрямую к акционерам, минуя совет директоров целевой компании. |  |
| **Hurdle rate** |  | Минимальная доходность, которую должен дать проект, чтобы в него стоило вкладываться (часто WACC + премия). «Hurdle» значит «барьер»: проект должен через него перепрыгнуть | <code>Hurdle = Минимальная требуемая доходность проекта</code><br><span class="fx">где: Если IRR проекта ниже, проект не берут. Часто равна WACC плюс запас</span> |
| **IC memo** | Investment committee memo | Документ для инвестиционного комитета фонда: тезис, оценка, риски, доходность. | |
| **ICR** | Interest Coverage Ratio | Покрытие процентов: во сколько раз прибыль больше процентов (EBIT / проценты). Если прибыль 90, а проценты 30, ICR равен 3: денег втрое больше, чем нужно на проценты | <code>ICR = EBIT / Проценты к уплате</code><br><span class="fx">где: Во сколько раз операционная прибыль покрывает проценты. Ниже 1,5–2 — тревожно</span> |
| **IFRS / МСФО** | International Financial Reporting Standards | Международные правила составления финансовой отчётности. Они нужны, чтобы компании из разных стран считали и показывали свои цифры одинаково |  |
| **IFRS 16** | Стандарт об аренде | По МСФО почти любая аренда показывается в балансе: актив (право пользования) и долг на сумму будущих платежей. Из-за этого у арендаторов выросли EBITDA и долг. |  |
| **IFRS 9 stages** | Стадии по МСФО 9 | Кредиты делят на три стадии: 1 — всё хорошо, 2 — риск вырос, 3 — дефолт. Чем выше стадия, тем больше резерв. |  |
| **Impairment** | Обесценение | Когда актив оказался стоит меньше, чем записан в балансе, его списывают до реальной цены. Убыток разовый и бумажный, деньги не уходят. |  |
| **Implied multiple** | Подразумеваемый мультипликатор | Мультипликатор, который «зашит» в полученной оценке. Помогает проверить DCF: если вышло EV/EBITDA = 30, что-то не так. |  |
| **Implied volatility** | Подразумеваемая волатильность | Волатильность, которую «закладывает» рынок в цену опциона. Растёт в страх. |  |
| **Income statement (P&L)** | Отчёт о прибылях и убытках | Показывает за период, сколько компания заработала и потратила: от выручки сверху до чистой прибыли внизу. | <code>Чистая прибыль = Выручка − Расходы − Проценты − Налоги</code> |
| **Index** | Индекс | Число, показывающее, как ведёт себя группа бумаг. IMOEX — российские акции, S&P 500 — американские. |  |
| **Inflation-linked bond** | Облигация, привязанная к инфляции | Номинал или купон растёт вместе с инфляцией. Защита от обесценения денег. В России — ОФЗ-ИН. |  |
| **Information ratio** | Информационный коэффициент | Насколько постоянно управляющий обыгрывает бенчмарк, с учётом отклонения от него. | <code>IR = (Rp − Rb) / Tracking error</code> |
| **Intangible assets** | Нематериальные активы | Активы без вещественной формы: патенты, лицензии, бренды, программы, гудвил. |  |
| **Interest expense** | Процентные расходы | Сколько компания заплатила процентов по своим долгам за период. |  |
| **Intrinsic value** | Внутренняя стоимость опциона | Сколько опцион стоил бы, если бы его исполнили прямо сейчас. | <code>Call: max(S − K; 0)</code> |
| **Inventory** | Запасы | Сырьё, незавершёнка и готовая продукция на складе. Пока не продано, лежит в балансе как актив. |  |
| **Inventory turnover** | Оборачиваемость запасов | Сколько раз за год запасы «проходят» через продажи. | <code>Inventory turnover = Себестоимость / Средние запасы</code> |
| **Investment grade** | Инвестиционный рейтинг | Рейтинг не ниже BBB− по шкале S&P: считается, что компания скорее вернёт долг. Всё ниже — high yield. |  |
| **IPO** | Initial Public Offering | Первичное публичное размещение: компания впервые продаёт свои акции на бирже. После этого любой человек может купить долю в такой компании |  |
| **IRR** | Internal Rate of Return | Внутренняя норма доходности: годовая доходность проекта, то есть ставка, при которой NPV = 0. Проще говоря, «под какой годовой процент работают вложенные деньги» | <code>0 = Σ CF<sub>t</sub> / (1+IRR)<sup>t</sup></code><br><span class="fx">где: CF<sub>t</sub> — денежный поток года t (включая начальную инвестицию с минусом). IRR — ставка, при которой NPV равна нулю. Подбирается итерациями</span> |
| **IRS** | Interest Rate Swap | Процентный своп: стороны меняются платежами по фиксированной и плавающей ставке на одну и ту же сумму. Применяют, чтобы превратить плавающий долг в фиксированный. |  |
| **J-curve** | J-кривая | Доходность фонда в первые годы отрицательна (комиссии, неокупившиеся вложения), потом растёт. График по форме похож на букву J. |  |
| **Joint venture** | Совместное предприятие | Две компании создают общую, делят расходы, риски и прибыль. |  |
| **LBO** | Leveraged Buyout | Покупка компании в основном на заёмные деньги. Как купить квартиру в ипотеку с маленьким первым взносом. Долг потом гасят из прибыли самой купленной компании |  |
| **LCR** | Liquidity Coverage Ratio | Хватит ли у банка ликвидных активов, чтобы пережить отток денег за 30 дней. Должен быть не ниже 100%. | <code>LCR = Ликвидные активы / Чистый отток за 30 дней</code> |
| **Leverage** |  | Финансовый рычаг: использование долга. Часто его измеряют как ND/EBITDA. Долг усиливает и прибыль, и убытки, как рычаг: чем длиннее, тем сильнее эффект | <code>Леверидж = Net Debt / EBITDA</code><br><span class="fx">где: Net Debt — долг минус деньги. Показывает, за сколько лет EBITDA погасит долг</span> |
| **Levered beta** | Бета с учётом долга | Бета акций компании, как она есть: включает риск самого бизнеса и риск долга. | <code>βL = βU × (1 + (1 − t) × D/E)</code><br><span class="fx">где: βU — бета без долга. t — налог. D/E — долг к капиталу.</span> |
| **LGD** | Loss Given Default | Доля потерь при дефолте = 1 − recovery rate. Если кредитор вернул 40% долга, потеря составила 60% | <code>LGD = 1 − Recovery rate</code><br><span class="fx">где: Recovery rate — доля долга, которую вернули при дефолте. LGD — доля потерь</span> |
| **LIFO** | Последним пришёл — первым ушёл | Способ учёта: в себестоимость идёт самая свежая партия. Разрешён в US GAAP, запрещён в МСФО. |  |
| **LIFO reserve** | Резерв LIFO | Разница между запасами по FIFO и по LIFO. Нужна, чтобы пересчитать отчёт американской компании в FIFO. | <code>Запасы FIFO = Запасы LIFO + LIFO reserve</code> |
| **Lifting cost** | Себестоимость добычи | Сколько стоит достать баррель нефти из скважины. |  |
| **Limit order** | Лимитная заявка | Купить или продать не хуже указанной цены. Может не исполниться, если рынок не дошёл. |  |
| **Liquidation preference** | Приоритет при ликвидации | Право инвестора первым забрать свои деньги (иногда с кратным умножением) при продаже или закрытии компании, до основателей. |  |
| **LLCR** | Loan Life Cover Ratio | NPV потоков проекта за срок кредита / остаток долга. Показывает, хватит ли денег проекта, чтобы погасить весь кредит. Если меньше 1, не хватит | <code>LLCR = NPV(CFADS за срок кредита) / Остаток долга</code><br><span class="fx">где: CFADS — денежный поток, доступный для обслуживания долга. NPV берётся по ставке кредита</span> |
| **Loan loss provision** | Резерв на возможные потери по ссудам | Деньги, которые банк откладывает на случай, что часть кредитов не вернут. Уменьшает прибыль. |  |
| **Lock-up** |  | Запрет продавать свои акции после IPO (обычно 180 дней). Нужен, чтобы владельцы не бросились продавать сразу и не обвалили цену |  |
| **Locked box** |  | Способ определить цену сделки: её фиксируют по балансу на прошлую дату, и дальше цена не пересчитывается. Покупатель знает цену заранее, а продавец обещает, что до закрытия сделки деньги из компании не уйдут |  |
| **Loss ratio** | Коэффициент убыточности | Какую долю премий страховщик выплатил как возмещение. | <code>Loss ratio = Выплаты / Премии</code> |
| **LTM / TTM / NTM** | Last / Trailing / Next Twelve Months | Последние 12 месяцев (LTM, TTM) или следующие 12 месяцев (NTM). Так считают показатели за «скользящий» год, а не за календарный | <code>LTM = Год<sub>прошлый</sub> + YTD<sub>тек</sub> − YTD<sub>прош</sub></code><br><span class="fx">где: YTD — с начала года до отчётной даты. Берём прошлый год, добавляем текущий YTD и вычитаем YTD прошлого года. Получаем последние 12 месяцев</span> |
| **LTV (клиент)** | Customer Lifetime Value | Сколько денег клиент принесёт за всё время, пока пользуется продуктом. | <code>LTV = Средний чек × Покупок за период × Срок жизни клиента × Маржа</code><br><span class="fx">где: Хорошо, когда LTV / CAC больше 3.</span> |
| **LTV (кредит)** | Loan-to-Value | Какую долю от стоимости залога составляет кредит. Чем ниже, тем безопаснее банк. | <code>LTV = Кредит / Стоимость залога</code> |
| **M&A** | Mergers & Acquisitions | Слияния и поглощения компаний. Слияние — две компании становятся одной, поглощение — одна покупает другую |  |
| **M2** | Денежная масса M2 | Наличные, деньги на счетах и на срочных вкладах. Показывает, сколько денег в экономике. |  |
| **MAC / MAE** | Material Adverse Change / Effect | Условие, по которому покупатель может отказаться от сделки, если случится существенное негативное событие. Например, пожар на главном заводе до закрытия сделки |  |
| **Maintenance capex** | Поддерживающие инвестиции | Деньги, которые надо тратить, чтобы бизнес просто не развалился: ремонт, замена оборудования. |  |
| **Make-whole** | Компенсация при досрочном погашении | Платёж, равный приведённой стоимости всех недополученных платежей по облигации. | |
| **Management fee** | Комиссия за управление | Ежегодная плата фонду за управление деньгами, часто 1,5–2% от капитала. Выплачивается независимо от результата. |  |
| **Margin call** | Маржин-колл | Требование брокера добавить денег на счёт, когда убытки по позиции с плечом съели обеспечение. Не добавил — позицию закроют принудительно. |  |
| **Mark-to-market** | Переоценка по рынку | Оценка позиции по сегодняшней рыночной цене, а не по цене покупки. Прибыль и убыток видны каждый день. |  |
| **Market maker** | Маркетмейкер | Участник, который постоянно выставляет и цену покупки, и цену продажи, давая рынку ликвидность. Зарабатывает на спреде. |  |
| **Market order** | Рыночная заявка | Купить или продать сразу по лучшей доступной цене. Исполнится, но цена может отличаться от ожидаемой. |  |
| **Max drawdown** | Максимальная просадка | Самое глубокое падение портфеля от пика до дна за период. Показывает, сколько можно потерять в плохой момент. | <code>Drawdown = (Дно − Пик) / Пик</code> |
| **MBO** | Management Buyout | Выкуп компании самим менеджментом, обычно вместе с фондом и за счёт долга. |  |
| **MBS** | Mortgage-Backed Security | Бумага, обеспеченная пулом ипотечных кредитов. |  |
| **Merger arbitrage** | Арбитраж слияний | Покупка акций цели по цене чуть ниже цены сделки. Заработок, если сделка закроется, убыток, если сорвётся. |  |
| **Mezzanine** | Мезонинное финансирование | Дорогой долг между обычным долгом и акциями. Платят выше, чем по кредитам, зато при банкротстве возвращают позже. |  |
| **Mid-year convention** | Допущение о середине года | Денежные потоки приходят равномерно в течение года, поэтому их дисконтируют не на конец года, а на середину. Оценка получается выше. |  |
| **Minority discount** | Скидка за миноритарность | Доля без контроля стоит дешевле пропорциональной доли компании, потому что владелец не может решать. |  |
| **Modified duration** | Модифицированная дюрация | Приблизительно на сколько процентов изменится цена облигации при изменении доходности на 1 п. п. | <code>ΔP/P ≈ −D_mod × Δy</code> |
| **Modigliani–Miller** | Теорема Модильяни — Миллера | В идеальном мире без налогов стоимость компании не зависит от структуры капитала. В реальности есть налоговый щит и риск банкротства, поэтому структура важна. |  |
| **MoM / MOIC** | Multiple of Money / Multiple on Invested Capital | Во сколько раз выросли вложенные деньги. Вложили 100, получили 250: MoM равен 2,5× | <code>MOIC = Выручка от выхода / Вложенный капитал</code><br><span class="fx">где: Сколько раз вернулись вложения. MOIC 3x значит, что на 1 вложенный пришло 3</span> |
| **Momentum** | Моментум | Стратегия: покупать то, что росло недавно, продавать то, что падало. Работает до разворота. |  |
| **Monetary policy** | Денежно-кредитная политика | Действия центробанка по ставке и количеству денег, чтобы держать инфляцию в цели и поддерживать экономику. |  |
| **Monte Carlo** | Метод Монте-Карло | Тысячи прогонов модели со случайными значениями вводных. На выходе не одно число, а распределение результатов. |  |
| **MRR** | Monthly Recurring Revenue | Ежемесячная повторяющаяся выручка от подписок. Годовая версия — ARR. |  |
| **Mutual fund** | Паевой фонд (ПИФ) | Фонд, где деньги многих инвесторов объединены и управляются управляющей компанией. Пай можно купить и погасить по цене, зависящей от стоимости активов. |  |
| **MVA** | Market Value Added | Рыночная стоимость компании минус вложенный в неё капитал. Показывает, сколько стоимости компания создала сверх вложенных в неё денег | <code>MVA = Рыночная стоимость компании − Инвестированный капитал</code><br><span class="fx">где: Сколько стоимости компания добавила сверх вложенных в неё денег</span> |
| **NAV** | Net Asset Value | Стоимость чистых активов: что останется, если из имущества вычесть долги. Как стоимость квартиры за вычетом остатка ипотеки | <code>NAV = Активы − Обязательства</code><br><span class="fx">где: Для фонда: стоимость активов по рынку минус долги. На пай: NAV / число паёв</span> |
| **NBO / BO** | (Non-) Binding Offer | Предложение о покупке: необязывающее (NBO) или обязывающее (BO). Необязывающее — это «пока намерение», от него можно отказаться. Обязывающее — это уже обещание, за отказ от которого могут быть последствия |  |
| **NCI** | Non-Controlling Interest | Доли меньшинства: часть дочерней компании, которая принадлежит другим владельцам, а не материнской компании. Например, материнская компания владеет 80% дочерней, а остальные 20% — это NCI |  |
| **NDA** | Non-Disclosure Agreement | Соглашение о конфиденциальности: стороны обещают не раскрывать полученные сведения. Его подписывают до того, как покупатель увидит внутренние данные компании |  |
| **Net Debt** |  | Чистый долг = Долг − Денежные средства. Если у тебя долг 100 и 30 на счёте, то чистый долг равен 70: на столько ты реально должен | <code>Net Debt = Долг − Деньги и эквиваленты</code><br><span class="fx">где: Долг — кредиты и облигации. Деньги вычитаем, потому что их можно использовать для погашения</span> |
| **Net Debt / EBITDA** | Чистый долг к EBITDA | За сколько лет компания расплатилась бы с долгом, если бы вся EBITDA шла на долг. Главная мера долговой нагрузки. | <code>ND/EBITDA = (Долг − Деньги) / EBITDA</code> |
| **Net margin** | Чистая маржа | Какая доля выручки доходит до чистой прибыли. | <code>Net margin = Чистая прибыль / Выручка</code> |
| **Netback** | Нетбэк | Цена на рынке сбыта минус все расходы на доставку. Сколько реально остаётся производителю на заводе. |  |
| **NFT** | Non-Fungible Token | Уникальный токен, подтверждающий владение конкретным цифровым объектом. Не взаимозаменяем. |  |
| **NIM** | Net Interest Margin | Чистая процентная маржа банка: «наценка» банка на разнице между ставками по кредитам и по депозитам. Банк платит вкладчикам 8%, берёт с заёмщиков 12%, и разница в 4% — его маржа | <code>NIM = (Процентные доходы − Процентные расходы) / Активы, приносящие доход</code><br><span class="fx">где: Чистая процентная маржа банка: сколько он зарабатывает на разнице между ставками по кредитам и депозитам</span> |
| **NOI** | Net Operating Income | Чистый операционный доход объекта: аренда минус расходы на содержание, без процентов и амортизации. |  |
| **Non-recourse** | Без регресса | Кредит, который проект гасит только за счёт своих денег. Если проект не выручил, банк не требует остальное с владельцев. |  |
| **NOPAT** | Net Operating Profit After Tax | Операционная прибыль после налога: EBIT × (1 − t). Здесь t — налоговая ставка. Показывает, сколько останется от прибыли основной работы после уплаты налога, если бы долга не было | <code>NOPAT = EBIT × (1 − t)</code><br><span class="fx">где: EBIT — операционная прибыль. t — ставка налога. Прибыль после налога, но без учёта долга</span> |
| **NPL** | Non-Performing Loans | Проблемные кредиты: те, по которым заёмщик перестал платить. Обычно так называют кредиты с просрочкой больше 90 дней | <code>NPL ratio = Просроченные кредиты (90+ дней) / Кредитный портфель</code><br><span class="fx">где: Доля кредитов, по которым платежи просрочены более 90 дней</span> |
| **NPV** | Net Present Value | Чистая приведённая стоимость: сегодняшняя стоимость будущих денег минус вложения. Если NPV больше нуля, проект приносит больше, чем стоит, и в него стоит вкладываться | <code>NPV = Σ CF<sub>t</sub> / (1+r)<sup>t</sup> − I<sub>0</sub></code><br><span class="fx">где: CF<sub>t</sub> — поток года t. r — ставка дисконтирования. I<sub>0</sub> — начальные вложения. NPV>0 значит проект выгоден</span> |
| **NSFR** | Net Stable Funding Ratio | Достаточно ли у банка устойчивых источников денег (долгие вклады, капитал) относительно долгих активов. Не ниже 100%. |  |
| **NWC** | Net Working Capital | Чистый оборотный капитал: деньги, которые «застряли» в повседневной работе (запасы и долги клиентов минус долги перед поставщиками). Это деньги, которыми компания «кредитует» собственный бизнес | <code>NWC = Дебиторка + Запасы − Кредиторка</code><br><span class="fx">где: Оборотные операционные активы минус операционные обязательства. Рост NWC «замораживает» деньги</span> |
| **NWC peg** | Целевой оборотный капитал | Уровень NWC, зафиксированный в договоре сделки: отклонение на дату закрытия меняет цену. | |
| **OAS** | Option-Adjusted Spread | Спред облигации с учётом встроенных опционов (например, права досрочного погашения). |  |
| **Off-balance sheet** | Внебалансовые статьи | Обязательства или активы, которых нет в самом балансе, но они влияют на компанию: гарантии, часть аренды, SPV. |  |
| **Offtake** | Договор на закупку продукции | Покупатель обещает забирать продукцию проекта по оговорённой цене. Банки требуют его для кредита. |  |
| **OID** | Original issue discount | Скидка к номиналу при выдаче долга. Добавляет доходность кредитору. | |
| **Operating income** | Операционная прибыль | То же, что EBIT: прибыль от основной деятельности до процентов и налогов. |  |
| **Operating lease** | Операционная аренда | Аренда, при которой актив возвращают владельцу. По старым правилам платежи шли в расходы; по IFRS 16 почти любая аренда стала долгом. |  |
| **Operating leverage** | Операционный рычаг | Чем больше у бизнеса постоянных расходов, тем сильнее прибыль растёт при росте выручки и тем сильнее падает при снижении. | <code>DOL = Маржинальный доход / EBIT</code> |
| **Operating margin** | Операционная маржа | Доля выручки, которая остаётся после всех операционных расходов, до процентов и налогов. | <code>Operating margin = EBIT / Выручка</code> |
| **OPEX** | Operating Expenses | Операционные расходы: траты на повседневную работу. Зарплаты, аренда, электричество, реклама | <code>OPEX = SG&A + R&D + Прочие операционные расходы</code><br><span class="fx">где: Текущие расходы на ведение бизнеса, без капитальных затрат</span> |
| **Option premium** | Премия по опциону | Цена самого опциона: деньги, которые покупатель платит продавцу за право. |  |
| **Order book** | Книга заявок (стакан) | Список всех заявок на покупку и продажу с ценами и объёмами. |  |
| **OTC** | Over-the-counter | Внебиржевой рынок: стороны договариваются напрямую, без общего стакана. |  |
| **Output gap** | Разрыв выпуска | Разница между фактическим ВВП и тем, что экономика может выдать без перегрева. |  |
| **Oversubscription** | Переподписка | Заявок на IPO больше, чем бумаг. Бумаги делят между инвесторами пропорционально. |  |
| **P/B** | Price to Book | Капитализация / балансовый собственный капитал. Главный мультипликатор для банков. Показывает, во сколько раз рынок оценивает компанию дороже, чем стоят её собственные деньги по балансу | <code>P/B = Капитализация / Балансовый капитал</code><br><span class="fx">где: Балансовый капитал — активы минус обязательства. P/B<1 значит, что рынок оценивает компанию ниже книжной стоимости</span> |
| **P/E** | Price to Earnings | Капитализация / чистая прибыль (= цена / EPS). Показывает, за сколько лет прибыли окупится покупка компании. Капитализация — это цена всех акций компании на бирже. P/E равно 10: цена в десять раз больше годовой прибыли | <code>P/E = Цена акции / EPS = Капитализация / Чистая прибыль</code><br><span class="fx">где: Сколько лет прибыли содержится в цене. EPS — прибыль на акцию</span> |
| **P/FFO** |  | Цена к денежному потоку от операций, мультипликатор для REIT и недвижимости. | <code>P/FFO = Капитализация / FFO</code> |
| **P/S** | Price to Sales | Капитализация / выручка. Подходит для убыточных и быстрорастущих компаний. Выручка — все деньги от продаж, до вычета расходов. Прибыли у таких компаний ещё нет, поэтому сравнивают по выручке | <code>P/S = Капитализация / Выручка</code><br><span class="fx">где: Во сколько раз цена компании больше годовой выручки</span> |
| **Par / Premium / Discount** |  | Цена облигации: равна номиналу (par), выше (premium) или ниже (discount). |  |
| **Payback** |  | Срок окупаемости: за сколько времени вложения вернутся. Потратил 100 и получаешь по 25 в год: окупишься за 4 года | <code>Payback = Инвестиции / Годовой денежный поток</code><br><span class="fx">где: При равных потоках. Показывает, за сколько лет вложения вернутся (без учёта дисконтирования)</span> |
| **Payout ratio** | Коэффициент выплат | Какую часть чистой прибыли компания отдаёт в виде дивидендов. | <code>Payout = Дивиденды / Чистая прибыль</code> |
| **PD** | Probability of Default | Вероятность того, что заёмщик не вернёт долг за период. |  |
| **PE (Private Equity)** |  | Фонды прямых инвестиций: они покупают компании, чтобы развить их и потом продать дороже. Похоже на покупку старой квартиры, ремонт и перепродажу, но с целыми компаниями |  |
| **Pecking order** | Иерархия источников | Компании сначала используют собственную прибыль, потом долг, и только в последнюю очередь выпускают акции. |  |
| **PEG** | P/E to Growth | P/E, делённый на темп роста EPS. Помогает понять, не переплачиваешь ли за быстрый рост. Меньше — лучше | <code>PEG = P/E / Темп роста EPS (в %)</code><br><span class="fx">где: P/E скорректирован на рост прибыли. Около 1 — справедливо, ниже — дёшево</span> |
| **Penny stock** | «Пенни-сток» | Дешёвая акция малой компании. Ликвидность низкая, цена скачет, мошенничество встречается чаще. |  |
| **Perpetual bond** | Вечная облигация | Облигация без срока погашения: проценты платят бесконечно. |  |
| **Phillips curve** | Кривая Филлипса | Зависимость между безработицей и инфляцией: чем ниже безработица, тем выше инфляция. |  |
| **PI** | Profitability Index | Индекс прибыльности: PV потоков / инвестиции. PV — сегодняшняя стоимость будущих денег. Если индекс больше 1, проект окупается и приносит прибыль | <code>PI = PV будущих потоков / Начальные инвестиции</code><br><span class="fx">где: PV — приведённая стоимость потоков. PI>1 значит проект выгоден. Нужен при ограниченном бюджете</span> |
| **PIK** | Payment-in-Kind | Проценты, которые не выплачивают, а прибавляют к сумме долга. Сейчас платить легче, но долг растёт: на следующий год проценты начислят уже на большую сумму |  |
| **Pitchbook** |  | Презентация банка для клиента: идея сделки, оценка, аналоги. Так банк «продаёт» клиенту свою идею и показывает, почему сделка выгодна |  |
| **PMI** | Purchasing Managers' Index | Опрос менеджеров по закупкам. Выше 50 — деловая активность растёт, ниже — падает. |  |
| **Poison pill** | Shareholder rights plan | Защита цели от поглощения: если покупатель набрал акций больше порога, остальные акционеры получают право купить акции со скидкой. Доля покупателя размывается, и враждебная покупка теряет смысл. «Ядовитая таблетка» |  |
| **PP&E** | Основные средства | Здания, станки, оборудование, транспорт: всё, что служит больше года и не продаётся. |  |
| **PPA** | Power Purchase Agreement | Долгосрочный договор на покупку электроэнергии по фиксированной цене. Гарантирует выручку проекту. |  |
| **Pre-money / Post-money** |  | Оценка компании до вложения инвестора и после. После = До + Сумма инвестиции. | <code>Post-money = Pre-money + Инвестиция</code><br><span class="fx">где: Доля инвестора = Инвестиция / Post-money.</span> |
| **Precedent transactions** |  | Сделки-аналоги: мультипликаторы, по которым прошли прошлые сделки M&A. Как узнать цену квартиры по тому, за сколько недавно продали похожие в этом доме | <code>Цена = Метрика цели × Мультипликатор прошлых сделок</code><br><span class="fx">где: Похоже на Comps, но мультипликаторы взяты из реальных сделок M&A (включают премию за контроль)</span> |
| **Preferred return** | Приоритетная доходность | Минимальная доходность, которую фонд должен принести инвесторам, прежде чем управляющий возьмёт свой carry. |  |
| **Preferred stock** | Привилегированные акции | Акции, по которым дивиденд обычно фиксирован и платится раньше, чем по обычным, но права голоса, как правило, нет. |  |
| **Primary / Secondary market** | Первичный / вторичный рынок | На первичном бумаги продаёт сам эмитент (деньги идут компании). На вторичном инвесторы продают их друг другу. |  |
| **Prospectus** | Проспект эмиссии | Документ с описанием компании и рисков, который выдают инвесторам перед размещением. |  |
| **Provision** | Резерв (оценочное обязательство) | Расход, который компания записывает заранее, потому что почти уверена, что заплатит: например, по судебному иску. |  |
| **Proxy fight** | Борьба за голоса | Группа акционеров собирает голоса других акционеров, чтобы сменить совет директоров или отклонить сделку. |  |
| **Purchasing power parity** | Паритет покупательной способности | Идея, что одна и та же корзина должна стоить одинаково в разных странах по обменному курсу. Если не стоит, валюта недо- или переоценена. |  |
| **Put option** | Опцион пут | Право, но не обязанность продать актив по цене страйк. Выигрыш при падении цены, поэтому его используют как страховку. | <code>Выплата = max(K − S; 0)</code> |
| **QE / QT** | Количественное смягчение / ужесточение | QE — центробанк печатает деньги и покупает бумаги, чтобы снизить ставки. QT — наоборот, сокращает баланс. |  |
| **Quick ratio** | Коэффициент быстрой ликвидности | То же, но без запасов: их не всегда быстро продать. | <code>Quick ratio = (Оборотные активы − Запасы) / Краткосрочные обязательства</code> |
| **Quiet period** | Период тишины | Время перед и после IPO, когда компания и банки не вправе делать оптимистичные публичные заявления. |  |
| **RAB** | Regulatory Asset Base | Регулируемая база активов: стоимость имущества (сетей, инфраструктуры), от которой государство считает допустимую прибыль. Например, у электросетей тариф устанавливает государство, чтобы владелец получал разумную доходность от стоимости сетей | <code>Выручка = RAB × Норма доходности + Амортизация + Расходы</code><br><span class="fx">где: RAB — регулируемая база активов. Регулятор разрешает получать доход на эту базу</span> |
| **Real options** | Реальные опционы | Идея, что у менеджмента есть право выбрать: расширить, отложить или закрыть проект. Это право имеет цену, которую обычный DCF не видит. |  |
| **Real vs nominal** | Реальный и номинальный | Номинальное значение считают в текущих деньгах. Реальное очищают от инфляции. | <code>Реальная ставка ≈ Номинальная − Инфляция</code> |
| **Receivables turnover** | Оборачиваемость дебиторки | Сколько раз за год компания собирает свою дебиторку. | <code>Receivables turnover = Выручка / Средняя дебиторка</code> |
| **Recession** | Рецессия | Спад экономики, обычно два квартала подряд падения ВВП. |  |
| **Recovery rate** |  | Доля номинала долга, которую кредитор вернёт при дефолте. Если из долга 100 вернули 40, recovery rate равен 40% | <code>Recovery = Возврат при дефолте / Номинал долга</code><br><span class="fx">где: Доля долга, которую удалось вернуть</span> |
| **Reinsurance** | Перестрахование | Страховая передаёт часть риска другой страховой. Страховка для страховщика. |  |
| **REIT** | Real Estate Investment Trust | Компания, владеющая недвижимостью и обязанная раздавать большую часть дохода. Покупаешь акцию вместо квартиры. |  |
| **Repo** | Репо | Сделка, где продают бумаги и обязуются выкупить их обратно позже по более высокой цене. По сути краткосрочный кредит под залог. |  |
| **Reserve currency** | Резервная валюта | Валюта, в которой центробанки держат запасы. Главные: доллар, евро, юань. |  |
| **Restructuring** | Реструктуризация долга | Изменение условий: удлинить срок, снизить ставку, списать часть. Должник получает облегчение, кредитор надеется вернуть хоть что-то. |  |
| **Retained earnings** | Нераспределённая прибыль | Прибыль, накопленная за все годы, которую не выплатили акционерам, а оставили в компании. | <code>Нераспр. прибыль (конец) = Нераспр. прибыль (начало) + Чистая прибыль − Дивиденды</code> |
| **Retention ratio** | Коэффициент удержания | Какая часть прибыли остаётся в компании. Дополняет payout ratio до 100%. | <code>Retention = 1 − Payout</code> |
| **Revenue recognition** | Признание выручки | Правило, когда именно продажу можно записать в выручку. По IFRS 15 это момент, когда клиент получил контроль над товаром или услугой. |  |
| **Reverse merger** | Обратное слияние | Частная компания выходит на биржу, сливаясь с уже торгуемой «пустой» компанией. Быстрее и дешевле, чем IPO. |  |
| **Reverse split** | Консолидация акций | Несколько акций объединяют в одну: цена растёт, число акций падает. Стоимость компании не меняется. |  |
| **Revolver** | Револьверная кредитная линия | Кредитная линия: взял, вернул, снова взял в пределах лимита. Закрывает кассовые разрывы. |  |
| **Rf** | Risk-free rate | Безрисковая ставка: доходность вложений, в которых риск практически отсутствует. Обычно это доходность государственных облигаций | <code>Rf ≈ Доходность госбумаг</code><br><span class="fx">где: Берут доходность ОФЗ/Treasuries на срок, близкий к горизонту проекта</span> |
| **RI** | Residual Income | Остаточная прибыль: ЧП − Ke × Капитал (то, что осталось после того, как акционерам заплатили «положенную» доходность). ЧП — чистая прибыль, Ke — доходность, которую ждут акционеры. Если результат положительный, компания зарабатывает больше, чем от неё требуют | <code>RI = Чистая прибыль − Ke × Балансовый капитал</code><br><span class="fx">где: Ke — стоимость собственного капитала. Прибыль сверх требуемой акционерами доходности</span> |
| **Rights issue** | Выпуск акций с правом первоочередного приобретения | Новые акции предлагают сначала текущим акционерам, чтобы их доля не размылась. |  |
| **ROA** | Return on Assets | Чистая прибыль / активы. Для банков нормой считается 1–3%. Показывает, сколько прибыли приносит каждый рубль имущества компании | <code>ROA = Чистая прибыль / Активы</code><br><span class="fx">где: Эффективность использования всех активов</span> |
| **Roadshow** | Роад-шоу | Серия презентаций компании крупным инвесторам перед IPO. Здесь собирают отзывы и определяют цену. |  |
| **ROCE** | Return on Capital Employed | EBIT / (активы − краткосрочные обязательства). Показывает, сколько операционной прибыли приносит весь капитал, работающий в компании | <code>ROCE = EBIT / (Активы − Краткосрочные обязательства)</code><br><span class="fx">где: Доходность капитала, задействованного в бизнесе, до налогов</span> |
| **ROE** | Return on Equity | Чистая прибыль / собственный капитал. Показывает доходность денег акционеров. Вложили 100, прибыль 15: ROE равен 15% | <code>ROE = Чистая прибыль / Собственный капитал</code><br><span class="fx">где: Сколько прибыли на рубль капитала акционеров</span> |
| **ROIC** | Return on Invested Capital | NOPAT / инвестированный капитал. Если ROIC > WACC, компания создаёт стоимость. Проще говоря, если бизнес зарабатывает на вложенные деньги больше, чем стоят эти деньги, он выгоден | <code>ROIC = NOPAT / (Долг + Капитал − Деньги)</code><br><span class="fx">где: NOPAT — операционная прибыль после налога. В знаменателе — инвестированный капитал</span> |
| **Roll-up** | Консолидация рынка | Стратегия: купить много мелких компаний одной отрасли и объединить. Выигрыш — в масштабе и в повышении оценки. |  |
| **Run-rate** |  | Годовой показатель, который получают, умножив результат последнего периода (квартал × 4). Например, квартальная выручка 25 даёт run-rate 100 в год. Это грубая оценка «если так пойдёт и дальше» | <code>Run-rate = Показатель за период × (12 / Месяцев в периоде)</code><br><span class="fx">где: Например, выручка за месяц × 12 даёт годовой run-rate</span> |
| **Runway** | Запас хода | На сколько месяцев хватит денег при текущем burn rate. | <code>Runway = Деньги на счёте / Burn</code> |
| **RUONIA** |  | Российская индикативная ставка овернайт. Привязывают к ней плавающие облигации и кредиты. |  |
| **RWA** | Risk-Weighted Assets | Активы банка, взвешенные на риск (чем рискованнее актив, тем больше вес). На них делят капитал при расчёте коэффициентов капитала. Кредит надёжному заёмщику «весит» меньше, чем рискованному | <code>RWA = Σ Актив<sub>i</sub> × Вес риска<sub>i</sub></code><br><span class="fx">где: Каждый актив умножается на вес риска (например, госбумаги 0%, корпоративные кредиты 100%)</span> |
| **SAFE** | Simple Agreement for Future Equity | Договор, по которому инвестор отдаёт деньги сейчас, а акции получит позже, в следующем раунде, по скидке. |  |
| **Scenario analysis** | Сценарный анализ | Расчёт модели в нескольких сценариях: базовый, оптимистичный, пессимистичный. Показывает вилку возможных результатов. |  |
| **Second lien** | Второй залог | Долг, обеспеченный тем же залогом, что и старший, но с очередью после него. |  |
| **Secondary buyout** | Вторичный выкуп | Один фонд прямого инвестирования продаёт компанию другому фонду. |  |
| **Securitization** | Секьюритизация | Много однотипных кредитов собирают в пул и продают инвесторам в виде бумаг. Платежи заёмщиков идут держателям. |  |
| **Security market line** | Линия рынка ценных бумаг | График CAPM: чем выше бета, тем выше требуемая доходность. |  |
| **Seed** | Посевной раунд | Самый ранний раунд: деньги на проверку идеи и первый продукт. |  |
| **Sell-side / Buy-side** |  | Консультирование продавца (sell-side) или покупателя (buy-side) в сделке; также так называют брокеров (sell-side) и фонды (buy-side). Sell-side продаёт услуги и идеи, buy-side покупает ценные бумаги |  |
| **Senior debt** | Старший долг | Долг, который при банкротстве возвращают первым. Самый дешёвый и самый защищённый. |  |
| **Sensitivity analysis** | Анализ чувствительности | Таблица, где меняют одну-две вводные (например, WACC и g) и смотрят, как меняется оценка. |  |
| **Series A / B / C** |  | Последовательные раунды: A — масштабирование уже работающей идеи, B — рост, C и дальше — выход на большой рынок или подготовка к IPO. |  |
| **Settlement** | Расчёты по сделке | Обмен деньгами и бумагами. T+1 означает «на следующий рабочий день после сделки». |  |
| **SG&A** | Selling, General & Administrative | Коммерческие и управленческие расходы: на продажи и на содержание офиса и управления. Например, реклама, зарплата менеджеров и бухгалтеров |  |
| **Share / Stock** | Акция | Ценная бумага, дающая долю в компании и право на часть прибыли (дивиденды). |  |
| **Sharpe ratio** | Коэффициент Шарпа | Сколько избыточной доходности получено на единицу общего риска. Чем выше, тем лучше. | <code>Sharpe = (Rp − Rf) / σp</code><br><span class="fx">где: Rp — доходность портфеля. Rf — безрисковая ставка. σp — волатильность портфеля.</span> |
| **Short selling** | Короткая продажа | Берут бумагу в долг, продают, а потом выкупают дешевле и возвращают. Заработок при падении цены. Убыток при росте не ограничен. |  |
| **Short squeeze** | Шорт-сквиз | Цена растёт, шортисты вынуждены закрываться покупкой, что толкает цену ещё выше. |  |
| **Size premium** | Премия за размер | Добавка к ставке для малых компаний: считается, что они рискованнее больших. |  |
| **Slippage** | Проскальзывание | Разница между ожидаемой ценой сделки и реальной, когда заявка исполняется по частям по худшим ценам. |  |
| **Smart contract** | Смарт-контракт | Программа на блокчейне, которая сама исполняет условия, без посредника. |  |
| **SOFR** | Secured Overnight Financing Rate | Американская ставка овернайт под залог гособлигаций. Заменила LIBOR в долларовых кредитах. |  |
| **Sortino ratio** | Коэффициент Сортино | Как Шарп, но учитывает только риск падения: рост цен не считается плохим. |  |
| **SOTP** | Sum of the Parts | Оценка по частям: каждую часть бизнеса оценивают отдельно и складывают. Как оценить дом, оценив отдельно каждую квартиру | <code>Стоимость = Σ (Метрика<sub>i</sub> × Мультипликатор<sub>i</sub>)</code><br><span class="fx">где: Каждый бизнес-сегмент оценивается своим мультипликатором, результаты суммируются</span> |
| **SPA** | Share Purchase Agreement | Договор купли-продажи акций. Главный документ сделки, в нём цена, условия и гарантии |  |
| **SPAC** | Special Purpose Acquisition Company | Пустая компания, которая выходит на биржу, собирает деньги и потом ищет, какую компанию купить. Её называют «компанией с чистым чеком». |  |
| **Spin-off** | Спин-офф | Подразделение выделяют в отдельную компанию, а акции раздают текущим акционерам бесплатно. |  |
| **SPO** | Secondary Public Offering | Повторная продажа акций компании, которая уже торгуется на бирже. Например, компания хочет собрать ещё денег и выпускает дополнительные акции |  |
| **Spot** | Спот | Цена и сделка «на сегодня» с быстрой поставкой, в отличие от фьючерса. |  |
| **SPV** | Special Purpose Vehicle | Отдельная компания, созданная под одну цель: проект, секьюритизацию, сделку. Изолирует риск от основной компании. |  |
| **Squeeze-out** |  | Принудительный выкуп оставшихся акций покупателем с долей более 95%. Мелкие владельцы обязаны продать свои акции, чтобы не оставалось «хвостика» |  |
| **Stagflation** | Стагфляция | Одновременно высокая инфляция и застой в экономике с безработицей. Центральному банку трудно действовать. |  |
| **Staking** | Стейкинг | Блокируешь монеты, помогаешь работе сети и получаешь вознаграждение. |  |
| **Standard deviation** | Стандартное отклонение | Мера разброса доходностей вокруг среднего. В финансах — то же, что волатильность. |  |
| **Stock split** | Сплит акций | Каждую акцию дробят на несколько. Цена одной падает, но стоимость компании не меняется. |  |
| **Stop-loss** | Стоп-лосс | Заявка, которая автоматически закрывает позицию, если цена дошла до заданного убытка. |  |
| **Strike price** | Цена исполнения (страйк) | Цена, по которой по опциону можно купить или продать актив. |  |
| **Stub period** | Неполный период | Остаток текущего года до даты оценки. Первый год прогноза берут только за эту часть. |  |
| **Subordinated debt** | Субординированный долг | Долг, который возвращают после старшего. Риск выше, ставка выше. У банков может засчитываться в капитал. |  |
| **Sustainable growth rate** | Устойчивый рост | Максимальный рост, который компания может обеспечить без новых акций и без роста долговой нагрузки. | <code>g = ROE × Retention</code> |
| **Swap** | Своп | Договор обменяться денежными потоками. Например, платить фиксированную ставку, а получать плавающую. |  |
| **Synergies** |  | Синергии: дополнительная стоимость, которая появляется от объединения компаний. Например, две компании сливаются и сокращают общие расходы: вместе получается выгоднее, чем по отдельности | <code>Value = PV(экономии затрат + прироста выручки) − Затраты на интеграцию</code><br><span class="fx">где: PV — приведённая стоимость. Эффект от объединения двух компаний</span> |
| **Tag-along** | Право присоединения | Если крупный акционер продаёт долю, миноритарий вправе продать свою на тех же условиях. |  |
| **Take rate** | Комиссия платформы | Какую долю от GMV платформа оставляет себе. | <code>Take rate = Выручка платформы / GMV</code> |
| **TAM / SAM / SOM** | Размеры рынка | Весь возможный рынок / часть, которую можно обслужить / часть, которую реально займёшь. | |
| **Tangible book value** | Материальная балансовая стоимость | Капитал без нематериальных активов и гудвила. Сколько останется владельцам, если продать только «вещи». | <code>Tangible BV = Капитал − Гудвил − Нематер. активы</code> |
| **Taylor rule** | Правило Тейлора | Формула, по которой оценивают подходящую ставку центробанка исходя из инфляции и отклонения ВВП от потенциала. |  |
| **Teaser** |  | Короткое анонимное описание компании, которое рассылают потенциальным покупателям. Название скрыто, нужно лишь, чтобы заинтересовать. Как объявление «продаётся бизнес в сфере…» без адреса |  |
| **Tender offer** |  | Публичное предложение ко всем акционерам: продайте нам свои акции по этой цене. Как объявление «куплю у всех желающих по такой-то цене до такой-то даты» |  |
| **Term Loan A / B** | TLA / TLB | Старший кредит. Кредит A амортизируется (гасится частями) и обычно выдан банками. Кредит B почти не амортизируется и выдан инвесторами. Старший значит, что его возвращают первым. Кредит B дороже, потому что основную сумму отдают в конце |  |
| **Term sheet** | Условия сделки | Короткий документ с главными условиями инвестиции или покупки. Юридически обязывает только частично, но потом по нему пишут договор. |  |
| **Terminal growth** | Темп роста в бесконечности | Постоянный рост денежных потоков после прогноза. Берут не выше долгосрочного роста экономики и инфляции. |  |
| **Theta** | Тета | Сколько стоимости опцион теряет за один день просто от течения времени. |  |
| **Tier 1 / Tier 2** |  | Уровни капитала банка. Tier 1 — самый надёжный (акции, прибыль), Tier 2 — запасной (например, субординированный долг). |  |
| **Time value** | Временна́я стоимость | Часть цены опциона сверх внутренней стоимости: плата за шанс, что цена ещё выгодно сдвинется. К дате экспирации сходит к нулю. | <code>Time value = Премия − Внутренняя стоимость</code> |
| **Token** | Токен | Цифровая единица на блокчейне. Может быть валютой, долей, доступом к сервису. |  |
| **Tracking error** | Ошибка слежения | Насколько сильно доходность портфеля отклоняется от бенчмарка. Для индексного фонда должна быть маленькой. |  |
| **Trade-off theory** | Компромиссная теория | Оптимальный долг находят, сравнивая выгоду от налогового щита и расходы на возможное банкротство. |  |
| **Tranche** | Транш | Часть выпуска или кредита с разным риском и доходом. Старший транш получает деньги первым и платит меньше. |  |
| **Treasury stock** | Выкупленные собственные акции | Акции, которые компания выкупила у рынка. В балансе они вычитаются из капитала и не получают дивидендов. |  |
| **Treynor ratio** | Коэффициент Трейнора | Избыточная доходность на единицу рыночного риска (беты). | <code>Treynor = (Rp − Rf) / β</code> |
| **TSR** | Total Shareholder Return | Полная доходность акционера: рост цены акции + дивиденды. Это всё, что владелец акции заработал: и на подорожании, и на выплатах | <code>TSR = (P<sub>кон</sub> − P<sub>нач</sub> + Дивиденды) / P<sub>нач</sub></code><br><span class="fx">где: P — цена акции в конце и в начале периода. Совокупный доход акционера: рост цены плюс дивиденды</span> |
| **TV** | Terminal Value | Терминальная (постпрогнозная) стоимость: стоимость бизнеса за пределами прогнозного периода. Прогноз обычно делают на 5–10 лет, а компания живёт дальше, и эту «остальную жизнь» оценивают одной суммой | <code>TV = FCF<sub>n</sub> × (1+g) / (WACC − g)</code><br><span class="fx">где: FCF<sub>n</sub> — поток последнего прогнозного года. g — вечный рост. WACC — ставка дисконтирования (модель Гордона)</span> |
| **TVL** | Total Value Locked | Сколько денег лежит в DeFi-протоколе. Показывает его размер. |  |
| **Underwriter** | Андеррайтер | Банк, который организует выпуск бумаг, а иногда гарантирует выкуп непроданной части. |  |
| **Unicorn** | Единорог | Частная компания, оценённая дороже 1 млрд долларов. |  |
| **Unit economics** | Юнит-экономика | Прибыльность одной единицы бизнеса: одного клиента, заказа, магазина. Если на одной единице убыток, рост только увеличивает убытки. |  |
| **Unitranche** | Юнитранш | Один кредит, объединяющий старший и мезонинный долг, с одной ставкой. Любят кредитные фонды. |  |
| **Unlevered beta** | Бета без долга | Бета бизнеса, очищенная от влияния долга. Нужна, чтобы сравнивать компании с разным долгом. | <code>βU = βL / (1 + (1 − t) × D/E)</code> |
| **Urals** | Urals | Российская экспортная нефть. Продаётся со скидкой к Brent. |  |
| **Value investing** | Стоимостное инвестирование | Покупать недооценённые компании: цена ниже, чем должна быть по прибыли и активам. Идея Грэма и Баффетта. |  |
| **VaR** | Value at Risk | Потеря, которую не превысят с заданной вероятностью за период. | <code>VaR = z × σ × Стоимость</code> (z = 1,65 для 95%) |
| **Variance** | Дисперсия | Квадрат стандартного отклонения. Показывает разброс значений. |  |
| **VDR** | Virtual Data Room | Виртуальная комната данных: закрытое онлайн-хранилище документов для due diligence. Покупатели заходят туда и изучают документы, а продавец видит, кто что открывал |  |
| **Vega** | Вега | Насколько изменится цена опциона при росте волатильности на 1 п. п. |  |
| **Venture capital** | Венчурный капитал | Деньги, которые вкладывают в молодые компании с высоким риском ради большого роста. Большинство вложений не окупается, пара — окупает всё. |  |
| **Vesting** | Вестинг | Опционы или акции сотрудник получает постепенно, а не сразу. Обычно срок 4 года и «клифф» в год: уйдёшь раньше — ничего не получишь. |  |
| **Vintage** | Винтаж фонда | Год, когда фонд начал вкладывать. Результаты фондов одного винтажа сравнивают между собой. |  |
| **VIX** | Индекс волатильности | «Индекс страха»: ожидаемая рынком волатильность S&P 500 на 30 дней. Растёт при панике. |  |
| **WACC** | Weighted Average Cost of Capital | Средневзвешенная стоимость капитала: средняя цена всех денег компании, и заёмных, и собственных. Заёмные деньги стоят процента по кредиту, собственные — доходности, которую ждут владельцы. Их усредняют по долям | <code>WACC = E/(D+E) × Ke + D/(D+E) × Kd × (1−t)</code><br><span class="fx">где: E — капитал, D — долг. Ke — стоимость капитала, Kd — стоимость долга, t — налог. Средняя цена всех источников финансирования</span> |
| **Warrant** | Варрант | Право купить акции компании по зафиксированной цене в течение срока. Часто выдают вместе с облигациями. |  |
| **Waterfall** |  | Очерёдность выплат кредиторам и акционерам, когда делят деньги или компания банкротится. «Водопад»: деньги стекают сверху вниз, и нижние получают только то, что осталось после верхних | <code>Выплата = по очереди: долг → преференции → доходы остальных</code><br><span class="fx">где: Распределение денег по приоритету. Следующий уровень получает деньги, только когда предыдущий полностью выплачен</span> |
| **WC peg** |  | Нормальный уровень оборотного капитала, от которого корректируют цену сделки. Если на момент закрытия оборотных денег меньше нормы, цену снижают, если больше — повышают | <code>Корректировка цены = NWC на закрытие − WC peg</code><br><span class="fx">где: WC peg — согласованный уровень оборотного капитала. Недостаток снижает цену, избыток повышает</span> |
| **Weighted average cost** | Средневзвешенная стоимость | Способ учёта запасов: берут среднюю цену всех партий. | <code>Средняя цена = Стоимость всех партий / Количество всех партий</code> |
| **White knight** | «Белый рыцарь» | Дружественный покупатель, которого целевая компания находит, чтобы уйти от враждебного поглощения. |  |
| **Working capital** | Рабочий капитал | То же, что оборотный капитал: деньги, застрявшие в операциях. См. NWC. |  |
| **WTI** | West Texas Intermediate | Американский эталон нефти. Торгуется на бирже в Нью-Йорке. |  |
| **Yield curve inversion** | Инверсия кривой доходности | Короткие ставки выше длинных. Считается признаком будущей рецессии. |  |
| **YTM** | Yield to Maturity | Доходность к погашению: сколько заработает покупатель облигации, если продержит её до конца срока. Выражается в процентах годовых | <code>P = Σ C / (1+YTM)<sup>t</sup> + N / (1+YTM)<sup>n</sup></code><br><span class="fx">где: P — цена облигации. C — купон. N — номинал. n — срок. YTM — ставка, при которой приведённые платежи равны цене. Подбирается итерациями</span> |
| **Z-spread** | Z-спред | Постоянная добавка к безрисковой кривой, при которой облигация стоит как на рынке. Показывает кредитный риск. |  |
| **Zero-coupon bond** | Бескупонная облигация | Купонов нет: покупают дешевле номинала, а при погашении получают номинал целиком. |  |
| **БПИФ** | Биржевой ПИФ | ПИФ, паи которого торгуются на бирже, как ETF. Российский аналог ETF. |  |
| **Дефолт** |  | Неисполнение обязательств по долгу: компания не выплатила купон или не погасила долг. Купон — регулярный процентный платёж по облигации. Проще говоря, должник не заплатил вовремя |  |
| **Дюрация** | Duration | Средневзвешенный срок денежных потоков облигации, мера чувствительности цены к ставке. | <code>ΔP/P ≈ −D_mod × Δy</code> |
| **ИИС** | Индивидуальный инвестиционный счёт | Брокерский счёт с налоговыми льготами для частного инвестора (условия и типы сверять в актуальных правилах). | |
| **КБД** | Кривая бескупонной доходности | Кривая доходности ОФЗ (ЦБ, Мосбиржа): показывает, какую доходность дают госбумаги на разные сроки. Это «эталон» безрисковой ставки для каждого срока, от которого отсчитывают ставки остальных бумаг |  |
| **Квал** | Квалифицированный инвестор | Особый статус, который открывает доступ к сложным инструментам. Его присваивают по критериям ЦБ (размер активов, опыт сделок, образование и др.). Считается, что такой человек лучше понимает риски |  |
| **Квалифицированный инвестор** |  | Инвестор, которому разрешены более рискованные продукты. Нужен достаточный капитал или опыт (условия сверить). |  |
| **Ломбардная ставка** |  | Ставка, по которой ЦБ даёт банкам кредит под залог ценных бумаг. |  |
| **Мосбиржа** | Московская биржа | Главная российская площадка торгов акциями, облигациями, валютой и производными. |  |
| **Н1** | Норматив достаточности капитала | Требование ЦБ к капиталу банков. Банк обязан держать собственных денег не меньше определённой доли от своих рисковых активов, чтобы выдержать потери | <code>Н1 = Капитал банка / RWA</code><br><span class="fx">где: Норматив достаточности капитала ЦБ. Чем выше, тем устойчивее банк</span> |
| **Налог на прибыль** |  | Налог на прибыль организаций. Ставка 20% по общему правилу, с 2025 года 25% (сверить). |  |
| **Налоговый вычет** |  | Сумма, которая уменьшает налогооблагаемый доход или налог. Для инвесторов — вычеты по ИИС (сверить). |  |
| **НДС** | Налог на добавленную стоимость | Налог на продажи. Основная ставка 20% (сверить). Компания платит разницу между НДС с продаж и НДС с закупок. |  |
| **НДФЛ** | Налог на доходы физических лиц | Налог на доходы людей, в том числе от инвестиций. Ставка зависит от размера дохода (условия сверить). |  |
| **НКД** | Накопленный купонный доход | Часть купона, которая набежала с последней выплаты до сегодняшнего дня. Часть купона, накопленная продавцом облигации</span> |
| **НКЦ** | Национальный клиринговый центр | Клиринг и центральный контрагент на Мосбирже: гарантирует исполнение сделок. | |
| **НПФ** | Негосударственный пенсионный фонд | Организация, которая копит и инвестирует пенсионные деньги людей и платит накопленное при выходе на пенсию. |  |
| **НРД** | Национальный расчётный депозитарий | Хранит ценные бумаги и проводит расчёты по сделкам. | |
| **ОФЗ** | Облигации федерального займа | Облигации, которые выпускает государство РФ. Государство берёт у людей и организаций в долг и обещает вернуть с процентами. Считаются самыми надёжными в рублях |  |
| **ОФЗ-ИН** | ОФЗ с индексируемым номиналом | Номинал растёт вместе с инфляцией. Защищает от обесценения. |  |
| **ОФЗ-ПД** | ОФЗ с постоянным доходом | Обычные ОФЗ с фиксированным купоном. |  |
| **ОФЗ-ПК** | ОФЗ с переменным купоном | Купон привязан к ставке денежного рынка (RUONIA), поэтому растёт вместе со ставками. |  |
| **ПДН** | Показатель долговой нагрузки | Какая доля доходов заёмщика уходит на платежи по кредитам (его регулирует ЦБ). Если человек зарабатывает 100 и платит по кредитам 40, ПДН равен 40%. | **ПИФ** | Паевой инвестиционный фонд | Российский паевой фонд. Покупаешь пай, управляющая компания вкладывает деньги в бумаги. Взимает комиссию за управление. |  |
| **РСБУ** | Российские стандарты бухучёта | Российские правила, по которым компании ведут бухгалтерский учёт и составляют отчётность. Нужны для налогов и отчётов внутри страны, а МСФО — для сравнения с зарубежными компаниями |  |
| **Спред (bid-ask)** | Разница котировок | Разница между лучшей ценой продажи и покупки: скрытая стоимость сделки. | <code>Spread = Ask − Bid</code> |
| **ФНБ** | Фонд национального благосостояния | Резервный фонд государства РФ: деньги от нефтегазовых доходов, которые копят на трудные времена и пенсионные нужды. |  |
