# Глоссарий
short: Термины и сокращения от A до Я. В алфавитном порядке: сначала латиница, потом кириллица. У терминов с расчётом есть формула и расшифровка обозначений

| Термин | Расшифровка | Значение | Формула и расшифровка |
|---|---|---|---|
| **10-K / 10-Q / 8-K** |  | Американские отчёты: годовой, квартальный и о существенном событии. Публикуются на сайте SEC (EDGAR). |  |
| **2P reserves** | Запасы 2P | Доказанные и вероятные запасы: те, что можно извлечь с вероятностью не ниже 50%. |  |
| **ABB** | Accelerated Bookbuilding | Быстрая (за 1–2 дня) продажа крупного пакета акций крупным инвесторам, например фондам и банкам. Банк быстро собирает заявки и продаёт всё оптом, как распродажа партии товара одному-двум крупным покупателям |  |
| **ABS** | Asset-Backed Security | Бумага, обеспеченная пулом других кредитов или платежей (автокредиты, потребкредиты, лизинг). |  |
| **Absolute priority rule** | Правило абсолютного приоритета | Младшие кредиторы и акционеры не получают ничего, пока старшие не получили всё. |  |
| **Accretion / Dilution** |  | Насколько вырастет или упадёт прибыль на акцию (EPS) у покупателя после сделки. «Accretion» — прибавка, «dilution» — разбавление. Если прибыль на акцию выросла, сделка выгодна акционерам покупателя | <code>EPS<sub>после</sub> − EPS<sub>до</sub></code><br><span class="fx">где: EPS — прибыль на акцию. Если после сделки EPS выше, это accretion (прирост), если ниже, dilution (размытие)</span> |
| **Accrual accounting** | Метод начисления | Доходы и расходы записывают, когда они случились, а не когда пришли или ушли деньги. Продал товар в долг — выручка есть сразу, хотя денег ещё нет. |  |
| **Accrued interest** |  | См. НКД | <code>Accrued = Купон × Дней с выплаты / Дней в периоде</code><br><span class="fx">где: То же, что НКД</span> |
| **Acquiring** | Эквайринг | Услуга банка магазину: принимать оплату картами. Банк берёт комиссию с каждой покупки. |  |
| **Actuary** | Актуарий | Специалист, который считает вероятности страховых событий и резервы. |  |
| **Add-backs** | Корректировки EBITDA | Статьи, которые добавляют к EBITDA, чтобы получить Adjusted EBITDA. Часть нормальна (разовые расходы), часть завышает базу. | Проверяйте детализацию и лимиты в договоре |
| **Add-on** | Добавочная покупка | Покупка небольшой компании, чтобы присоединить её к уже купленной платформе. |  |
| **Adjusted EBITDA** | Скорректированная EBITDA (EBITDA — Earnings Before Interest, Taxes, Depreciation and Amortization) | EBITDA без разовых и нетипичных статей (реструктуризация, судебные издержки). Компании любят «приукрасить», поэтому корректировки надо проверять. |  |
| **ADR / GDR** | Депозитарные расписки (ADR — American Depositary Receipt; GDR — Global Depositary Receipt) | Бумаги, которые торгуются на иностранной бирже и представляют акции российской или другой компании. ADR — на американской, GDR — на других. |  |
| **AFFO** | Adjusted Funds From Operations | FFO за вычетом обязательных вложений в содержание объектов. Лучше показывает, сколько REIT может раздать. |  |
| **Agency problem** | Проблема агента | Интересы менеджеров (агентов) и акционеров (принципалов) не совпадают: менеджер хочет больше бонусов и меньше риска. |  |
| **AISC** | All-in Sustaining Cost | Полная себестоимость унции золота с учётом поддерживающих инвестиций. Стандарт золотодобычи. |  |
| **Alpha** | Альфа | Доходность управляющего сверх той, которую можно было ожидать при его уровне риска. Показывает мастерство. | <code>α = Доходность портфеля − (Rf + β × (Rm − Rf))</code> |
| **Altman Z-score** | Z-модель Альтмана | Формула из пяти коэффициентов, которая предсказывает банкротство. Ниже 1,8 — зона риска. | <code>Z = 1,2×A + 1,4×B + 3,3×C + 0,6×D + 1,0×E</code><br><span class="fx">где: A — NWC/Активы. B — Нераспр. прибыль/Активы. C — EBIT/Активы. D — Капитализация/Обязательства. E — Выручка/Активы.</span> |
| **AML** | Anti-Money Laundering | Правила против отмывания денег. В РФ — закон 115-ФЗ (сверить). |  |
| **Amortization** | Амортизация (нематериальных активов) | То же списание, но для нематериальных вещей: программ, лицензий, патентов. |  |
| **Amortization of goodwill** | Амортизация гудвила | По МСФО гудвил не амортизируют, а проверяют на обесценение. По РСБУ амортизируют 20 лет (сверить). |  |
| **Analyst / Associate / VP / Director / MD** | VP — Vice President; MD — Managing Director | Карьерная лестница инвестбанка снизу вверх. Аналитик — первые 2–3 года после вуза. |  |
| **Anchor tenant** | Якорный арендатор | Крупный арендатор, который приводит трафик в торговый центр: гипермаркет, кинотеатр. |  |
| **Anchoring** | Якорение | Привязка к первому увиденному числу: цена покупки, прошлый максимум. Мешает оценивать трезво. |  |
| **Annuity** | Аннуитет | Ряд одинаковых платежей через равные промежутки: ипотека, аренда, купоны. | <code>PV = C × (1 − (1 + r)^−n) / r</code><br><span class="fx">где: C — платёж за период. r — ставка. n — число платежей.</span> |
| **Anti-dilution** | Защита от размытия | Если следующий раунд проходит дешевле предыдущего, инвестор получает дополнительные акции, чтобы сохранить свою долю. |  |
| **APA** | Asset Purchase Agreement | Договор покупки активов, а не акций. Покупатель берёт только выбранное имущество и не наследует все долги. |  |
| **APT** | Arbitrage Pricing Theory | Теория арбитражного ценообразования: доходность определяется несколькими факторами (инфляция, ВВП и т. п.), а не одной бетой. |  |
| **APV** | Adjusted Present Value | Сначала считают стоимость компании так, будто долга нет, потом прибавляют сегодняшнюю стоимость (PV) налоговой экономии от процентов по долгу (налогового щита). Проценты по кредиту уменьшают налог, и эту выгоду учитывают отдельной строкой | <code>APV = NPV<sub>без долга</sub> + PV(налоговый щит)</code><br><span class="fx">где: NPV без долга — стоимость бизнеса, будто долгов нет. PV налогового щита — приведённая выгода от вычета процентов из налога</span> |
| **Arbitrage** | Арбитраж | Покупка и продажа одного и того же актива на разных рынках, чтобы без риска забрать разницу цен. Такие возможности быстро исчезают. |  |
| **ARPU** | Average Revenue Per User | Сколько выручки в среднем приносит один пользователь (телеком, интернет). Если оператор за месяц получил 1000 рублей от 10 абонентов, ARPU равен 100 рублей | <code>ARPU = Выручка / Число пользователей</code><br><span class="fx">где: Выручка за период, делённая на среднее число пользователей за тот же период</span> |
| **ARPU (телеком)** | Средняя выручка на абонента (ARPU — Average Revenue Per User) | Выручка за месяц, делённая на число абонентов. Главная метрика телекома. |  |
| **ARR** | Annual Recurring Revenue | Выручка за год, которая повторяется из года в год, например по подписке (SaaS — программы по подписке). Похоже на абонемент в спортзал: деньги приходят регулярно, а не разово | <code>ARR = MRR × 12</code><br><span class="fx">где: MRR — ежемесячная повторяющаяся выручка по подпискам. Умножаем на 12 месяцев</span> |
| **Asset management** | Управление активами | Бизнес по управлению чужими деньгами за комиссию: ПИФы, ДУ, пенсионные деньги. |  |
| **Asset turnover** | Оборачиваемость активов | Сколько рублей выручки приносит каждый рубль активов. | <code>Asset turnover = Выручка / Средние активы</code> |
| **Audit opinion** | Аудиторское заключение | Вывод аудитора: отчётность достоверна (чистое заключение), с оговоркой, отрицательное или отказ. |  |
| **AUM** | Assets Under Management | Сколько денег находится под управлением компании. Комиссия считается от AUM. |  |
| **Backlog** | Портфель заказов | Подписанные, но ещё не выполненные заказы. Показывает будущую выручку строителей и машиностроителей. |  |
| **Backwardation** | Бэквордация | Фьючерсы на более поздний срок дешевле ближайших. Означает дефицит товара сейчас. |  |
| **Balance check** | Проверка баланса | Строка в модели: активы минус обязательства минус капитал. Должна быть ноль во всех годах. |  |
| **Balance sheet** | Баланс | Снимок компании на одну дату: что у неё есть (активы) и откуда это взялось (долг и капитал). | <code>Активы = Обязательства + Капитал</code><br><span class="fx">где: Активы — всё, чем владеет компания. Обязательства — всё, что она должна. Капитал — доля владельцев.</span> |
| **Balloon payment** | Баллонный платёж | Последний платёж по кредиту намного больше предыдущих. До него платят мало. |  |
| **Bankruptcy** | Банкротство | Состояние, когда должник не может платить по долгам. Имущество продают, деньги делят по очереди. |  |
| **Base / Bonus** |  | Оклад и бонус. В инвестбанке бонус может быть равен окладу и зависит от года. |  |
| **Basel III** | Базель III | Международные правила для банков: сколько капитала и ликвидности держать, чтобы пережить кризис. |  |
| **Basis** | База для сравнения | Эффект низкой базы: рост выглядит большим, потому что в прошлом периоде было мало. |  |
| **Basis point (б.п.)** |  | Базисный пункт = 0,01%. 50 б.п. = 0,5 п.п. (п.п. — процентный пункт). Это очень мелкая единица, чтобы точно говорить о небольших изменениях ставок | <code>1 б.п. = 0,01% = 0,0001</code><br><span class="fx">где: Сотая доля процента. Рост ставки с 10% до 10,5% — это +50 б.п.</span> |
| **Behavioral finance** | Поведенческие финансы | Направление о том, как люди реально принимают финансовые решения: с ошибками, страхом и жадностью, а не как «рациональные агенты». |  |
| **Benchmark** | Бенчмарк | Индекс, с которым сравнивают результат управляющего. Обыграл индекс — молодец. |  |
| **Beneficial owner** | Бенефициарный владелец | Человек, который в итоге владеет компанией или контролирует её, даже через цепочку фирм. |  |
| **Beneish M-score** | Модель Бениша | Формула из восьми коэффициентов, которая оценивает вероятность манипуляций с отчётностью. |  |
| **Beta (β)** |  | Показывает, насколько сильно акция реагирует на движения рынка. Бета 1 значит «двигается как рынок», больше 1 — «качается сильнее», меньше 1 — «спокойнее» | <code>β = Cov(R<sub>акции</sub>, R<sub>рынка</sub>) / Var(R<sub>рынка</sub>)</code><br><span class="fx">где: Cov — ковариация доходностей акции и рынка (двигаются вместе или нет). Var — дисперсия доходности рынка. β>1 значит акция колеблется сильнее рынка</span> |
| **Big Four** | Большая четвёрка | Крупнейшие аудиторские сети: Deloitte, PwC, EY, KPMG. В России работают под новыми брендами: «Деловые решения и технологии», «Технологии Доверия», Б1, Kept. |  |
| **Big Three** | Большая тройка консалтинга | McKinsey, BCG, Bain. Ушли из России в 2022 году, бывшие офисы работают под новыми названиями. |  |
| **Bitcoin** | Биткоин | Первая и крупнейшая криптовалюта. Ограниченное предложение: 21 млн монет. |  |
| **Black swan** | Чёрный лебедь | Непредсказуемое событие с огромными последствиями. Термин Талеба. |  |
| **Black-Scholes** | Модель Блэка — Шоулза | Формула справедливой цены европейского опциона. Использует цену актива, страйк, срок, ставку и волатильность. |  |
| **Bloomberg terminal** | Терминал Блумберг | Главная платформа данных для финансистов. Дорогая. Команды: DES, FA, GP, WACC. |  |
| **Blue chip** | «Голубые фишки» | Акции крупнейших стабильных компаний с долгой историей. В России: Сбербанк, Газпром, Лукойл. |  |
| **BNPL** | Buy Now Pay Later | Оплата частями без процентов: сервис платит магазину сразу, покупатель платит сервису по частям. |  |
| **Board of directors** | Совет директоров | Орган, который назначает менеджмент, одобряет стратегию и крупные сделки от имени акционеров. |  |
| **Bond** | Облигация | Долговая бумага: ты одалживаешь деньги эмитенту, он платит проценты (купоны) и в конце возвращает номинал. |  |
| **Book building** | Сбор заявок | Сбор заявок инвесторов по цене и количеству, по которому определяют цену и распределение акций при размещении. | |
| **Book value** | Балансовая стоимость | Сколько стоит актив или вся компания по записям в балансе. | <code>Book value of equity = Активы − Обязательства</code> |
| **Book-to-bill** | Заказы к выручке | Новые заказы за период к выручке за него. Выше 1 — портфель растёт. |  |
| **Bookrunner** |  | Банк, который собирает заявки инвесторов при размещении акций или облигаций. Он ведёт «книгу заявок»: список, кто сколько готов купить и по какой цене |  |
| **Boutique** | Бутик | Небольшой инвестбанк, занимающийся только консультированием по M&A: Lazard, Evercore, Rothschild. |  |
| **Brain teaser** |  | Задача на сообразительность на собеседовании: сколько мячей влезет в автобус. |  |
| **Break fee** | Termination fee | Неустойка, которую платит цель, если выходит из сделки ради другого предложения. Неустойка — это штраф за срыв договорённости. Цель — компания, которую покупают |  |
| **Break-even** | Точка безубыточности | Объём продаж, при котором прибыль равна нулю: маржинальный доход как раз покрыл постоянные расходы. | <code>Break-even (штук) = Постоянные расходы / (Цена − Переменные расходы на штуку)</code> |
| **Brent** | Brent | Эталонный сорт нефти для мировых цен. Его цену берут за основу при оценке других сортов. |  |
| **Bridge** | Мост | Разложение изменения показателя на причины: «EBITDA выросла на 10: +15 цена, −3 объём, −2 расходы». |  |
| **Broker** | Брокер | Посредник, через которого частный инвестор торгует на бирже. Берёт комиссию. |  |
| **Bubble** | Пузырь | Цены растут далеко выше справедливой стоимости на ожиданиях дальнейшего роста. Потом лопается. |  |
| **Budget deficit** | Дефицит бюджета | Расходы государства больше доходов. Покрывается займами или резервами. |  |
| **Bulge bracket** |  | Крупнейшие глобальные инвестбанки: Goldman Sachs, Morgan Stanley, JPMorgan, Bank of America, Citi. |  |
| **Bull / Bear market** | Рынок быков / медведей | Бычий рынок — растущий, медвежий — падающий (обычно от пика минус 20% и больше). |  |
| **Bullet repayment** | Погашение разом | Весь основной долг возвращают одним платежом в конце срока, до этого платят только проценты. |  |
| **Burn rate** | Скорость сжигания денег | Сколько денег в месяц компания тратит сверх того, что зарабатывает. Характерно для стартапов. | <code>Burn = Расходы − Выручка (в месяц)</code> |
| **Business judgment rule** | Правило делового решения | Суд не наказывает директора за неудачное, но добросовестное и обоснованное решение. |  |
| **CAC** | Customer Acquisition Cost | Сколько стоит привлечь одного клиента: вся реклама и продажи, делённые на новых клиентов. | <code>CAC = Расходы на маркетинг и продажи / Число новых клиентов</code> |
| **CAGR** | Compound Annual Growth Rate | Средний рост за год с учётом «процента на процент»: (Конец/Начало)^(1/n) − 1. Здесь n — число лет. Это та единая годовая скорость роста, которая из начальной суммы даёт конечную | <code>CAGR = (V<sub>кон</sub> / V<sub>нач</sub>)<sup>1/n</sup> − 1</code><br><span class="fx">где: V<sub>кон</sub> — конечное значение, V<sub>нач</sub> — начальное, n — число лет. Показывает среднегодовой темп роста с учётом сложного процента</span> |
| **Call option** | Опцион колл | Право, но не обязанность купить актив по цене страйк в будущем. Выигрыш при росте цены. | <code>Выплата = max(S − K; 0)</code><br><span class="fx">где: S — цена актива. K — страйк.</span> |
| **Callable bond** | Облигация с правом досрочного погашения | Эмитент может выкупить её раньше срока по заранее оговорённой цене. Он делает это, когда ставки упали. |  |
| **Candlestick** | Японская свеча | Способ рисовать цену: тело показывает открытие и закрытие, тени — максимум и минимум. |  |
| **Cannibalization** | Каннибализация | Новый продукт отбирает продажи у старого продукта той же компании. Это минус в приростных потоках. |  |
| **Cap rate** | Ставка капитализации | Доходность недвижимости: годовой чистый доход, делённый на цену объекта. Чем ниже cap rate, тем дороже объект. | <code>Cap rate = NOI / Цена</code> |
| **Cap table** | Таблица капитализации | Список всех владельцев компании: кому какая доля принадлежит, включая опционы. |  |
| **CAPEX** | Capital Expenditures | Капитальные затраты: траты на покупку и обновление оборудования и других основных средств (ОС). Основные средства — это то, что служит много лет: станки, здания, машины. Например, пекарня покупает новую печь | <code>CAPEX = ΔОС + Амортизация</code><br><span class="fx">где: ΔОС — изменение основных средств за период (конец минус начало). Амортизация добавляется, потому что она уменьшила стоимость ОС без покупок</span> |

| **Carry trade** | Керри-трейд | Занять в валюте с низкой ставкой, вложить в валюту с высокой и заработать разницу. Рискует резким изменением курса. |  |

| **Case interview** | Кейс-интервью | Формат собеседования в консалтинг: решить бизнес-задачу вслух, со структурой и цифрами. |  |

| **Cash-free debt-free** | Без денег и без долга | Цена названа за бизнес как будто без денег и без долга. На закрытии к ней прибавляют деньги и вычитают долг. | <code>Цена за акции = EV + Деньги − Долг ± Корректировка NWC</code> |

| **Crossover rate** | Ставка пересечения | Ставка, при которой NPV двух проектов равны. Выше неё лучше один, ниже — другой. |  |
| **CRP** | Country Risk Premium | Надбавка к доходности за то, что вложения в конкретной стране рискованнее. Инвестор требует больше за вложения туда, где больше политических и экономических неожиданностей | <code>Ke = Rf + β × ERP + CRP</code><br><span class="fx">где: CRP — добавка к ставке за риск страны. Остальное как в CAPM</span> |
| **Currency peg** | Привязка курса | Центробанк удерживает курс валюты на фиксированном уровне к другой валюте, например к доллару. |  |
| **Currency risk** | Валютный риск | Риск потерять из-за изменения курса: выручка в рублях, долг в долларах. |  |
| **Current account** | Счёт текущих операций | Разница между тем, сколько страна получила от остального мира за экспорт и доходы, и сколько заплатила. Положительный — экспортёр. |  |
| **Current ratio** | Коэффициент текущей ликвидности | Хватит ли оборотных активов, чтобы закрыть краткосрочные долги. Выше 1 — запас есть. | <code>Current ratio = Оборотные активы / Краткосрочные обязательства</code> |
| **Current yield** | Текущая доходность | Купоны за год, делённые на цену облигации. Не учитывает разницу цены и номинала. | <code>Current yield = Годовой купон / Цена</code> |
| **Custodian** | Депозитарий / кастодиан | Организация, которая хранит бумаги клиентов и фиксирует права на них. В России — НРД. |  |
| **D&A** | Depreciation & Amortization | Амортизация: постепенное списание стоимости основных средств (ОС) и нематериальных активов (НМА) в расходы. Купили станок за 100 на 10 лет: каждый год в расходы идёт по 10, хотя деньги заплатили один раз. НМА — то, что нельзя потрогать: лицензии, программы, бренд |  |
| **Data room** | Комната данных | Защищённое хранилище документов компании, куда пускают покупателей для проверки. Сейчас почти всегда виртуальная (VDR). |  |
| **Data table** | Таблица данных (Excel) | Инструмент Excel «Анализ что-если», который считает результат при переборе двух вводных. Так строят таблицы чувствительности. |  |
| **DAU / MAU** | Daily / Monthly Active Users | Активные пользователи в день и в месяц. Их отношение показывает вовлечённость. | <code>Stickiness = DAU / MAU</code> |
| **DCF** | Discounted Cash Flow | Оценка компании по будущим денежным потокам, пересчитанным в сегодняшние деньги (дисконтированным). Идея: рубль сегодня ценнее рубля через год, поэтому будущие деньги «уценивают» | <code>EV = Σ FCF<sub>t</sub> / (1+WACC)<sup>t</sup> + TV / (1+WACC)<sup>n</sup></code><br><span class="fx">где: FCF<sub>t</sub> — свободный денежный поток года t. WACC — ставка дисконтирования. TV — терминальная стоимость после прогноза. n — последний год прогноза</span> |
| **DCM** | Debt Capital Markets | Рынок, на котором компании занимают деньги, выпуская облигации. Облигация — это долговая расписка: компания берёт деньги у многих людей и обещает вернуть с процентами |  |
| **DDM** | Dividend Discount Model | Оценка акции по будущим дивидендам, пересчитанным в сегодняшние деньги. Дивиденд — это часть прибыли, которую компания платит владельцам акций | <code>P = DPS<sub>1</sub> / (Ke − g)</code><br><span class="fx">где: DPS<sub>1</sub> — дивиденд на акцию в следующем году. Ke — требуемая доходность. g — вечный темп роста дивидендов (модель Гордона)</span> |
| **Deadlock** | Тупик | Ситуация, когда партнёры 50/50 не могут договориться. В корпоративном договоре заранее пишут выход: «русская рулетка», «техасская перестрелка», медиация. |  |
| **Deal team** | Команда сделки | Группа банкиров на проекте: MD ведёт клиента, VP управляет, ассоциат и аналитик делают материалы. |  |
| **Debt / Equity** | Долг к капиталу | Сколько долга приходится на рубль собственных денег. Мера финансового рычага. | <code>D/E = Долг / Капитал</code> |
| **Debt capacity** | Долговая ёмкость | Максимум долга, который компания может нести без угрозы платежеспособности. |  |
| **Debt schedule** | График долга | Таблица в модели: сколько долга на начало года, сколько взяли и погасили, сколько осталось и какие проценты. |  |
| **Debt service** | Обслуживание долга | Проценты плюс погашение основного долга за период. |  |
| **Debt-to-equity swap** | Обмен долга на акции | Кредиторы прощают долг и получают взамен акции компании. Часто итог реструктуризации. |  |
| **Deferred revenue** | Доходы будущих периодов | Деньги, которые клиент уже заплатил, а услугу или товар компания ещё не отдала. Это обязательство: пока не отдала, выручкой это не считается. |  |
| **DeFi** | Decentralized Finance | Финансовые сервисы на блокчейне без банков: кредиты, обмен, ставки, всё через смарт-контракты. |  |
| **Deflation** | Дефляция | Цены в экономике падают. Выглядит приятно, но люди откладывают покупки и экономика замедляется. |  |
| **Delta** | Дельта | Насколько изменится цена опциона, если цена актива сдвинется на 1. У колла от 0 до 1. |  |
| **Depreciation** | Амортизация (основных средств) | Постепенное списание стоимости оборудования, зданий и т. п. на расходы за все годы их службы. Деньги не уходят, но прибыль уменьшается. | <code>Амортизация в год = (Стоимость − Остаточная стоимость) / Срок службы</code> |
| **Devaluation** | Девальвация | Намеренное или вынужденное снижение курса национальной валюты. |  |
| **Diluted EPS** | Разводнённая прибыль на акцию (EPS — Earnings Per Share) | EPS с учётом всех бумаг, которые можно превратить в акции: опционов, конвертируемых облигаций. |  |
| **Dilution** | Размытие доли | Когда выпускают новые акции, доля каждого старого акционера уменьшается. | <code>Новая доля = Старая доля × Старое число акций / Новое число акций</code> |
| **DIP financing** | Debtor-in-Possession | Кредит компании в процедуре Chapter 11. Имеет приоритет над старыми долгами. |  |
| **Direct listing** | Прямой листинг | Выход на биржу без привлечения новых денег: акции просто начинают торговаться. |  |
| **Disclosure** | Раскрытие информации | Обязанность публичной компании публиковать отчётность и существенные факты. В РФ правила ЦБ и закон о рынке ценных бумаг (сверить). |  |
| **Discount factor** | Коэффициент дисконтирования | Число меньше единицы, на которое умножают будущую сумму, чтобы получить сегодняшнюю. | <code>DF = 1 / (1 + r)^n</code> |
| **Discounted payback** | Дисконтированный срок окупаемости | За сколько лет дисконтированные потоки вернут вложения. Честнее обычного payback. |  |
| **Disposition effect** | Эффект диспозиции | Продавать растущие бумаги слишком рано и держать падающие слишком долго. |  |
| **Distressed debt** | Проблемный долг | Долг компании в тяжёлом положении, торгуется с большим дисконтом. Фонды скупают его, надеясь на выкуп или реструктуризацию. |  |
| **Diversification** | Диверсификация | Не класть все яйца в одну корзину. Разные активы падают не одновременно, поэтому риск портфеля меньше риска отдельных бумаг. |  |
| **Divestiture** | Продажа бизнеса | Компания продаёт неосновной бизнес целиком. Деньги идут на долг, дивиденды или основной бизнес. |  |
| **Dividend policy** | Дивидендная политика | Правила, по которым компания решает, сколько прибыли выплатить акционерам, а сколько оставить. |  |
| **Dividend recap** | Рекапитализация ради дивиденда | Компания берёт новый долг и выплачивает деньги акционерам. Фонд так возвращает часть вложений до продажи. |  |
| **DKD** | Крупноузловая сборка (DKD — Disassembled Knocked Down) | Сборка из полуготовых автомобилей: кузов и крупные узлы уже готовы, на месте дособирают. Быстрый вход на рынок, маржа ниже, чем у CKD. В других источниках похожую схему называют SKD (Semi-Knocked Down). | |
| **DLOM** | Discount for Lack of Marketability | Скидка за низкую ликвидность: долю в частной компании трудно быстро продать по справедливой цене. |  |
| **Dot-com bubble** | Пузырь доткомов | Пузырь интернет-компаний 1998–2000 годов. NASDAQ упал на 78%. |  |
| **Down round** | Раунд по сниженной оценке | Компания привлекает деньги дешевле, чем в прошлый раз. Плохой знак для старых инвесторов и для сотрудников с опционами. |  |
| **DPI / TVPI / RVPI** | DPI — Distributions to Paid-In Capital; TVPI — Total Value to Paid-In Capital; RVPI — Residual Value to Paid-In Capital | Метрики фонда. DPI — сколько денег уже вернули инвесторам, RVPI — сколько ещё стоят оставшиеся вложения, TVPI — их сумма. | <code>TVPI = DPI + RVPI</code><br><span class="fx">где: Каждая метрика — на рубль вложенных денег.</span> |
| **DPS** | Dividend Per Share | Сколько дивидендов приходится на одну акцию. Если компания выплатила 1000 и акций 100, то DPS равен 10 | <code>DPS = Дивиденды / Число акций</code><br><span class="fx">где: Все выплаченные дивиденды делим на число акций в обращении</span> |
| **Drag-along** | Право принудительной продажи | Если крупные акционеры продают компанию, они могут заставить продать и миноритариев на тех же условиях. |  |
| **Driver** | Драйвер | Вводная, от которой считается строка модели: рост выручки, маржа, дни дебиторки. |  |
| **Dry powder** | «Сухой порох» | Деньги, которые фонд уже собрал, но ещё не вложил. |  |
| **DSCR** | Debt Service Coverage Ratio | Денежный поток для обслуживания долга / (проценты + плановое погашение). Показывает, во сколько раз заработок больше платежей по долгу. Если DSCR меньше 1, денег на платёж не хватает | <code>DSCR = CFADS / (Проценты + Погашение основного долга)</code><br><span class="fx">где: CFADS — денежный поток для обслуживания долга. Ниже 1 — денег на платежи не хватает</span> |
| **DSO / DIO / DPO** | Days Sales / Inventory / Payables Outstanding | За сколько дней в среднем оборачиваются: дебиторка (долги клиентов), запасы, кредиторка (долги перед поставщиками). Например, DSO 30 дней значит, что клиенты платят в среднем через месяц после продажи | <code>DSO = Дебиторка / Выручка × 365; DIO = Запасы / COGS × 365; DPO = Кредиторка / COGS × 365</code><br><span class="fx">где: Дебиторка — долги покупателей. Запасы — товары на складе. Кредиторка — долги поставщикам. COGS — себестоимость. Результат в днях. Цикл денег: DSO + DIO − DPO</span> |
| **DSRA** | Debt Service Reserve Account | Резервный счёт проекта: на нём лежат деньги на несколько платежей по долгу. |  |
| **DTA / DTL** | Отложенные налоговые активы / обязательства (DTA — Deferred Tax Asset; DTL — Deferred Tax Liability) | Разница между налогом по учёту и налогом по закону. DTL — налог, который заплатят позже; DTA — налог, который заплатили вперёд и потом вернут через уменьшение налога. |  |
| **Dual-class shares** | Акции двух классов | Акции основателей дают больше голосов, чем обычные. Основатели сохраняют контроль с небольшой долей. |  |
| **Due diligence (DD)** |  | Тщательная проверка компании перед сделкой: покупатель смотрит документы, финансы и риски. Как осмотр квартиры и проверка документов перед покупкой |  |
| **DuPont** | Разложение ROE по Дюпону | ROE делят на три части: маржа, оборачиваемость активов, рычаг. Видно, за счёт чего прибыльность: хорошая маржа, быстрые продажи или долг. | <code>ROE = (Прибыль/Выручка) × (Выручка/Активы) × (Активы/Капитал)</code> |
| **Dutch disease** | «Голландская болезнь» | Рост добычи сырья укрепляет валюту и делает остальные отрасли неконкурентными. |  |
| **DV01** | DV01 — Dollar Value of a Basis Point | Сколько рублей меняется цена позиции при смещении доходности на 1 б.п. |  |
| **EAD** | Exposure at Default | Сумма, которую банк потеряет под риском в момент дефолта заёмщика. |  |
| **EAR / APR** | Эффективная и номинальная годовая ставка (EAR — Effective Annual Rate; APR — Annual Percentage Rate) | APR — ставка «по бумагам», без учёта частоты начисления. EAR — реальная годовая с учётом сложного процента. | <code>EAR = (1 + APR/m)^m − 1</code><br><span class="fx">где: m — число начислений в год.</span> |
| **Earn-out** |  | Часть цены сделки, которую платят позже, если компания достигнет оговорённых результатов. Продавец получает доплату, только если бизнес оправдает его обещания | <code>Цена = Фиксированная часть + Отложенная часть, если цель достигнута</code><br><span class="fx">где: Отложенная часть зависит от результатов бизнеса после сделки</span> |
| **Earnings surprise** | Сюрприз по прибыли | Разница между фактической прибылью и консенсусом. |  |
| **EBIT** | Earnings Before Interest & Taxes | Операционная прибыль: заработок до вычета процентов и налогов. Показывает, сколько приносит сам бизнес, без влияния кредитов и налогов. В учебниках и в этом конспекте EBIT и операционную прибыль считают одним и тем же; строго говоря, EBIT может включать ещё прочие (неоперационные) доходы и расходы, тогда он чуть отличается | <code>EBIT = Выручка − COGS − Операционные расходы</code><br><span class="fx">где: COGS — себестоимость проданного. Операционные расходы — SG&A, R&D и т. п. Прибыль до процентов и налогов</span> |
| **EBITDA** | Earnings Before Interest, Taxes, Depreciation and Amortization | Прибыль до вычета процентов, налогов и амортизации; грубо показывает, сколько компания зарабатывает на своей основной работе. Это EBIT, к которому прибавили амортизацию | <code>EBITDA = EBIT + D&A</code><br><span class="fx">где: EBIT — операционная прибыль. D&A — амортизация и износ. Маржа EBITDA = EBITDA / Выручка</span> |
| **EBITDA margin** | Маржа EBITDA (EBITDA — Earnings Before Interest, Taxes, Depreciation and Amortization) | Какая доля выручки превращается в EBITDA. Удобно сравнивать компании одной отрасли. | <code>EBITDA margin = EBITDA / Выручка</code> |
| **EBITDA per tonne** | EBITDA на тонну (EBITDA — Earnings Before Interest, Taxes, Depreciation and Amortization) | Метрика металлургов: прибыль на тонну продукции. Показывает позицию на кривой затрат. |  |
| **EBITDAR** | EBITDAR — Earnings Before Interest, Taxes, Depreciation, Amortization and Rent | EBITDA до арендных расходов. Нужна для сравнения компаний, где часть бизнеса арендована, а часть куплена (ритейл, авиа, рестораны). | <code>EBITDAR = EBITDA + Аренда</code> |
| **ECL** | Expected Credit Loss | Ожидаемые кредитные потери, которые банк резервирует по МСФО 9 заранее. |  |
| **ECM** | Equity Capital Markets | Рынок, на котором компании привлекают деньги, продавая свои акции (IPO, SPO). Акция — доля в компании, и тот, кто её купил, становится совладельцем |  |
| **Economic capital** | Экономический капитал | Сколько капитала нужно банку по его собственной оценке риска, а не по нормативам. |  |
| **Effective tax rate** | Эффективная ставка налога | Фактически уплаченный налог к прибыли до налога. Отличается от законной ставки из-за льгот и невычитаемых расходов. | <code>ETR = Налог на прибыль / Прибыль до налога</code> |
| **Efficient frontier** | Эффективная граница | Линия на графике «риск — доходность»: лучшие портфели, где нельзя поднять доходность без роста риска. |  |
| **Efficient market hypothesis** | Гипотеза эффективного рынка | Цены уже учитывают всю доступную информацию, поэтому стабильно обыгрывать рынок нельзя. Три формы: слабая, средняя, сильная. |  |
| **Embedded value** | Встроенная стоимость | Оценка страховщика жизни: капитал плюс сегодняшняя стоимость прибыли по уже заключённым договорам. |  |
| **Enron** |  | Американская энергокомпания, рухнувшая в 2001 году из-за махинаций с отчётностью через SPV. Привела к SOX и краху Arthur Andersen. |  |
| **Enterprise value (в сделке)** | Стоимость бизнеса | Цена за весь бизнес до учёта того, как он финансируется. |  |
| **EPC** | Engineering, Procurement, Construction | Договор, по которому подрядчик проектирует, закупает и строит объект под ключ за фиксированную цену. |  |
| **EPS** | Earnings Per Share | Сколько чистой прибыли приходится на одну акцию. Чистая прибыль — то, что осталось после всех расходов и налогов | <code>EPS = (Чистая прибыль − Дивиденды по привилегированным) / Средневзвешенное число акций</code><br><span class="fx">где: Прибыль, которая приходится на одну обыкновенную акцию</span> |
| **Equity** | Акционерный капитал / акции | Доля владельцев в компании. Может означать и сам капитал, и ценные бумаги, которые его представляют. |  |
| **Equity method** | Метод долевого участия | Как учитывают долю в компании, где у тебя 20–50% и нет контроля: не складывают её отчёт по строкам, а показывают одну строку «доля в прибыли». |  |
| **Equity multiplier** | Мультипликатор капитала | Активы к собственному капиталу. Часть разложения Дюпона. | <code>Equity multiplier = Активы / Капитал</code> |

Например, купили за 150 компанию, чьё имущество за вычетом долгов стоит 100: гудвилл равен 50. Это плата за бренд, клиентов, репутацию | <code>Goodwill = Цена покупки − Справедливая стоимость чистых активов</code><br><span class="fx">где: Переплата за бренд, клиентов и команду сверх стоимости активов</span> |
| **Gordon growth model** | Модель Гордона | Стоимость актива, который приносит поток, растущий вечно с постоянным темпом g. Используют в двух местах: для оценки акции по дивидендам (DDM) и для терминальной стоимости в DCF. Работает только если ставка больше роста. | <code>P₀ = DPS₁ / (Ke − g);  TV = FCF₁ / (WACC − g) = FCF₀ × (1+g) / (WACC − g)</code><br><span class="fx">где: DPS₁ — дивиденд следующего года. Ke — стоимость собственного капитала. g — темп роста. FCF — свободный денежный поток. Если g ≥ ставки, формула ломается; g берут не выше роста экономики</span> |
| **GP / LP** | General / Limited Partner | GP — управляющий фондом, принимает решения. LP — инвестор, даёт деньги и не управляет. |  |
| **Green bond** | Зелёная облигация | Облигация, деньги от которой идут на экологические проекты. |  |
| **Greenshoe** |  | Право организатора размещения продать дополнительные акции (до 15%), чтобы удерживать цену на стабильном уровне. Это «запасной» объём: если спрос высокий, продают больше, а если цена падает, организатор выкупает акции и поддерживает цену | <code>Допразмещение ≤ 15% от основного объёма</code><br><span class="fx">где: Опцион андеррайтера выкупить дополнительные акции по цене IPO, чтобы стабилизировать курс</span> |
| **Greenwashing** | Гринвошинг | Компания выдаёт себя за более «зелёную», чем есть. |  |
| **Gross margin** | Валовая маржа | Какая доля выручки остаётся после себестоимости. | <code>Gross margin = Валовая прибыль / Выручка</code> |
| **Gross merchandise margin** | Торговая наценка | Разница между ценой продажи и закупки к выручке. Основа маржи ритейлера. |  |
| **Gross profit** | Валовая прибыль | Выручка минус себестоимость. Сколько остаётся на всё остальное: зарплаты, аренду, проценты, налоги. | <code>Валовая прибыль = Выручка − Себестоимость</code> |
| **Growing perpetuity** | Растущий перпетуитет | Платёж, который растёт каждый год на g навсегда. Основа модели Гордона и терминальной стоимости. | <code>PV = C / (r − g)</code><br><span class="fx">где: Работает только при r больше g.</span> |
| **Growth capex** | Инвестиции в рост | Траты на расширение: новые заводы, магазины, мощности. Их можно отложить, не ломая текущий бизнес. |  |
| **Growth investing** | Инвестирование в рост | Покупать быстро растущие компании, даже если мультипликаторы высокие, ожидая, что рост окупит цену. |  |
| **Guidance** | Прогноз компании | Ориентир по выручке и прибыли, который компания сама даёт рынку на год или квартал. |  |
| **Haircut** |  | Скидка к рыночной стоимости залога или бумаги в сделке: кредитор принимает актив не по полной цене, а с запасом на случай её падения. Например, бумагу за 100 засчитывают как залог на 80. Второе значение — списание части долга при реструктуризации, см. следующую строку | <code>Залог = Рыночная стоимость × (1 − Haircut)</code><br><span class="fx">где: Haircut — скидка к рыночной цене залога. При 20% бумага за 100 принимается как залог на 80</span> |
| **Haircut (реструктуризация)** | Списание части долга | Кредиторы соглашаются получить меньше номинала. |  |
| **Halving** | Халвинг | Раз в 4 года награда майнерам за блок биткоина падает вдвое. Предложение растёт медленнее. |  |
| **Hard currency** | Твёрдая валюта | Валюта, которую охотно принимают по всему миру: доллар, евро, франк. |  |
| **Hardcode** | Жёстко вбитое число | Число, введённое в ячейку руками, а не формулой. В моделях выделяют синим, чтобы видеть вводные. |  |
| **Hedge fund** | Хедж-фонд | Фонд для квалифицированных инвесторов с широкими стратегиями: шорты, плечо, деривативы. Берёт 2% за управление и 20% от прибыли. |  |
| **Hedging** | Хеджирование | Сделка, которая страхует от неприятного движения цены: например, продать фьючерс, чтобы защитить стоимость товара на складе. |  |
| **Herding** | Стадное поведение | Покупать потому, что все покупают. Так надуваются пузыри. |  |
| **HFT** | High-Frequency Trading | Высокочастотная торговля: алгоритмы совершают тысячи сделок в секунду, зарабатывая на крошечных разницах цен. |  |
| **High yield** | Высокодоходные облигации | Облигации компаний с низким рейтингом и высокой ставкой. Иначе «мусорные». |  |
| **Historical cost** | Первоначальная стоимость | Актив записан по цене покупки и не пересматривается вверх вместе с рынком (только амортизируется). |  |
| **Holdback** | Удержание | Покупатель удерживает часть цены на срок, чтобы покрыть возможные претензии. Как эскроу, но без третьей стороны. |  |
| **Holding company** | Холдинг | Компания, владеющая долями в других компаниях и управляющая ими. |  |
| **Hostile takeover** | Недружественное поглощение | Покупатель обращается напрямую к акционерам, минуя совет директоров целевой компании. |  |
| **Hurdle rate** |  | Минимальная доходность, которую должен дать проект, чтобы в него стоило вкладываться (часто WACC + премия). «Hurdle» значит «барьер»: проект должен через него перепрыгнуть | <code>Hurdle = Минимальная требуемая доходность проекта</code><br><span class="fx">где: Если IRR проекта ниже, проект не берут. Часто равна WACC плюс запас</span> |
| **IC memo** | Investment committee memo | Документ для инвестиционного комитета фонда: тезис, оценка, риски, доходность. | |
| **ICR** | Interest Coverage Ratio | Покрытие процентов: во сколько раз операционная прибыль больше процентов (EBIT / проценты; в кредитном анализе и ковенантах чаще берут EBITDA / проценты, как в главах про долг). Если прибыль 90, а проценты 30, ICR равен 3: денег втрое больше, чем нужно на проценты | <code>ICR = EBIT / Проценты к уплате</code><br><span class="fx">где: Во сколько раз операционная прибыль покрывает проценты. Ниже 1,5–2 — тревожно</span> |
| **Idiosyncratic risk** | Специфический риск | Риск одной компании, который убирается диверсификацией. |  |
| **IFRS / МСФО** | International Financial Reporting Standards | Международные правила составления финансовой отчётности. Они нужны, чтобы компании из разных стран считали и показывали свои цифры одинаково |  |
| **IFRS 16** | Стандарт об аренде (IFRS — International Financial Reporting Standards) | По МСФО почти любая аренда показывается в балансе: актив (право пользования) и долг на сумму будущих платежей. Из-за этого у арендаторов выросли EBITDA и долг. |  |
| **IFRS 9 stages** | Стадии по МСФО 9 (IFRS — International Financial Reporting Standards) | Кредиты делят на три стадии: 1 — всё хорошо, 2 — риск вырос, 3 — дефолт. Чем выше стадия, тем больше резерв. |  |
| **Impairment** | Обесценение | Когда актив оказался стоит меньше, чем записан в балансе, его списывают до реальной цены. Убыток разовый и бумажный, деньги не уходят. |  |
| **Implied multiple** | Подразумеваемый мультипликатор | Мультипликатор, который «зашит» в полученной оценке. Помогает проверить DCF: если вышло EV/EBITDA = 30, что-то не так. |  |
| **Implied volatility** | Подразумеваемая волатильность | Волатильность, которую «закладывает» рынок в цену опциона. Растёт в страх. |  |
| **Income statement (P&L)** | Отчёт о прибылях и убытках (P&L — Profit & Loss) | Показывает за период, сколько компания заработала и потратила: от выручки сверху до чистой прибыли внизу. | <code>Чистая прибыль = Выручка − Расходы − Проценты − Налоги</code> |
| **Incremental cash flow** | Приростный денежный поток | Только те деньги, которые появятся или исчезнут из-за проекта. Остальное в оценку проекта не входит. |  |
| **Indemnity** | Возмещение потерь | Обязательство продавца покрыть конкретные убытки покупателя, например по налоговой проверке за прошлые годы. В РФ — ст. 406.1 ГК (сверить). |  |
| **Independent director** | Независимый директор | Член совета, не связанный с компанией и крупными акционерами. Должен защищать интересы всех акционеров. |  |
| **Index** | Индекс | Число, показывающее, как ведёт себя группа бумаг. IMOEX — российские акции, S&P 500 — американские. |  |
| **Inflation-linked bond** | Облигация, привязанная к инфляции | Номинал или купон растёт вместе с инфляцией. Защита от обесценения денег. В России — ОФЗ-ИН. |  |
| **Information ratio** | Информационный коэффициент | Насколько постоянно управляющий обыгрывает бенчмарк, с учётом отклонения от него. | <code>IR = (Rp − Rb) / Tracking error</code> |
| **Insider trading** | Инсайдерская торговля | Сделки с бумагами на основе непубличной информации. Запрещена. В РФ — закон 224-ФЗ (сверить). |  |
| **Installed capacity** | Установленная мощность | Максимальная мощность электростанции, МВт. |  |
| **Intangible assets** | Нематериальные активы | Активы без вещественной формы: патенты, лицензии, бренды, программы, гудвил. |  |
| **Interchange** | Интерчейндж | Часть комиссии за оплату картой, которую банк магазина платит банку покупателя. |  |
| **Interest coverage** | Покрытие процентов | Во сколько раз операционная прибыль (EBIT, в кредитном анализе часто EBITDA) больше процентов по долгу. Ниже 1,5 — тревожно. | <code>ICR = EBIT / Проценты</code> |
| **Interest expense** | Процентные расходы | Сколько компания заплатила процентов по своим долгам за период. |  |
| **Interested party transaction** | Сделка с заинтересованностью | Сделка, в которой у директора или крупного акционера есть личный интерес. Нужно раскрытие и, по требованию, одобрение. В РФ — глава XI закона об АО (сверить). |  |
| **Internal audit** | Внутренний аудит | Служба внутри компании, проверяющая процессы и контроли. Подчиняется совету, а не менеджменту. |  |
| **Internship** | Стажировка | Летняя программа 2–3 месяца, часто ведёт к офферу. |  |
| **Intrinsic value** | Внутренняя стоимость опциона | Сколько опцион стоил бы, если бы его исполнили прямо сейчас. | <code>Call: max(S − K; 0)</code> |
| **Inventory** | Запасы | Сырьё, незавершёнка и готовая продукция на складе. Пока не продано, лежит в балансе как актив. |  |
| **Inventory turnover** | Оборачиваемость запасов | Сколько раз за год запасы «проходят» через продажи. | <code>Inventory turnover = Себестоимость / Средние запасы</code> |
| **Investment grade** | Инвестиционный рейтинг | Рейтинг не ниже BBB− по шкале S&P: считается, что компания скорее вернёт долг. Всё ниже — high yield. |  |
| **IPO** | Initial Public Offering | Первичное публичное размещение: компания впервые продаёт свои акции на бирже. После этого любой человек может купить долю в такой компании |  |
| **IPO 2023–2024** | IPO — Initial Public Offering | Волна небольших IPO на Мосбирже: Астра, Совкомбанк, Диасофт, Европлан, МТС-Банк, ВИ.ру, Элемент (сверить). |  |
| **IRR** | Internal Rate of Return | Внутренняя норма доходности: годовая доходность проекта, то есть ставка, при которой NPV = 0. Проще говоря, «под какой годовой процент работают вложенные деньги» | <code>0 = Σ CF<sub>t</sub> / (1+IRR)<sup>t</sup></code><br><span class="fx">где: CF<sub>t</sub> — денежный поток года t (включая начальную инвестицию с минусом). IRR — ставка, при которой NPV равна нулю. Подбирается итерациями</span> |
| **IRS** | Interest Rate Swap | Процентный своп: стороны меняются платежами по фиксированной и плавающей ставке на одну и ту же сумму. Применяют, чтобы превратить плавающий долг в фиксированный. |  |
| **J-curve** | J-кривая | Доходность фонда в первые годы отрицательна (комиссии, неокупившиеся вложения), потом растёт. График по форме похож на букву J. |  |
| **Joint venture** | Совместное предприятие | Две компании создают общую, делят расходы, риски и прибыль. |  |
| **KYC** | Know Your Customer | Процедура проверки клиента банком или брокером: кто он, откуда деньги. |  |
| **LBO** | Leveraged Buyout | Покупка компании в основном на заёмные деньги. Как купить квартиру в ипотеку с маленьким первым взносом. Долг потом гасят из прибыли самой купленной компании |  |
| **LCOE** | Levelized Cost of Energy | Полная стоимость одного кВт·ч за весь срок станции с учётом стройки, топлива и ставки дисконтирования. |  |
| **LCR** | Liquidity Coverage Ratio | Хватит ли у банка ликвидных активов, чтобы пережить отток денег за 30 дней. Должен быть не ниже 100%. | <code>LCR = Ликвидные активы / Чистый отток за 30 дней</code> |
| **Legal DD** | Юридическая проверка (DD — Due Diligence) | Проверка прав на акции и активы, договоров, судов, лицензий, трудовых вопросов. |  |
| **Lehman Brothers** |  | Инвестбанк, банкротство которого в сентябре 2008 года стало пиком мирового кризиса. |  |
| **Leverage** |  | Финансовый рычаг: использование долга. Часто его измеряют как ND/EBITDA. Долг усиливает и прибыль, и убытки, как рычаг: чем длиннее, тем сильнее эффект | <code>Леверидж = Net Debt / EBITDA</code><br><span class="fx">где: Net Debt — долг минус деньги. Показывает, за сколько лет EBITDA погасит долг</span> |
| **Levered beta** | Бета с учётом долга | Бета акций компании, как она есть: включает риск самого бизнеса и риск долга. | <code>βL = βU × (1 + (1 − t) × D/E)</code><br><span class="fx">где: βU — бета без долга. t — налог. D/E — долг к капиталу.</span> |
| **LGD** | Loss Given Default | Доля потерь при дефолте = 1 − recovery rate. Если кредитор вернул 40% долга, потеря составила 60% | <code>LGD = 1 − Recovery rate</code><br><span class="fx">где: Recovery rate — доля долга, которую вернули при дефолте. LGD — доля потерь</span> |
| **LIFO** | Последним пришёл — первым ушёл (LIFO — Last In, First Out) | Способ учёта: в себестоимость идёт самая свежая партия. Разрешён в US GAAP, запрещён в МСФО. |  |
| **LIFO reserve** | Резерв LIFO (LIFO — Last In, First Out) | Разница между запасами по FIFO и по LIFO. Нужна, чтобы пересчитать отчёт американской компании в FIFO. | <code>Запасы FIFO = Запасы LIFO + LIFO reserve</code> |
| **Lifting cost** | Себестоимость добычи | Сколько стоит достать баррель нефти из скважины. |  |
| **Like-for-like (LFL)** | Сопоставимые продажи | Рост выручки только по тем магазинам или объектам, которые работали и в прошлом году. Убирает эффект открытий. |  |
| **Limit order** | Лимитная заявка | Купить или продать не хуже указанной цены. Может не исполниться, если рынок не дошёл. |  |
| **Liquidation preference** | Приоритет при ликвидации | Право инвестора первым забрать свои деньги (иногда с кратным умножением) при продаже или закрытии компании, до основателей. |  |
| **Liquidity risk** | Риск ликвидности | Не суметь быстро продать актив или найти деньги для платежа. |  |
| **LLCR** | Loan Life Cover Ratio | NPV потоков проекта за срок кредита / остаток долга. Показывает, хватит ли денег проекта, чтобы погасить весь кредит. Если меньше 1, не хватит | <code>LLCR = NPV(CFADS за срок кредита) / Остаток долга</code><br><span class="fx">где: CFADS — денежный поток, доступный для обслуживания долга. NPV берётся по ставке кредита</span> |
| **Load factor** | Загрузка | Авиация: доля занятых кресел. Энергетика: доля времени, когда станция работает на полную мощность. |  |
| **Loan loss provision** | Резерв на возможные потери по ссудам | Деньги, которые банк откладывает на случай, что часть кредитов не вернут. Уменьшает прибыль. |  |
| **Loan-to-deposit** | Кредиты к депозитам | Сколько кредитов банк выдал на рубль вкладов. Выше 100% — банк зависит от рыночного фондирования. | <code>LDR = Кредиты / Депозиты</code> |
| **Lock-up** |  | Запрет продавать свои акции после IPO (обычно 180 дней). Нужен, чтобы владельцы не бросились продавать сразу и не обвалили цену |  |
| **Locked box** |  | Способ определить цену сделки: её фиксируют по балансу на прошлую дату, и дальше цена не пересчитывается. Покупатель знает цену заранее, а продавец обещает, что до закрытия сделки деньги из компании не уйдут |  |
| **LOI / MoU** | Письмо о намерениях / меморандум (LOI — Letter of Intent; MoU — Memorandum of Understanding) | Предварительный документ с основными условиями. Обычно необязательный, кроме эксклюзивности и конфиденциальности. |  |
| **Long-stop date** | Крайний срок | Дата, после которой любая сторона может выйти из договора, если сделка не закрылась. |  |
| **Long/short equity** |  | Стратегия хедж-фонда: покупать недооценённые акции, шортить переоценённые. |  |
| **Loss aversion** | Неприятие потерь | Потеря ощущается сильнее, чем такая же по размеру прибыль. Из-за этого люди держат убыточные позиции слишком долго. |  |
| **Loss ratio** | Коэффициент убыточности | Какую долю премий страховщик выплатил как возмещение. | <code>Loss ratio = Выплаты / Премии</code> |
| **LSE / HKEX / SGX** | LSE — London Stock Exchange; HKEX — Hong Kong Exchanges and Clearing; SGX — Singapore Exchange | Биржи Лондона, Гонконга, Сингапура. Российские компании размещали GDR в Лондоне до 2022 года. |  |
| **LTM / TTM / NTM** | Last / Trailing / Next Twelve Months | Последние 12 месяцев (LTM, TTM) или следующие 12 месяцев (NTM). | **LTV (клиент)** | Customer Lifetime Value | Сколько денег клиент принесёт за всё время, пока пользуется продуктом. | <code>LTV = Средний чек × Покупок за период × Срок жизни клиента × Маржа</code><br><span class="fx">где: Хорошо, когда LTV / CAC больше 3.</span> |
| **LTV (кредит)** | Loan-to-Value | Какую долю от стоимости залога составляет кредит. Чем ниже, тем безопаснее банк. | <code>LTV = Кредит / Стоимость залога</code> |
| **M&A** | Mergers & Acquisitions | Слияния и поглощения компаний. Слияние — две компании становятся одной, поглощение — одна покупает другую |  |
| **M2** | Денежная масса M2 | Наличные, деньги на счетах и на срочных вкладах. Показывает, сколько денег в экономике. |  |
| **MAC / MAE** | Material Adverse Change / Effect | Условие, по которому покупатель может отказаться от сделки, если случится существенное негативное событие. Например, пожар на главном заводе до закрытия сделки |  |
| **MACD** | MACD — Moving Average Convergence Divergence | Индикатор на разнице двух скользящих средних. Показывает смену тренда. |  |
| **Magic number** | «Магическое число» | Сколько новой годовой выручки принёс рубль расходов на продажи в прошлом квартале. |  |
| **Maintenance capex** | Поддерживающие инвестиции | Деньги, которые надо тратить, чтобы бизнес просто не развалился: ремонт, замена оборудования. |  |
| **Major transaction** | Крупная сделка | Сделка на 25% и больше балансовых активов. Требует одобрения совета или собрания. В РФ — глава X закона об АО (сверить). |  |
| **Majority shareholder** | Мажоритарий | Акционер с контрольной долей. В РФ по закону об АО есть пороги прав: 1%, 2%, 10%, 25%, 30%, 50%, 75%, 95% (сверить). |  |
| **Make-whole** | Компенсация при досрочном погашении | Платёж, равный приведённой стоимости всех недополученных платежей по облигации. | |
| **Management fee** | Комиссия за управление | Ежегодная плата фонду за управление деньгами, часто 1,5–2% от капитала. Выплачивается независимо от результата. |  |
| **Mandatory offer** | Обязательное предложение | Кто перешёл порог 30% голосующих акций ПАО, обязан предложить остальным выкупить их акции. В РФ — ст. 84.2 закона об АО (сверить). |  |
| **Margin call** | Маржин-колл | Требование брокера добавить денег на счёт, когда убытки по позиции с плечом съели обеспечение. Не добавил — позицию закроют принудительно. |  |
| **Marginal tax rate** | Предельная ставка | Ставка на следующий рубль дохода. Для налогового щита важна она. |  |
| **Mark-to-market** | Переоценка по рынку | Оценка позиции по сегодняшней рыночной цене, а не по цене покупки. Прибыль и убыток видны каждый день. |  |
| **Market maker** | Маркетмейкер | Участник, который постоянно выставляет и цену покупки, и цену продажи, давая рынку ликвидность. Зарабатывает на спреде. |  |
| **Market manipulation** | Манипулирование рынком | Искусственное движение цены: ложные заявки, сговор, распространение слухов. Запрещено. |  |
| **Market order** | Рыночная заявка | Купить или продать сразу по лучшей доступной цене. Исполнится, но цена может отличаться от ожидаемой. |  |
| **Market risk** | Рыночный риск | Потери от движения цен, ставок, курсов. |  |
| **Marketplace** | Маркетплейс | Площадка, сводящая продавцов и покупателей. Зарабатывает комиссию. Ozon, Wildberries. |  |
| **Materiality** | Существенность | Порог, ниже которого ошибка или событие не меняет решения читателя отчётности. Аудитор проверяет только существенное. |  |
| **Max drawdown** | Максимальная просадка | Самое глубокое падение портфеля от пика до дна за период. Показывает, сколько можно потерять в плохой момент. | <code>Drawdown = (Дно − Пик) / Пик</code> |
| **MBO** | Management Buyout | Выкуп компании самим менеджментом, обычно вместе с фондом и за счёт долга. |  |
| **MBS** | Mortgage-Backed Security | Бумага, обеспеченная пулом ипотечных кредитов. |  |
| **Merger arbitrage** | Арбитраж слияний | Покупка акций цели по цене чуть ниже цены сделки. Заработок, если сделка закроется, убыток, если сорвётся. |  |
| **Mezzanine** | Мезонинное финансирование | Дорогой долг между обычным долгом и акциями. Платят выше, чем по кредитам, зато при банкротстве возвращают позже. |  |
| **Mid-year convention** | Допущение о середине года | Денежные потоки приходят равномерно в течение года, поэтому их дисконтируют не на конец года, а на середину. Оценка получается выше. |  |
| **Minority discount** | Скидка за миноритарность | Доля без контроля стоит дешевле пропорциональной доли компании, потому что владелец не может решать. |  |
| **Minority shareholder** | Миноритарий | Акционер с небольшой долей, без контроля. Защищён законом: право на информацию, выкуп при крупных сделках. |  |
| **MIRR** | Modified Internal Rate of Return | IRR с реалистичным допущением: промежуточные потоки реинвестируют по стоимости капитала, а не по самой IRR. |  |
| **Moat** | «Ров» | Устойчивое преимущество, которое защищает бизнес: бренд, сеть, лицензия, низкие затраты. Термин Баффетта. |  |
| **Modified duration** | Модифицированная дюрация | Приблизительно на сколько процентов изменится цена облигации при изменении доходности на 1 п. п. | <code>ΔP/P ≈ −D_mod × Δy</code> |
| **Modigliani–Miller** | Теорема Модильяни — Миллера | В идеальном мире без налогов стоимость компании не зависит от структуры капитала. В реальности есть налоговый щит и риск банкротства, поэтому структура важна. |  |
| **MoM / MOIC** | Multiple of Money / Multiple on Invested Capital | Во сколько раз выросли вложенные деньги. Вложили 100, получили 250: MoM равен 2,5× | <code>MOIC = Деньги, полученные при выходе / Вложенный капитал</code><br><span class="fx">где: Сколько раз вернулись вложения. MOIC 3x значит, что на 1 вложенный пришло 3</span> |
| **Momentum** | Моментум | Стратегия: покупать то, что росло недавно, продавать то, что падало. Работает до разворота. |  |
| **Monetary policy** | Денежно-кредитная политика | Действия центробанка по ставке и количеству денег, чтобы держать инфляцию в цели и поддерживать экономику. |  |
| **Monte Carlo** | Метод Монте-Карло | Тысячи прогонов модели со случайными значениями вводных. На выходе не одно число, а распределение результатов. |  |
| **Moving average** | Скользящая средняя | Средняя цена за последние N дней. Сглаживает график, показывает тренд. |  |
| **MRR** | Monthly Recurring Revenue | Ежемесячная повторяющаяся выручка от подписок. Годовая версия — ARR. |  |
| **Mutual fund** | Паевой фонд (ПИФ) | Фонд, где деньги многих инвесторов объединены и управляются управляющей компанией. Пай можно купить и погасить по цене, зависящей от стоимости активов. |  |
| **MVA** | Market Value Added | Рыночная стоимость компании минус вложенный в неё капитал. Показывает, сколько стоимости компания создала сверх вложенных в неё денег | <code>MVA = Рыночная стоимость компании − Инвестированный капитал</code><br><span class="fx">где: Сколько стоимости компания добавила сверх вложенных в неё денег</span> |
| **NASDAQ / NYSE** | NASDAQ — National Association of Securities Dealers Automated Quotations; NYSE — New York Stock Exchange | Две главные биржи США. NYSE — старейшая, NASDAQ — технологические компании. |  |
| **Natural hedge** | Естественный хедж | Защита от валютного риска без деривативов: выручка и расходы в одной валюте. |  |
| **NAV** | Net Asset Value | Стоимость чистых активов: что останется, если из имущества вычесть долги. Как стоимость квартиры за вычетом остатка ипотеки | <code>NAV = Активы − Обязательства</code><br><span class="fx">где: Для фонда: стоимость активов по рынку минус долги. На пай: NAV / число паёв</span> |
| **NBO / BO** | (Non-) Binding Offer | Предложение о покупке: необязывающее (NBO) или обязывающее (BO). Необязывающее — это «пока намерение», от него можно отказаться. Обязывающее — это уже обещание, за отказ от которого могут быть последствия |  |
| **NCI** | Non-Controlling Interest | Доли меньшинства: часть дочерней компании, которая принадлежит другим владельцам, а не материнской компании. Например, материнская компания владеет 80% дочерней, а остальные 20% — это NCI |  |
| **NDA** | Non-Disclosure Agreement | Соглашение о конфиденциальности: стороны обещают не раскрывать полученные сведения. Его подписывают до того, как покупатель увидит внутренние данные компании |  |
| **NDF** | Non-Deliverable Forward | Форвард без поставки валюты: стороны платят только разницу курсов. Для валют с ограничениями, в том числе рубля на внешнем рынке. |  |
| **Neobank** | Необанк | Банк без отделений, только приложение. В России — Тинькофф (Т-Банк). |  |
| **Net Debt** |  | Чистый долг = Долг − Денежные средства. Если у тебя долг 100 и 30 на счёте, то чистый долг равен 70: на столько ты реально должен | <code>Net Debt = Долг − Деньги и эквиваленты</code><br><span class="fx">где: Долг — кредиты и облигации. Деньги вычитаем, потому что их можно использовать для погашения</span> |
| **Net Debt / EBITDA** | Чистый долг к EBITDA (EBITDA — Earnings Before Interest, Taxes, Depreciation and Amortization) | За сколько лет компания расплатилась бы с долгом, если бы вся EBITDA шла на долг. Главная мера долговой нагрузки. | <code>ND/EBITDA = (Долг − Деньги) / EBITDA</code> |

| **Network effect** | Сетевой эффект | Чем больше пользователей, тем полезнее продукт каждому. Создаёт защиту от конкурентов. |  |
| **NFT** | Non-Fungible Token | Уникальный токен, подтверждающий владение конкретным цифровым объектом. Не взаимозаменяем. |  |
| **NIM** | Net Interest Margin | Чистая процентная маржа банка: «наценка» банка на разнице между ставками по кредитам и по депозитам. | **NOI** | Net Operating Income | Чистый операционный доход объекта: аренда минус расходы на содержание, без процентов и амортизации. |  |
| **Nominal rate** | Номинальная ставка | Ставка без поправки на инфляцию. Реальная получается по формуле Фишера. | <code>(1 + номинальная) = (1 + реальная) × (1 + инфляция)</code> |

| **OAS** | Option-Adjusted Spread | Спред облигации с учётом встроенных опционов (например, права досрочного погашения). |  |
| **Off-balance sheet** | Внебалансовые статьи | Обязательства или активы, которых нет в самом балансе, но они влияют на компанию: гарантии, часть аренды, SPV. |  |
| **Offer** | Оффер | Предложение о работе с условиями. |  |
| **Offshore** | Офшор | Юрисдикция с низкими налогами и закрытой информацией о владельцах. Кипр, БВО, Каймановы острова. |  |

| **Open banking** | Открытый банкинг | Банки обязаны отдавать данные клиента по его согласию другим сервисам через API. |  |
| **Operating income** | Операционная прибыль | То же, что EBIT: прибыль от основной деятельности до процентов и налогов. |  |

| **Operating margin** | Операционная маржа | Доля выручки, которая остаётся после всех операционных расходов, до процентов и налогов. | <code>Operating margin = EBIT / Выручка</code> |
| **Operational risk** | Операционный риск | Потери из-за ошибок людей, систем, процессов или мошенничества. |  |
| **OPEX** | Operating Expenses | Операционные расходы: траты на повседневную работу. Зарплаты, аренда, электричество, реклама | <code>OPEX = SG&A + R&D + Прочие операционные расходы</code><br><span class="fx">где: Текущие расходы на ведение бизнеса, без капитальных затрат</span> |
| **Opportunity cost** | Альтернативные издержки | Что ты теряешь, выбирая этот вариант вместо лучшего из остальных. Ставка дисконтирования — это альтернативные издержки капитала. |  |
| **Option premium** | Премия по опциону | Цена самого опциона: деньги, которые покупатель платит продавцу за право. |  |
| **Order book** | Книга заявок (стакан) | Список всех заявок на покупку и продажу с ценами и объёмами. |  |
| **Ore grade** | Содержание металла в руде | Граммов золота на тонну руды. Чем выше, тем дешевле добыча. |  |
| **Organic growth** | Органический рост | Рост бизнеса без покупок других компаний. |  |
| **OTC** | Over-the-counter | Внебиржевой рынок: стороны договариваются напрямую, без общего стакана. |  |
| **Output gap** | Разрыв выпуска | Разница между фактическим ВВП и тем, что экономика может выдать без перегрева. |  |
| **Overconfidence** | Самоуверенность | Переоценка своих прогнозов. Ведёт к слишком частым сделкам и недостаточной диверсификации. |  |
| **Oversubscription** | Переподписка | Заявок на IPO больше, чем бумаг. Бумаги делят между инвесторами пропорционально. |  |
| **P/B** | Price to Book | Капитализация / балансовый собственный капитал. Главный мультипликатор для банков. Показывает, во сколько раз рынок оценивает компанию дороже, чем стоят её собственные деньги по балансу | <code>P/B = Капитализация / Балансовый капитал</code><br><span class="fx">где: Балансовый капитал — активы минус обязательства. P/B<1 значит, что рынок оценивает компанию ниже книжной стоимости</span> |
| **P/E** | Price to Earnings | Капитализация / чистая прибыль (= цена / EPS). Показывает, за сколько лет прибыли окупится покупка компании. Капитализация — это цена всех акций компании на бирже. P/E равно 10: цена в десять раз больше годовой прибыли | <code>P/E = Цена акции / EPS = Капитализация / Чистая прибыль</code><br><span class="fx">где: Сколько лет прибыли содержится в цене. EPS — прибыль на акцию</span> |
| **P/FFO** | FFO — Funds From Operations | Цена к денежному потоку от операций, мультипликатор для REIT и недвижимости. | <code>P/FFO = Капитализация / FFO</code> |
| **P/S** | Price to Sales | Капитализация / выручка. Подходит для убыточных и быстрорастущих компаний. Выручка — все деньги от продаж, до вычета расходов. Прибыли у таких компаний ещё нет, поэтому сравнивают по выручке | <code>P/S = Капитализация / Выручка</code><br><span class="fx">где: Во сколько раз цена компании больше годовой выручки</span> |
| **P2P lending** | Кредитование между людьми (P2P — Peer-to-Peer) | Платформа сводит тех, кто хочет одолжить, с теми, кто хочет занять, без банка. |  |
| **Paper LBO** | LBO — Leveraged Buyout | Задача на собеседовании: посчитать LBO на бумаге за 5 минут без Excel. |  |
| **Par / Premium / Discount** |  | Цена облигации: равна номиналу (par), выше (premium) или ниже (discount). |  |
| **Payback** |  | Срок окупаемости: за сколько времени вложения вернутся. Потратил 100 и получаешь по 25 в год: окупишься за 4 года | <code>Payback = Инвестиции / Годовой денежный поток</code><br><span class="fx">где: При равных потоках. Показывает, за сколько лет вложения вернутся (без учёта дисконтирования)</span> |
| **Payback (CAC)** | Срок окупаемости клиента (CAC — Customer Acquisition Cost) | За сколько месяцев маржа от клиента вернёт стоимость его привлечения. | <code>CAC payback = CAC / (Месячная выручка × Маржа)</code> |
| **Payment system** | Платёжная система | Инфраструктура для переводов между банками: Visa, Mastercard, Мир, СБП. |  |
| **Payout ratio** | Коэффициент выплат | Какую часть чистой прибыли компания отдаёт в виде дивидендов. | <code>Payout = Дивиденды / Чистая прибыль</code> |
| **PD** | Probability of Default | Вероятность того, что заёмщик не вернёт долг за период. |  |
| **PE (Private Equity)** |  | Фонды прямых инвестиций: они покупают компании, чтобы развить их и потом продать дороже. Похоже на покупку старой квартиры, ремонт и перепродажу, но с целыми компаниями |  |
| **Pecking order** | Иерархия источников | Компании сначала используют собственную прибыль, потом долг, и только в последнюю очередь выпускают акции. |  |
| **PEG** | Price/Earnings to Growth | P/E, делённый на темп роста EPS. Помогает понять, не переплачиваешь ли за быстрый рост. Меньше — лучше | <code>PEG = P/E / Темп роста EPS (в %)</code><br><span class="fx">где: P/E скорректирован на рост прибыли. Около 1 — справедливо, ниже — дёшево</span> |
| **Penny stock** | «Пенни-сток» | Дешёвая акция малой компании. Ликвидность низкая, цена скачет, мошенничество встречается чаще. |  |
| **Percentage of completion** | Метод по мере готовности | Выручку по длинному контракту признают пропорционально выполненной части, а не в конце. |  |
| **Perpetual bond** | Вечная облигация | Облигация без срока погашения: проценты платят бесконечно. |  |
| **Perpetuity** | Перпетуитет (бессрочная рента) | Одинаковый платёж навсегда. Его сегодняшняя стоимость конечна. | <code>PV = C / r</code> |
| **Phillips curve** | Кривая Филлипса | Зависимость между безработицей и инфляцией: чем ниже безработица, тем выше инфляция. |  |
| **PI** | Profitability Index | Индекс прибыльности: PV потоков / инвестиции. PV — сегодняшняя стоимость будущих денег. Если индекс больше 1, проект окупается и приносит прибыль | <code>PI = PV будущих потоков / Начальные инвестиции</code><br><span class="fx">где: PV — приведённая стоимость потоков. PI>1 значит проект выгоден. Нужен при ограниченном бюджете</span> |
| **PIK** | Payment-in-Kind | Проценты, которые не выплачивают, а прибавляют к сумме долга. Сейчас платить легче, но долг растёт: на следующий год проценты начислят уже на большую сумму |  |
| **Piotroski F-score** | F-модель Пиотроски | Девять да/нет-признаков финансового здоровья: прибыль, денежный поток, долг, маржа. Чем больше баллов, тем крепче компания. |  |
| **Pitch** | Питч | Презентация идеи или сделки клиенту или инвестору. |  |
| **Pitchbook** |  | Презентация банка для клиента: идея сделки, оценка, аналоги. Так банк «продаёт» клиенту свою идею и показывает, почему сделка выгодна |  |
| **Plug** | «Затычка» | Строка, которая балансирует модель: обычно деньги или револьвер. Если баланс не сходится, ищут ошибку, а не ставят плаг. |  |
| **PMI** | Purchasing Managers' Index | Опрос менеджеров по закупкам. Выше 50 — деловая активность растёт, ниже — падает. |  |
| **Poison pill** | Shareholder rights plan | Защита цели от поглощения: если покупатель набрал акций больше порога, остальные акционеры получают право купить акции со скидкой. Доля покупателя размывается, и враждебная покупка теряет смысл. «Ядовитая таблетка» |  |
| **PP&E** | Основные средства (PP&E — Property, Plant & Equipment) | Здания, станки, оборудование, транспорт: всё, что служит больше года и не продаётся. |  |
| **PPA** | Power Purchase Agreement | Долгосрочный договор на покупку электроэнергии по фиксированной цене. Гарантирует выручку проекту. |  |
| **Pre-IPO** | IPO — Initial Public Offering | Покупка акций частной компании незадолго до выхода на биржу, обычно со скидкой и с риском, что IPO не будет. |  |
| **Pre-money / Post-money** |  | Оценка компании до вложения инвестора и после. После = До + Сумма инвестиции. | <code>Post-money = Pre-money + Инвестиция</code><br><span class="fx">где: Доля инвестора = Инвестиция / Post-money.</span> |
| **Pre-pack** | Заранее согласованное банкротство | План реструктуризации согласован с кредиторами до подачи в суд, процедура проходит быстро. |  |
| **Precedent transactions** |  | Сделки-аналоги: мультипликаторы, по которым прошли прошлые сделки M&A. Как узнать цену квартиры по тому, за сколько недавно продали похожие в этом доме | <code>Цена = Метрика цели × Мультипликатор прошлых сделок</code><br><span class="fx">где: Похоже на Comps, но мультипликаторы взяты из реальных сделок M&A (включают премию за контроль)</span> |
| **Preferred return** | Приоритетная доходность | Минимальная доходность, которую фонд должен принести инвесторам, прежде чем управляющий возьмёт свой carry. |  |
| **Preferred stock** | Привилегированные акции | Акции, по которым дивиденд обычно фиксирован и платится раньше, чем по обычным, но права голоса, как правило, нет. |  |
| **Premium (страхование)** | Страховая премия | Деньги, которые клиент платит за страховку. |  |
| **Present value (PV)** | Приведённая стоимость | Сколько будущая сумма стоит сегодня, если её «уценить» по ставке. | <code>PV = FV / (1 + r)^n</code><br><span class="fx">где: FV — будущая сумма. r — ставка за период. n — число периодов.</span> |
| **Pricing power** | Ценовая власть | Способность поднимать цены без потери клиентов. |  |
| **Primary / Secondary market** | Первичный / вторичный рынок | На первичном бумаги продаёт сам эмитент (деньги идут компании). На вторичном инвесторы продают их друг другу. |  |
| **Private banking** |  | Банковское обслуживание состоятельных клиентов с персональным менеджером. |  |
| **Private label** | Собственная торговая марка | Товары под брендом сети. Маржа выше, чем на брендах производителей. |  |
| **Pro forma** | Проформа | Отчётность «как если бы»: как выглядела бы компания после сделки или события. |  |
| **Prospect theory** | Теория перспектив | Модель Канемана и Тверски: люди оценивают выигрыши и потери относительно точки отсчёта и боятся потерь сильнее. |  |
| **Prospectus** | Проспект эмиссии | Документ с описанием компании и рисков, который выдают инвесторам перед размещением. |  |
| **Provision** | Резерв (оценочное обязательство) | Расход, который компания записывает заранее, потому что почти уверена, что заплатит: например, по судебному иску. |  |
| **Proxy fight** | Борьба за голоса | Группа акционеров собирает голоса других акционеров, чтобы сменить совет директоров или отклонить сделку. |  |
| **Pump and dump** | «Накачка и сброс» | Разогнать цену малоликвидной бумаги слухами, продать на пике, оставить остальных с убытком. |  |
| **Purchasing power parity** | Паритет покупательной способности | Идея, что одна и та же корзина должна стоить одинаково в разных странах по обменному курсу. Если не стоит, валюта недо- или переоценена. |  |
| **Put / Call option (доли)** | Опцион на долю | Право продать (пут) или купить (колл) долю партнёра по заранее оговорённой цене при наступлении условий. |  |
| **Put option** | Опцион пут | Право, но не обязанность продать актив по цене страйк. Выигрыш при падении цены, поэтому его используют как страховку. | <code>Выплата = max(K − S; 0)</code> |
| **QE / QT** | Количественное смягчение / ужесточение (QE — Quantitative Easing; QT — Quantitative Tightening) | QE — центробанк печатает деньги и покупает бумаги, чтобы снизить ставки. QT — наоборот, сокращает баланс. |  |
| **Quality of earnings** | Качество прибыли | Насколько прибыль подкреплена деньгами и повторяема. Высокое качество: прибыль похожа на операционный денежный поток. |  |
| **Quant** | Квант | Специалист или фонд, торгующий по математическим моделям и алгоритмам. |  |
| **Quick ratio** | Коэффициент быстрой ликвидности | То же, но без запасов: их не всегда быстро продать. | <code>Quick ratio = (Оборотные активы − Запасы) / Краткосрочные обязательства</code> |
| **Quiet period** | Период тишины | Время перед и после IPO, когда компания и банки не вправе делать оптимистичные публичные заявления. |  |
| **R&D capitalization** | Капитализация НИОКР (R&D — Research & Development) | Расходы на разработку признают активом, если продукт точно будет. Исследования всегда идут в расходы. |  |
| **RAB** | Regulatory Asset Base | Регулируемая база активов: стоимость имущества (сетей, инфраструктуры), от которой государство считает допустимую прибыль. Например, у электросетей тариф устанавливает государство, чтобы владелец получал разумную доходность от стоимости сетей | <code>Выручка = RAB × Норма доходности + Амортизация + Расходы</code><br><span class="fx">где: RAB — регулируемая база активов. Регулятор разрешает получать доход на эту базу</span> |
| **RAB-регулирование** | RAB — Regulatory Asset Base | Тариф считают так, чтобы инвестор получал доходность на вложенный капитал. Применяется в сетях. |  |
| **Random walk** | Случайное блуждание | Идея, что движения цен непредсказуемы: завтрашнее изменение не зависит от вчерашнего. |  |
| **RAROC** | Risk-Adjusted Return on Capital | Прибыль банка к капиталу, выделенному под риск. Показывает, выгоден ли клиент с учётом риска. |  |
| **RASK / CASK** | Выручка и затраты на кресло-километр (RASK — Revenue per Available Seat Kilometre; CASK — Cost per Available Seat Kilometre) | Метрики авиакомпаний: сколько заработали и потратили на одно кресло на один километр. |  |
| **Real options** | Реальные опционы | Идея, что у менеджмента есть право выбрать: расширить, отложить или закрыть проект. Это право имеет цену, которую обычный DCF не видит. |  |
| **Real vs nominal** | Реальный и номинальный | Номинальное значение считают в текущих деньгах. Реальное очищают от инфляции. | <code>Реальная ставка ≈ Номинальная − Инфляция</code> |
| **Receivables turnover** | Оборачиваемость дебиторки | Сколько раз за год компания собирает свою дебиторку. | <code>Receivables turnover = Выручка / Средняя дебиторка</code> |
| **Recession** | Рецессия | Спад экономики, обычно два квартала подряд падения ВВП. |  |
| **Recovery rate** |  | Доля номинала долга, которую кредитор вернёт при дефолте. Если из долга 100 вернули 40, recovery rate равен 40% | <code>Recovery = Возврат при дефолте / Номинал долга</code><br><span class="fx">где: Доля долга, которую удалось вернуть</span> |
| **Red flag report** | Отчёт о красных флагах | Короткий результат due diligence: только найденные проблемы, без описания всего бизнеса. |  |
| **Refinitiv / LSEG** | LSEG — London Stock Exchange Group | Конкурент Bloomberg по данным (бывший Thomson Reuters, терминал Eikon). |  |
| **Reinsurance** | Перестрахование | Страховая передаёт часть риска другой страховой. Страховка для страховщика. |  |
| **REIT** | Real Estate Investment Trust | Компания, владеющая недвижимостью и обязанная раздавать большую часть дохода. Покупаешь акцию вместо квартиры. |  |
| **Related party** | Связанная сторона | Акционеры, менеджмент, их компании. Сделки с ними раскрывают отдельно, потому что они могут быть не по рынку. |  |
| **Related-party lending** | Кредитование связанных сторон | Банк выдаёт кредиты своим же акционерам. ЦБ ограничивает нормативом Н25 (сверить). |  |
| **Repo** | Репо | Сделка, где продают бумаги и обязуются выкупить их обратно позже по более высокой цене. По сути краткосрочный кредит под залог. |  |
| **Reps & warranties** | Заверения и гарантии | Утверждения продавца о компании в договоре: отчётность верна, судов нет, налоги заплачены. Если неправда, покупатель требует возмещение. В РФ — заверения об обстоятельствах, ст. 431.2 ГК (сверить). |  |
| **Reserve currency** | Резервная валюта | Валюта, в которой центробанки держат запасы. Главные: доллар, евро, юань. |  |
| **Reserves vs resources** | Запасы и ресурсы | Запасы — то, что точно выгодно добыть. Ресурсы — то, что есть в земле, но пока не доказано, что добыча окупится. |  |
| **Restructuring** | Реструктуризация долга | Изменение условий: удлинить срок, снизить ставку, списать часть. Должник получает облегчение, кредитор надеется вернуть хоть что-то. |  |
| **Retained earnings** | Нераспределённая прибыль | Прибыль, накопленная за все годы, которую не выплатили акционерам, а оставили в компании. | <code>Нераспр. прибыль (конец) = Нераспр. прибыль (начало) + Чистая прибыль − Дивиденды</code> |
| **Retention** | Удержание | Доля пользователей, которые остались через неделю, месяц, год. |  |
| **Retention ratio** | Коэффициент удержания | Какая часть прибыли остаётся в компании. Дополняет payout ratio до 100%. | <code>Retention = 1 − Payout</code> |
| **Return offer** |  | Оффер на постоянную работу по итогам стажировки. |  |
| **Revenue recognition** | Признание выручки | Правило, когда именно продажу можно записать в выручку. По IFRS 15 это момент, когда клиент получил контроль над товаром или услугой. |  |

Если результат положительный, компания зарабатывает больше, чем от неё требуют | <code>RI = Чистая прибыль − Ke × Балансовый капитал</code><br><span class="fx">где: Ke — стоимость собственного капитала. | **Sales per sq. m** | Выручка с квадратного метра | Эффективность торговой площади. |  |

| **Tag-along** | Право присоединения | Если крупный акционер продаёт долю, миноритарий вправе продать свою на тех же условиях. |  |

| **Teaser** |  | Короткое анонимное описание компании, которое рассылают потенциальным покупателям. Название скрыто, нужно лишь, чтобы заинтересовать. Как объявление «продаётся бизнес в сфере…» без адреса |  |
| **Technical analysis** | Технический анализ | Прогноз цены по графику и объёмам, без изучения бизнеса. Академическая наука к нему скептична. |  |

| **Term Loan A / B** | TLA / TLB | Старший кредит. Кредит A амортизируется (гасится частями) и обычно выдан банками. Кредит B почти не амортизируется и выдан инвесторами. Старший значит, что его возвращают первым. Кредит B дороже, потому что основную сумму отдают в конце |  |

| **Three-statement model** | Трёхзвенная модель | Финансовая модель, где P&L, баланс и денежный поток связаны формулами: изменил выручку — поменялось всё. |  |
| **Throughput** | Пропускная способность / прокачка | Объём, прошедший через трубу, порт, терминал за период. |  |
| **Tier 1 / Tier 2** |  | Уровни капитала банка. Tier 1 — самый надёжный (акции, прибыль), Tier 2 — запасной (например, субординированный долг). |  |
| **Time value** | Временна́я стоимость | Часть цены опциона сверх внутренней стоимости: плата за шанс, что цена ещё выгодно сдвинется. К дате экспирации сходит к нулю. | <code>Time value = Премия − Внутренняя стоимость</code> |
| **Time value of money** | Стоимость денег во времени | Рубль сегодня дороже рубля завтра: сегодняшний можно вложить и получить проценты. На этой идее стоит вся оценка. |  |

| **Tracking error** | Ошибка слежения | Насколько сильно доходность портфеля отклоняется от бенчмарка. Для индексного фонда должна быть маленькой. |  |
| **Trade-off theory** | Компромиссная теория | Оптимальный долг находят, сравнивая выгоду от налогового щита и расходы на возможное банкротство. |  |
| **Traffic / Ticket** | Трафик / средний чек | LFL-продажи раскладывают на число покупок и средний чек. |  |

| **Transfer of risk** | Передача риска | Переложить риск на другого: застраховать, захеджировать, включить в договор. |  |
| **Translation vs transaction exposure** | Пересчётный и операционный валютный риск | Пересчётный — бумажный, от перевода отчётности дочек в валюту материнской. Операционный — реальный, по конкретным платежам. |  |
| **Treasury stock** | Выкупленные собственные акции | Акции, которые компания выкупила у рынка. В балансе они вычитаются из капитала и не получают дивидендов. |  |

| **Trust** | Траст | Структура, где имущество передано управляющему в пользу бенефициаров. Для наследования и защиты активов. |  |
| **TSR** | Total Shareholder Return | Полная доходность акционера: рост цены акции + дивиденды. Совокупный доход акционера: рост цены плюс дивиденды</span> |

WACC — ставка дисконтирования (модель Гордона)</span> |
| **TVL** | Total Value Locked | Сколько денег лежит в DeFi-протоколе. Показывает его размер. |  |
| **Underwriter** | Андеррайтер | Банк, который организует выпуск бумаг, а иногда гарантирует выкуп непроданной части. |  |
| **Underwriting (страхование)** | Андеррайтинг | Оценка риска клиента и решение, страховать его или нет и по какой цене. |  |

| **Unit economics** | Юнит-экономика | Прибыльность одной единицы бизнеса: одного клиента, заказа, магазина. Если на одной единице убыток, рост только увеличивает убытки. |  |
| **Unitranche** | Юнитранш | Один кредит, объединяющий старший и мезонинный долг, с одной ставкой. Любят кредитные фонды. |  |

| **Value investing** | Стоимостное инвестирование | Покупать недооценённые компании: цена ниже, чем должна быть по прибыли и активам. Идея Грэма и Баффетта. |  |

| **Vega** | Вега | Насколько изменится цена опциона при росте волатильности на 1 п. п. |  |

| **Правкомиссия** | Правительственная комиссия по контролю за иностранными инвестициями | Орган, который разрешает сделки с нерезидентами из недружественных стран, в том числе продажу бизнеса с дисконтом (сверить). |  |
| **Приватизация** |  | Продажа госсобственности частным владельцам. В РФ 1990-х — ваучеры и залоговые аукционы. |  |
| **Признаки банкротства** |  | Юрлицо: долг от 2 млн руб. (порог повышен с 300 тыс. в 2024 году) и просрочка от 3 месяцев. Гражданин: от 500 тыс. и 3 месяца для подачи кредитором (сверить). |  |
| **Программа долгосрочных сбережений (ПДС)** |  | Государство софинансирует взносы граждан в НПФ до 36 тыс. руб. в год. Запущена в 2024 году (сверить). |  |
| **Проектное финансирование застройщика** |  | Банк кредитует стройку под залог проекта, ставка зависит от наполнения эскроу. |  |
| **Распроданность** |  | Доля проданных квартир в строящемся доме. Основная метрика девелоперов. |  |
| **Ребалансировка** |  | Периодическое возвращение долей активов в портфеле к целевым: продать то, что выросло, купить то, что упало. |  |
| **Ревизионная комиссия** |  | Орган АО, проверяющий финансово-хозяйственную деятельность. С 2018 года необязателен для ПАО (сверить). |  |
| **Редомициляция** |  | Перенос компании из одной юрисдикции в другую без ликвидации. Российские компании переезжают с Кипра и из Нидерландов в САР (сверить). |  |
| **Реестр акционеров** |  | Список владельцев акций. Ведёт регистратор, независимая компания. |  |
| **Реестр требований кредиторов** |  | Список кредиторов и сумм, признанных судом. Чтобы попасть, подают заявление в срок. |  |
| **Рефинансирование** |  | Новый кредит, чтобы погасить старый на лучших условиях. |  |
| **Розничный инвестор** |  | Частное лицо, которое торгует через брокера. В России их больше 30 млн счетов (сверить). |  |
| **Росимущество** |  | Управляет государственной собственностью и долями в госкомпаниях. |  |
| **Росфинмониторинг** |  | Финансовая разведка: следит за отмыванием денег по 115-ФЗ. |  |
| **РСБУ** | Российские стандарты бухучёта | Российские правила, по которым компании ведут бухгалтерский учёт и составляют отчётность. Нужны для налогов и отчётов внутри страны, а МСФО — для сравнения с зарубежными компаниями |  |
| **РФПИ** | Российский фонд прямых инвестиций | Государственный фонд, который вкладывает в российские проекты вместе с иностранными партнёрами. |  |
| **Сальдирование убытков** |  | Убыток по одним бумагам уменьшает налог с прибыли по другим в том же году. Можно переносить убытки на будущие годы (сверить). |  |
| **Санация** |  | Спасение банка: ЦБ или другой банк вливает капитал и берёт управление вместо отзыва лицензии. |  |
| **САР** | Специальный административный район | Острова Русский и Октябрьский, где зарегистрированные компании получают налоговые льготы. Российские «офшоры» (сверить). |  |
| **СБП** | Система быстрых платежей | Российская система ЦБ для мгновенных переводов по номеру телефона и оплаты по QR. |  |
| **СЗКО** | Системно значимая кредитная организация | Банк, крах которого ударит по всей системе. К ним требования жёстче. В списке ЦБ 13 банков (сверить). |  |
| **Скоринг** |  | Автоматическая оценка заёмщика баллами по анкете и кредитной истории. |  |
| **Сложный процент (на практике)** |  | 10% годовых за 30 лет превращают 1 рубль в 17. Главный аргумент начинать инвестировать рано. | <code>FV = 1 × 1,1^30 ≈ 17,4</code> |
| **СОИДН** | Соглашение об избежании двойного налогообложения | Договор между странами, чтобы один доход не облагался дважды. Многие соглашения РФ с недружественными странами приостановлены с 2023 года (сверить). |  |
| **СПАРК** |  | База «Интерфакса» по российским компаниям: отчётность, владельцы, суды, связи. |  |
| **СПБ Биржа** |  | Российская биржа, где торговались иностранные акции. С 2023 года под санкциями, активы заблокированы (сверить). |  |
| **Спред (bid-ask)** | Разница котировок | Разница между лучшей ценой продажи и покупки: скрытая стоимость сделки. | <code>Spread = Ask − Bid</code> |
| **Стакан** |  | Таблица заявок на покупку и продажу по ценам. То же, что order book. |  |
| **Страховые взносы** |  | Платежи работодателя за сотрудников в фонды. Общая ставка 30% до предельной базы, 15,1% сверх неё (сверить). |  |
| **Структурная нота** |  | Сложный продукт: облигация плюс опцион. Доход зависит от условий, капитал может быть не защищён. Для квалов. |  |
| **Структурный профицит ликвидности** |  | У банков в целом денег больше, чем надо, и они размещают их в ЦБ. При дефиците наоборот занимают у ЦБ. |  |
| **Сублизинг / возвратный лизинг** |  | Возвратный лизинг: компания продаёт своё оборудование лизингодателю и берёт его обратно в аренду, получив деньги. |  |
| **Субсидиарная ответственность** |  | Когда долгов компании не хватает, суд может взыскать их с контролирующих лиц: директора, акционеров. Глава III.2 закона о банкротстве (сверить). |  |
| **Существенный факт** |  | Событие, которое эмитент обязан раскрыть: сделка, дивиденды, смена директора. |  |
| **Счёт типа «С»** |  | Специальный счёт, на который зачисляют выплаты нерезидентам из недружественных стран. Вывести деньги с него ограниченно (сверить). |  |
| **Таргетирование инфляции** |  | Режим ЦБ: цель 4% в год, ставку двигают так, чтобы к ней прийти. |  |
| **Тикер** |  | Короткий код бумаги на бирже: SBER, GAZP, AAPL. |  |
| **Тонкая капитализация** |  | Правило: проценты по займам от иностранной материнской компании сверх лимита не вычитаются из налоговой базы, а считаются дивидендами (ст. 269 НК; сверить). |  |
| **Трансмиссионный механизм** |  | Цепочка, по которой ставка ЦБ доходит до цен: ставки банков → кредит и сбережения → спрос → инфляция. Занимает 3–6 кварталов. |  |
| **Трансфертное ценообразование** |  | Цены в сделках между компаниями одной группы. Налоговая проверяет, что они рыночные, чтобы прибыль не уводили в низконалоговые страны. |  |
| **УСН** | Упрощённая система налогообложения | Режим для малого бизнеса: платят 6% с доходов или 15% с разницы доходов и расходов вместо налога на прибыль и НДС (сверить, с 2025 года НДС частично вернулся). |  |
| **Усреднение (DCA)** | Dollar-Cost Averaging | Покупать на одинаковую сумму регулярно, не угадывая момент. Средняя цена сглаживается. |  |
| **Уставный капитал** |  | Минимальная сумма, которую вносят учредители: 10 тыс. руб. для ООО, 100 тыс. для ПАО (сверить). |  |
| **Факторинг** |  | Продажа дебиторки банку или фактору со скидкой: деньги сразу, а не через 60 дней. |  |
| **ФАС** | Федеральная антимонопольная служба | Одобряет крупные сделки слияния, следит за конкуренцией. |  |
| **Февраль 2022** |  | Санкции, заморозка резервов, ставка 20%, остановка торгов на месяц. Уход иностранных инвесторов с рынка. |  |
| **Финансовая подушка** |  | Запас денег на 3–6 месяцев расходов в ликвидной форме на случай потери дохода. |  |
| **Финансовый уполномоченный** |  | Омбудсмен, который бесплатно разбирает споры граждан с банками и страховыми до суда. |  |
| **ФНБ** | Фонд национального благосостояния | Резервный фонд государства РФ: деньги от нефтегазовых доходов, которые копят на трудные времена и пенсионные нужды. |  |
| **ФНС** | Федеральная налоговая служба | Собирает налоги, ведёт ЕГРЮЛ, проводит проверки. |  |
| **Форфейтинг** |  | Покупка банком долга по внешнеторговому контракту без права регресса на продавца. |  |
| **ФСО** | Федеральные стандарты оценки | Стандарты оценочной деятельности РФ. Это обязательные правила, по которым оценщики определяют стоимость имущества и бизнеса |  |
| **ЦБ РФ** | Банк России | Центральный банк: ставит ключевую ставку, регулирует банки и рынок, хранит резервы. |  |
| **Цветовой код модели** |  | Синий — вводные, чёрный — формулы, зелёный — ссылки на другие листы, красный — проверки. Стандарт инвестбанков. |  |
| **Центр раскрытия (e-disclosure)** |  | Официальный сайт, где российские эмитенты публикуют отчётность и существенные факты. |  |
| **Цессия** |  | Уступка права требования: кредитор продаёт долг другому. Так банки продают просрочку коллекторам. |  |
| **Цифровой рубль** |  | Третья форма рубля (кроме наличного и безналичного), которую выпускает ЦБ РФ. Хранится на платформе ЦБ. |  |
| **ЦФА** | Цифровые финансовые активы | Российские цифровые права на блокчейне: можно выпустить аналог облигации или права на товар. Регулируются законом о ЦФА (сверить). |  |
| **Экспортная пошлина** |  | Пошлина на вывоз товара. На нефть обнулена с 2024 года в рамках налогового манёвра (сверить). |  |
| **Эмитент** |  | Компания или государство, выпустившие ценные бумаги. |  |
| **Юанизация** |  | Рост доли юаня в расчётах, вкладах и долге российских компаний после 2022 года. |  |
