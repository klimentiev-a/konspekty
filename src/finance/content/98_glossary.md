# Глоссарий
short: Термины и сокращения от A до Я. В алфавитном порядке: сначала латиница, потом кириллица. У терминов с расчётом есть формула и расшифровка обозначений

| Термин | Расшифровка | Значение | Формула и расшифровка |
|---|---|---|---|
| **Add-backs** | Корректировки EBITDA | Статьи, которые добавляют к EBITDA, чтобы получить Adjusted EBITDA. Часть нормальна (разовые расходы), часть завышает базу. | Проверяйте детализацию и лимиты в договоре |
| **Book building** | Сбор заявок | Сбор заявок инвесторов по цене и количеству, по которому определяют цену и распределение акций при размещении. | |
| **NWC peg** | Целевой оборотный капитал | Уровень NWC, зафиксированный в договоре сделки: отклонение на дату закрытия меняет цену. | |
| **VaR** | Value at Risk | Потеря, которую не превысят с заданной вероятностью за период. | <code>VaR = z × σ × Стоимость</code> (z = 1,65 для 95%) |
| **Дюрация** | Duration | Средневзвешенный срок денежных потоков облигации, мера чувствительности цены к ставке. | <code>ΔP/P ≈ −D_mod × Δy</code> |
| **ABB** | Accelerated Bookbuilding | Быстрая (за 1–2 дня) продажа крупного пакета акций крупным инвесторам, например фондам и банкам. Банк быстро собирает заявки и продаёт всё оптом, как распродажа партии товара одному-двум крупным покупателям |  |
| **Accretion / Dilution** |  | Насколько вырастет или упадёт прибыль на акцию (EPS) у покупателя после сделки. «Accretion» — прибавка, «dilution» — разбавление. Если прибыль на акцию выросла, сделка выгодна акционерам покупателя | <code>EPS<sub>после</sub> − EPS<sub>до</sub></code><br><span class="fx">где: EPS — прибыль на акцию. Если после сделки EPS выше, это accretion (прирост), если ниже, dilution (размытие)</span> |
| **Accrued interest** |  | См. НКД | <code>Accrued = Купон × Дней с выплаты / Дней в периоде</code><br><span class="fx">где: То же, что НКД</span> |
| **APV** | Adjusted Present Value | Сначала считают стоимость компании так, будто долга нет, потом прибавляют сегодняшнюю стоимость (PV) налоговой экономии от процентов по долгу (налогового щита). Проценты по кредиту уменьшают налог, и эту выгоду учитывают отдельной строкой | <code>APV = NPV<sub>без долга</sub> + PV(налоговый щит)</code><br><span class="fx">где: NPV без долга — стоимость бизнеса, будто долгов нет. PV налогового щита — приведённая выгода от вычета процентов из налога</span> |
| **ARPU** | Average Revenue Per User | Сколько выручки в среднем приносит один пользователь (телеком, интернет). Если оператор за месяц получил 1000 рублей от 10 абонентов, ARPU равен 100 рублей | <code>ARPU = Выручка / Число пользователей</code><br><span class="fx">где: Выручка за период, делённая на среднее число пользователей за тот же период</span> |
| **ARR** | Annual Recurring Revenue | Выручка за год, которая повторяется из года в год, например по подписке (SaaS — программы по подписке). Похоже на абонемент в спортзал: деньги приходят регулярно, а не разово | <code>ARR = MRR × 12</code><br><span class="fx">где: MRR — ежемесячная повторяющаяся выручка по подпискам. Умножаем на 12 месяцев</span> |
| **Basis point (б.п.)** |  | Базисный пункт = 0,01%. 50 б.п. = 0,5 п.п. (п.п. — процентный пункт). Это очень мелкая единица, чтобы точно говорить о небольших изменениях ставок | <code>1 б.п. = 0,01% = 0,0001</code><br><span class="fx">где: Сотая доля процента. Рост ставки с 10% до 10,5% — это +50 б.п.</span> |
| **Beta (β)** |  | Показывает, насколько сильно акция реагирует на движения рынка. Бета 1 значит «двигается как рынок», больше 1 — «качается сильнее», меньше 1 — «спокойнее» | <code>β = Cov(R<sub>акции</sub>, R<sub>рынка</sub>) / Var(R<sub>рынка</sub>)</code><br><span class="fx">где: Cov — ковариация доходностей акции и рынка (двигаются вместе или нет). Var — дисперсия доходности рынка. β>1 значит акция колеблется сильнее рынка</span> |
| **Bookrunner** |  | Банк, который собирает заявки инвесторов при размещении акций или облигаций. Он ведёт «книгу заявок»: список, кто сколько готов купить и по какой цене |  |
| **Break fee** | Termination fee | Неустойка, которую платит цель, если выходит из сделки ради другого предложения. Неустойка — это штраф за срыв договорённости. Цель — компания, которую покупают |  |
| **CAGR** | Compound Annual Growth Rate | Средний рост за год с учётом «процента на процент»: (Конец/Начало)^(1/n) − 1. Здесь n — число лет. Это та единая годовая скорость роста, которая из начальной суммы даёт конечную | <code>CAGR = (V<sub>кон</sub> / V<sub>нач</sub>)<sup>1/n</sup> − 1</code><br><span class="fx">где: V<sub>кон</sub> — конечное значение, V<sub>нач</sub> — начальное, n — число лет. Показывает среднегодовой темп роста с учётом сложного процента</span> |
| **CAPEX** | Capital Expenditures | Капитальные затраты: траты на покупку и обновление оборудования и других основных средств (ОС). Основные средства — это то, что служит много лет: станки, здания, машины. Например, пекарня покупает новую печь | <code>CAPEX = ΔОС + Амортизация</code><br><span class="fx">где: ΔОС — изменение основных средств за период (конец минус начало). Амортизация добавляется, потому что она уменьшила стоимость ОС без покупок</span> |
| **Capital rationing** |  | Ограниченный бюджет на инвестиции: проекты выстраивают по PI и берут лучшие, пока деньги не кончатся. Как поход в магазин с ограниченной суммой: сначала берёшь самое выгодное |  |
| **CAPM** | Capital Asset Pricing Model | Модель, которая считает, какую доходность ждут от акции: Ke = Rf + β × ERP. Ke — требуемая доходность, Rf — безрисковая ставка, β — чувствительность акции к рынку, ERP — премия за риск акций. То есть «надёжная ставка плюс плата за риск» | <code>Ke = Rf + β × (Rm − Rf)</code><br><span class="fx">где: Ke — стоимость собственного капитала. Rf — безрисковая ставка. β — чувствительность акции к рынку. Rm − Rf — премия за риск рынка (ERP)</span> |
| **CET1** | Common Equity Tier 1 | Самый надёжный капитал банка: акции и нераспределённая прибыль (Базель III). Это собственные деньги банка, которыми он в первую очередь покрывает убытки | <code>CET1 = Основной капитал / RWA</code><br><span class="fx">где: Основной капитал — акции и нераспределённая прибыль. RWA — активы, взвешенные на риск</span> |
| **CFF** | Cash Flow from Financing | Финансовый поток: движение денег по долгу, дивидендам, байбэкам (выкупу своих акций) и выпуску новых акций. Это деньги, которые пришли от кредиторов и акционеров или ушли к ним |  |
| **CFI** | Cash Flow from Investing | Инвестиционный поток: деньги на CAPEX, а также от покупки и продажи активов и компаний. Обычно он отрицательный: компания тратит деньги на развитие |  |
| **CFO** | Cash Flow from Operations | Операционный денежный поток: деньги, которые компания получила от основной работы. Например, деньги магазина от продажи товаров за вычетом оплаты поставщикам и зарплат | <code>CFO = Чистая прибыль + D&A ± ΔNWC</code><br><span class="fx">где: D&A — амортизация (не денежные расходы, возвращаем). ΔNWC — изменение чистого оборотного капитала (рост NWC уменьшает денежный поток)</span> |
| **CIM** | Confidential Information Memorandum | Подробное закрытое описание продаваемой компании для покупателей. Как подробное объявление о продаже квартиры с планом, документами и историей, которое показывают только серьёзным покупателям |  |
| **CIR** | Cost-to-Income Ratio | Какую долю доходов банка съедают его расходы: расходы / доходы. Если на каждые 100 рублей дохода уходит 40 рублей расходов, CIR равен 40% | <code>CIR = Операционные расходы / Операционные доходы</code><br><span class="fx">где: Расходы банка (персонал, офисы, IT) делим на его доходы. Чем ниже, тем эффективнее банк</span> |
| **Club deal** |  | Кредит нескольких банков без широкой синдикации (то есть без привлечения множества участников). Узкий круг банков договаривается между собой, как в закрытом клубе |  |
| **Combined ratio** |  | (Убытки + расходы) / премии у страховщика. Если меньше 100%, страхование само по себе прибыльно. Премии — взносы клиентов. Собрали 100, выплатили и потратили 90: показатель 90% | <code>Combined = Убыточность + Расходность</code><br><span class="fx">где: Убыточность — выплаты / премии. Расходность — расходы на ведение дела / премии. Ниже 100% — страховщик в прибыли</span> |
| **Comps** | Comparable companies | Таблица похожих компаний и их мультипликаторов. Мультипликатор — это «во сколько раз цена больше показателя» (прибыли, выручки). Так оценивают компанию по аналогии, как квартиру по цене соседних | <code>Цена = Метрика цели × Медианный мультипликатор аналогов</code><br><span class="fx">где: Метрика — например, EBITDA. Мультипликатор берётся у похожих публичных компаний</span> |
| **CoR** | Cost of Risk | Цена кредитного риска: сколько денег банк отложил на возможные потери по кредитам (резервы / кредиты). Это «страховой запас» на случай, что часть клиентов не вернёт долг | <code>CoR = Резервы под потери за год / Средний кредитный портфель</code><br><span class="fx">где: Резервы — сумма, отложенная на плохие кредиты. Показывает, какая доля портфеля «сгорает» за год</span> |
| **Covenant** |  | Условие кредитного договора, которое заёмщик обязан соблюдать (например, ND/EBITDA ≤ 3×). ND/EBITDA — это чистый долг, делённый на EBITDA. То есть «долг не должен быть больше годовой прибыли в 3 раза». При нарушении банк может потребовать вернуть деньги |  |
| **Credit spread** |  | Кредитный спред: доходность облигации компании минус доходность госбумаги того же срока. Это плата за то, что компания надёжна хуже государства. Чем больше разница, тем рискованнее компания | <code>Spread = Доходность облигации − Доходность госбумаги</code><br><span class="fx">где: Доплата за кредитный риск. Измеряется в б.п.</span> |
| **CRP** | Country Risk Premium | Надбавка к доходности за то, что вложения в конкретной стране рискованнее. Инвестор требует больше за вложения туда, где больше политических и экономических неожиданностей | <code>Ke = Rf + β × ERP + CRP</code><br><span class="fx">где: CRP — добавка к ставке за риск страны. Остальное как в CAPM</span> |
| **D&A** | Depreciation & Amortization | Амортизация: постепенное списание стоимости основных средств (ОС) и нематериальных активов (НМА) в расходы. Купили станок за 100 на 10 лет: каждый год в расходы идёт по 10, хотя деньги заплатили один раз. НМА — то, что нельзя потрогать: лицензии, программы, бренд |  |
| **DCF** | Discounted Cash Flow | Оценка компании по будущим денежным потокам, пересчитанным в сегодняшние деньги (дисконтированным). Идея: рубль сегодня ценнее рубля через год, поэтому будущие деньги «уценивают» | <code>EV = Σ FCF<sub>t</sub> / (1+WACC)<sup>t</sup> + TV / (1+WACC)<sup>n</sup></code><br><span class="fx">где: FCF<sub>t</sub> — свободный денежный поток года t. WACC — ставка дисконтирования. TV — терминальная стоимость после прогноза. n — последний год прогноза</span> |
| **DCM** | Debt Capital Markets | Рынок, на котором компании занимают деньги, выпуская облигации. Облигация — это долговая расписка: компания берёт деньги у многих людей и обещает вернуть с процентами |  |
| **DDM** | Dividend Discount Model | Оценка акции по будущим дивидендам, пересчитанным в сегодняшние деньги. Дивиденд — это часть прибыли, которую компания платит владельцам акций | <code>P = DPS<sub>1</sub> / (Ke − g)</code><br><span class="fx">где: DPS<sub>1</sub> — дивиденд на акцию в следующем году. Ke — требуемая доходность. g — вечный темп роста дивидендов (модель Гордона)</span> |
| **DPS** | Dividend Per Share | Сколько дивидендов приходится на одну акцию. Если компания выплатила 1000 и акций 100, то DPS равен 10 | <code>DPS = Дивиденды / Число акций</code><br><span class="fx">где: Все выплаченные дивиденды делим на число акций в обращении</span> |
| **DSCR** | Debt Service Coverage Ratio | Денежный поток для обслуживания долга / (проценты + плановое погашение). Показывает, во сколько раз заработок больше платежей по долгу. Если DSCR меньше 1, денег на платёж не хватает | <code>DSCR = CFADS / (Проценты + Погашение основного долга)</code><br><span class="fx">где: CFADS — денежный поток для обслуживания долга. Ниже 1 — денег на платежи не хватает</span> |
| **DSO / DIO / DPO** | Days Sales / Inventory / Payables Outstanding | За сколько дней в среднем оборачиваются: дебиторка (долги клиентов), запасы, кредиторка (долги перед поставщиками). Например, DSO 30 дней значит, что клиенты платят в среднем через месяц после продажи | <code>DSO = Дебиторка / Выручка × 365; DIO = Запасы / COGS × 365; DPO = Кредиторка / COGS × 365</code><br><span class="fx">где: Дебиторка — долги покупателей. Запасы — товары на складе. Кредиторка — долги поставщикам. COGS — себестоимость. Результат в днях. Цикл денег: DSO + DIO − DPO</span> |
| **Due diligence (DD)** |  | Тщательная проверка компании перед сделкой: покупатель смотрит документы, финансы и риски. Как осмотр квартиры и проверка документов перед покупкой |  |
| **Earn-out** |  | Часть цены сделки, которую платят позже, если компания достигнет оговорённых результатов. Продавец получает доплату, только если бизнес оправдает его обещания | <code>Цена = Фиксированная часть + Отложенная часть, если цель достигнута</code><br><span class="fx">где: Отложенная часть зависит от результатов бизнеса после сделки</span> |
| **EBIT** | Earnings Before Interest & Taxes | Операционная прибыль: заработок до вычета процентов и налогов. Показывает, сколько приносит сам бизнес, без влияния кредитов и налогов | <code>EBIT = Выручка − COGS − Операционные расходы</code><br><span class="fx">где: COGS — себестоимость проданного. Операционные расходы — SG&A, R&D и т. п. Прибыль до процентов и налогов</span> |
| **EBITDA** | Earnings Before Interest, Taxes, D&A | Прибыль до вычета процентов, налогов и амортизации; грубо показывает, сколько компания зарабатывает на своей основной работе. Это EBIT, к которому прибавили амортизацию | <code>EBITDA = EBIT + D&A</code><br><span class="fx">где: EBIT — операционная прибыль. D&A — амортизация и износ. Маржа EBITDA = EBITDA / Выручка</span> |
| **ECM** | Equity Capital Markets | Рынок, на котором компании привлекают деньги, продавая свои акции (IPO, SPO). Акция — доля в компании, и тот, кто её купил, становится совладельцем |  |
| **EPS** | Earnings Per Share | Сколько чистой прибыли приходится на одну акцию. Чистая прибыль — то, что осталось после всех расходов и налогов | <code>EPS = (Чистая прибыль − Дивиденды по привилегированным) / Средневзвешенное число акций</code><br><span class="fx">где: Прибыль, которая приходится на одну обыкновенную акцию</span> |
| **Equity Value** |  | Стоимость акционерного капитала (для публичной компании — капитализация). Это цена только той части бизнеса, которая принадлежит владельцам, без долга | <code>Equity Value = EV − Net Debt − NCI − Привилегированные</code><br><span class="fx">где: EV — стоимость бизнеса. Вычитаем долги и права других держателей. Остаток принадлежит акционерам</span> |
| **ERP** | Equity Risk Premium | Дополнительная доходность, которую инвесторы требуют за то, что вкладываются в акции, а не в безрисковые бумаги. Это плата за то, что акции могут и упасть в цене | <code>ERP = Rm − Rf</code><br><span class="fx">где: Rm — ожидаемая доходность рынка акций. Rf — безрисковая ставка. Это доплата за то, что вложились в рынок, а не в госбумаги</span> |
| **EV** | Enterprise Value | Стоимость всего бизнеса целиком: капитал + чистый долг + … Представь цену квартиры целиком: и твоя часть, и часть, которую ты ещё должен банку по ипотеке | <code>EV = Капитализация + Долг + NCI + Привилегированные − Деньги</code><br><span class="fx">где: Капитализация — цена всех акций. NCI — доля миноритариев в дочках. Деньги вычитаем, ими можно сразу погасить часть долга</span> |
| **EVA** | Economic Value Added | Экономическая добавленная стоимость: (ROIC − WACC) × Инвестированный капитал. Показывает, сколько денег компания заработала сверх того, что требуют те, кто в неё вложился | <code>EVA = NOPAT − WACC × Инвестированный капитал</code><br><span class="fx">где: NOPAT — операционная прибыль после налога. Вычитаем плату за капитал. Положительная EVA — компания создаёт стоимость</span> |
| **FCF** | Free Cash Flow | Свободный денежный поток: деньги, которые остаются после операционных расходов, налогов и инвестиций. Это деньги, которые можно свободно потратить: выплатить владельцам или вернуть долг | <code>FCF = CFO − CAPEX</code><br><span class="fx">где: CFO — денежный поток от операций. CAPEX — инвестиции в основные средства</span> |
| **FCFE** | Free Cash Flow to Equity | Свободный поток только акционерам (после долга). Дисконтируется по Ke. То есть это деньги, которые могут достаться владельцам, когда кредиторы уже получили своё | <code>FCFE = FCFF − Проценты × (1−t) + Новый долг − Погашение долга</code><br><span class="fx">где: Проценты × (1−t) — проценты после налогового щита. Новый долг и погашение — чистое заимствование. Остаётся акционерам</span> |
| **FCFF** | Free Cash Flow to Firm | Свободный поток всем инвесторам (до долга), то есть и кредиторам, и акционерам: EBIT×(1−t) + D&A − CAPEX − ΔNWC. Здесь t — налоговая ставка, ΔNWC — прирост оборотного капитала. Дисконтируется по WACC | <code>FCFF = EBIT × (1−t) + D&A − CAPEX − ΔNWC</code><br><span class="fx">где: t — ставка налога. D&A — амортизация. CAPEX — инвестиции. ΔNWC — прирост оборотного капитала. Поток, доступный и кредиторам, и акционерам</span> |
| **FDV** | Fully Diluted Valuation | Капитализация криптотокена, если посчитать по максимальному числу токенов, которое можно выпустить. Токен — цифровая единица, которую выпускает проект. FDV показывает «потолок» оценки, когда все токены уже будут выпущены | <code>FDV = Цена токена × Максимальное число токенов</code><br><span class="fx">где: Цена текущая, число токенов — всё, что будет выпущено, включая ещё не выданные</span> |
| **FFO** | Funds From Operations | Денежная прибыль REIT (фонда, который владеет недвижимостью). Сюда не включают бумажное списание стоимости зданий, поэтому цифра ближе к реальным деньгам от аренды | <code>FFO = Чистая прибыль + D&A − Прибыль от продажи недвижимости</code><br><span class="fx">где: Используется для REIT: амортизацию возвращаем, разовую прибыль от продаж убираем</span> |
| **Free float** |  | Какая доля акций свободно торгуется на бирже. Остальное держат крупные владельцы и не продают | <code>Free float = Акции в свободном обращении / Все акции</code><br><span class="fx">где: Без долей стратегических держателей, государства и менеджмента</span> |
| **Fulcrum security** |  | Уровень долга, на котором заканчивается стоимость бизнеса. Его держатели получают контроль при реструктуризации. Реструктуризация — это пересмотр долгов, чтобы компания смогла выжить |  |
| **G-spread** |  | Спред доходности облигации к кривой госбумаг (КБД) на том же сроке. Показывает, на сколько облигация доходнее госбумаги с тем же сроком. КБД объяснена ниже | <code>G-spread = YTM облигации − YTM госбумаги того же срока</code><br><span class="fx">где: Спред к кривой гособлигаций</span> |
| **Goodwill** |  | Переплата при покупке компании: на сколько цена покупки больше справедливой стоимости её чистых активов. Например, купили за 150 компанию, чьё имущество за вычетом долгов стоит 100: гудвилл равен 50. Это плата за бренд, клиентов, репутацию | <code>Goodwill = Цена покупки − Справедливая стоимость чистых активов</code><br><span class="fx">где: Переплата за бренд, клиентов и команду сверх стоимости активов</span> |
| **Greenshoe** |  | Право организатора размещения продать дополнительные акции (до 15%), чтобы удерживать цену на стабильном уровне. Это «запасной» объём: если спрос высокий, продают больше, а если цена падает, организатор выкупает акции и поддерживает цену | <code>Допразмещение ≤ 15% от основного объёма</code><br><span class="fx">где: Опцион андеррайтера выкупить дополнительные акции по цене IPO, чтобы стабилизировать курс</span> |
| **Haircut** |  | Списание части долга: кредитор получает меньше номинала. Номинал — сумма долга по договору. Например, долг 100, а кредитор согласился на 70 | <code>Залог = Рыночная стоимость × (1 − Haircut)</code><br><span class="fx">где: Haircut — скидка к рыночной цене залога. При 20% бумага за 100 принимается как залог на 80</span> |
| **Hurdle rate** |  | Минимальная доходность, которую должен дать проект, чтобы в него стоило вкладываться (часто WACC + премия). «Hurdle» значит «барьер»: проект должен через него перепрыгнуть | <code>Hurdle = Минимальная требуемая доходность проекта</code><br><span class="fx">где: Если IRR проекта ниже, проект не берут. Часто равна WACC плюс запас</span> |
| **ICR** | Interest Coverage Ratio | Покрытие процентов: во сколько раз прибыль больше процентов (EBIT / проценты). Если прибыль 90, а проценты 30, ICR равен 3: денег втрое больше, чем нужно на проценты | <code>ICR = EBIT / Проценты к уплате</code><br><span class="fx">где: Во сколько раз операционная прибыль покрывает проценты. Ниже 1,5–2 — тревожно</span> |
| **IFRS / МСФО** | International Financial Reporting Standards | Международные правила составления финансовой отчётности. Они нужны, чтобы компании из разных стран считали и показывали свои цифры одинаково |  |
| **IPO** | Initial Public Offering | Первичное публичное размещение: компания впервые продаёт свои акции на бирже. После этого любой человек может купить долю в такой компании |  |
| **IRR** | Internal Rate of Return | Внутренняя норма доходности: годовая доходность проекта, то есть ставка, при которой NPV = 0. Проще говоря, «под какой годовой процент работают вложенные деньги» | <code>0 = Σ CF<sub>t</sub> / (1+IRR)<sup>t</sup></code><br><span class="fx">где: CF<sub>t</sub> — денежный поток года t (включая начальную инвестицию с минусом). IRR — ставка, при которой NPV равна нулю. Подбирается итерациями</span> |
| **LBO** | Leveraged Buyout | Покупка компании в основном на заёмные деньги. Как купить квартиру в ипотеку с маленьким первым взносом. Долг потом гасят из прибыли самой купленной компании |  |
| **Leverage** |  | Финансовый рычаг: использование долга. Часто его измеряют как ND/EBITDA. Долг усиливает и прибыль, и убытки, как рычаг: чем длиннее, тем сильнее эффект | <code>Леверидж = Net Debt / EBITDA</code><br><span class="fx">где: Net Debt — долг минус деньги. Показывает, за сколько лет EBITDA погасит долг</span> |
| **LGD** | Loss Given Default | Доля потерь при дефолте = 1 − recovery rate. Если кредитор вернул 40% долга, потеря составила 60% | <code>LGD = 1 − Recovery rate</code><br><span class="fx">где: Recovery rate — доля долга, которую вернули при дефолте. LGD — доля потерь</span> |
| **LLCR** | Loan Life Cover Ratio | NPV потоков проекта за срок кредита / остаток долга. Показывает, хватит ли денег проекта, чтобы погасить весь кредит. Если меньше 1, не хватит | <code>LLCR = NPV(CFADS за срок кредита) / Остаток долга</code><br><span class="fx">где: CFADS — денежный поток, доступный для обслуживания долга. NPV берётся по ставке кредита</span> |
| **Lock-up** |  | Запрет продавать свои акции после IPO (обычно 180 дней). Нужен, чтобы владельцы не бросились продавать сразу и не обвалили цену |  |
| **Locked box** |  | Способ определить цену сделки: её фиксируют по балансу на прошлую дату, и дальше цена не пересчитывается. Покупатель знает цену заранее, а продавец обещает, что до закрытия сделки деньги из компании не уйдут |  |
| **LTM / TTM / NTM** | Last / Trailing / Next Twelve Months | Последние 12 месяцев (LTM, TTM) или следующие 12 месяцев (NTM). Так считают показатели за «скользящий» год, а не за календарный | <code>LTM = Год<sub>прошлый</sub> + YTD<sub>тек</sub> − YTD<sub>прош</sub></code><br><span class="fx">где: YTD — с начала года до отчётной даты. Берём прошлый год, добавляем текущий YTD и вычитаем YTD прошлого года. Получаем последние 12 месяцев</span> |
| **M&A** | Mergers & Acquisitions | Слияния и поглощения компаний. Слияние — две компании становятся одной, поглощение — одна покупает другую |  |
| **MAC / MAE** | Material Adverse Change / Effect | Условие, по которому покупатель может отказаться от сделки, если случится существенное негативное событие. Например, пожар на главном заводе до закрытия сделки |  |
| **MoM / MOIC** | Multiple of Money / Multiple on Invested Capital | Во сколько раз выросли вложенные деньги. Вложили 100, получили 250: MoM равен 2,5× | <code>MOIC = Выручка от выхода / Вложенный капитал</code><br><span class="fx">где: Сколько раз вернулись вложения. MOIC 3x значит, что на 1 вложенный пришло 3</span> |
| **MVA** | Market Value Added | Рыночная стоимость компании минус вложенный в неё капитал. Показывает, сколько стоимости компания создала сверх вложенных в неё денег | <code>MVA = Рыночная стоимость компании − Инвестированный капитал</code><br><span class="fx">где: Сколько стоимости компания добавила сверх вложенных в неё денег</span> |
| **NAV** | Net Asset Value | Стоимость чистых активов: что останется, если из имущества вычесть долги. Как стоимость квартиры за вычетом остатка ипотеки | <code>NAV = Активы − Обязательства</code><br><span class="fx">где: Для фонда: стоимость активов по рынку минус долги. На пай: NAV / число паёв</span> |
| **NBO / BO** | (Non-) Binding Offer | Предложение о покупке: необязывающее (NBO) или обязывающее (BO). Необязывающее — это «пока намерение», от него можно отказаться. Обязывающее — это уже обещание, за отказ от которого могут быть последствия |  |
| **NCI** | Non-Controlling Interest | Доли меньшинства: часть дочерней компании, которая принадлежит другим владельцам, а не материнской компании. Например, материнская компания владеет 80% дочерней, а остальные 20% — это NCI |  |
| **NDA** | Non-Disclosure Agreement | Соглашение о конфиденциальности: стороны обещают не раскрывать полученные сведения. Его подписывают до того, как покупатель увидит внутренние данные компании |  |
| **Net Debt** |  | Чистый долг = Долг − Денежные средства. Если у тебя долг 100 и 30 на счёте, то чистый долг равен 70: на столько ты реально должен | <code>Net Debt = Долг − Деньги и эквиваленты</code><br><span class="fx">где: Долг — кредиты и облигации. Деньги вычитаем, потому что их можно использовать для погашения</span> |
| **NIM** | Net Interest Margin | Чистая процентная маржа банка: «наценка» банка на разнице между ставками по кредитам и по депозитам. Банк платит вкладчикам 8%, берёт с заёмщиков 12%, и разница в 4% — его маржа | <code>NIM = (Процентные доходы − Процентные расходы) / Активы, приносящие доход</code><br><span class="fx">где: Чистая процентная маржа банка: сколько он зарабатывает на разнице между ставками по кредитам и депозитам</span> |
| **NOPAT** | Net Operating Profit After Tax | Операционная прибыль после налога: EBIT × (1 − t). Здесь t — налоговая ставка. Показывает, сколько останется от прибыли основной работы после уплаты налога, если бы долга не было | <code>NOPAT = EBIT × (1 − t)</code><br><span class="fx">где: EBIT — операционная прибыль. t — ставка налога. Прибыль после налога, но без учёта долга</span> |
| **NPL** | Non-Performing Loans | Проблемные кредиты: те, по которым заёмщик перестал платить. Обычно так называют кредиты с просрочкой больше 90 дней | <code>NPL ratio = Просроченные кредиты (90+ дней) / Кредитный портфель</code><br><span class="fx">где: Доля кредитов, по которым платежи просрочены более 90 дней</span> |
| **NPV** | Net Present Value | Чистая приведённая стоимость: сегодняшняя стоимость будущих денег минус вложения. Если NPV больше нуля, проект приносит больше, чем стоит, и в него стоит вкладываться | <code>NPV = Σ CF<sub>t</sub> / (1+r)<sup>t</sup> − I<sub>0</sub></code><br><span class="fx">где: CF<sub>t</sub> — поток года t. r — ставка дисконтирования. I<sub>0</sub> — начальные вложения. NPV>0 значит проект выгоден</span> |
| **NWC** | Net Working Capital | Чистый оборотный капитал: деньги, которые «застряли» в повседневной работе (запасы и долги клиентов минус долги перед поставщиками). Это деньги, которыми компания «кредитует» собственный бизнес | <code>NWC = Дебиторка + Запасы − Кредиторка</code><br><span class="fx">где: Оборотные операционные активы минус операционные обязательства. Рост NWC «замораживает» деньги</span> |
| **OPEX** | Operating Expenses | Операционные расходы: траты на повседневную работу. Зарплаты, аренда, электричество, реклама | <code>OPEX = SG&A + R&D + Прочие операционные расходы</code><br><span class="fx">где: Текущие расходы на ведение бизнеса, без капитальных затрат</span> |
| **P/B** | Price to Book | Капитализация / балансовый собственный капитал. Главный мультипликатор для банков. Показывает, во сколько раз рынок оценивает компанию дороже, чем стоят её собственные деньги по балансу | <code>P/B = Капитализация / Балансовый капитал</code><br><span class="fx">где: Балансовый капитал — активы минус обязательства. P/B<1 значит, что рынок оценивает компанию ниже книжной стоимости</span> |
| **P/E** | Price to Earnings | Капитализация / чистая прибыль (= цена / EPS). Показывает, за сколько лет прибыли окупится покупка компании. Капитализация — это цена всех акций компании на бирже. P/E равно 10: цена в десять раз больше годовой прибыли | <code>P/E = Цена акции / EPS = Капитализация / Чистая прибыль</code><br><span class="fx">где: Сколько лет прибыли содержится в цене. EPS — прибыль на акцию</span> |
| **P/S** | Price to Sales | Капитализация / выручка. Подходит для убыточных и быстрорастущих компаний. Выручка — все деньги от продаж, до вычета расходов. Прибыли у таких компаний ещё нет, поэтому сравнивают по выручке | <code>P/S = Капитализация / Выручка</code><br><span class="fx">где: Во сколько раз цена компании больше годовой выручки</span> |
| **Payback** |  | Срок окупаемости: за сколько времени вложения вернутся. Потратил 100 и получаешь по 25 в год: окупишься за 4 года | <code>Payback = Инвестиции / Годовой денежный поток</code><br><span class="fx">где: При равных потоках. Показывает, за сколько лет вложения вернутся (без учёта дисконтирования)</span> |
| **PE (Private Equity)** |  | Фонды прямых инвестиций: они покупают компании, чтобы развить их и потом продать дороже. Похоже на покупку старой квартиры, ремонт и перепродажу, но с целыми компаниями |  |
| **PEG** | P/E to Growth | P/E, делённый на темп роста EPS. Помогает понять, не переплачиваешь ли за быстрый рост. Меньше — лучше | <code>PEG = P/E / Темп роста EPS (в %)</code><br><span class="fx">где: P/E скорректирован на рост прибыли. Около 1 — справедливо, ниже — дёшево</span> |
| **PI** | Profitability Index | Индекс прибыльности: PV потоков / инвестиции. PV — сегодняшняя стоимость будущих денег. Если индекс больше 1, проект окупается и приносит прибыль | <code>PI = PV будущих потоков / Начальные инвестиции</code><br><span class="fx">где: PV — приведённая стоимость потоков. PI>1 значит проект выгоден. Нужен при ограниченном бюджете</span> |
| **PIK** | Payment-in-Kind | Проценты, которые не выплачивают, а прибавляют к сумме долга. Сейчас платить легче, но долг растёт: на следующий год проценты начислят уже на большую сумму |  |
| **Pitchbook** |  | Презентация банка для клиента: идея сделки, оценка, аналоги. Так банк «продаёт» клиенту свою идею и показывает, почему сделка выгодна |  |
| **Poison pill** | Shareholder rights plan | Защита цели от поглощения: если покупатель набрал акций больше порога, остальные акционеры получают право купить акции со скидкой. Доля покупателя размывается, и враждебная покупка теряет смысл. «Ядовитая таблетка» |  |
| **Precedent transactions** |  | Сделки-аналоги: мультипликаторы, по которым прошли прошлые сделки M&A. Как узнать цену квартиры по тому, за сколько недавно продали похожие в этом доме | <code>Цена = Метрика цели × Мультипликатор прошлых сделок</code><br><span class="fx">где: Похоже на Comps, но мультипликаторы взяты из реальных сделок M&A (включают премию за контроль)</span> |
| **RAB** | Regulatory Asset Base | Регулируемая база активов: стоимость имущества (сетей, инфраструктуры), от которой государство считает допустимую прибыль. Например, у электросетей тариф устанавливает государство, чтобы владелец получал разумную доходность от стоимости сетей | <code>Выручка = RAB × Норма доходности + Амортизация + Расходы</code><br><span class="fx">где: RAB — регулируемая база активов. Регулятор разрешает получать доход на эту базу</span> |
| **Recovery rate** |  | Доля номинала долга, которую кредитор вернёт при дефолте. Если из долга 100 вернули 40, recovery rate равен 40% | <code>Recovery = Возврат при дефолте / Номинал долга</code><br><span class="fx">где: Доля долга, которую удалось вернуть</span> |
| **Rf** | Risk-free rate | Безрисковая ставка: доходность вложений, в которых риск практически отсутствует. Обычно это доходность государственных облигаций | <code>Rf ≈ Доходность госбумаг</code><br><span class="fx">где: Берут доходность ОФЗ/Treasuries на срок, близкий к горизонту проекта</span> |
| **RI** | Residual Income | Остаточная прибыль: ЧП − Ke × Капитал (то, что осталось после того, как акционерам заплатили «положенную» доходность). ЧП — чистая прибыль, Ke — доходность, которую ждут акционеры. Если результат положительный, компания зарабатывает больше, чем от неё требуют | <code>RI = Чистая прибыль − Ke × Балансовый капитал</code><br><span class="fx">где: Ke — стоимость собственного капитала. Прибыль сверх требуемой акционерами доходности</span> |
| **ROA** | Return on Assets | Чистая прибыль / активы. Для банков нормой считается 1–3%. Показывает, сколько прибыли приносит каждый рубль имущества компании | <code>ROA = Чистая прибыль / Активы</code><br><span class="fx">где: Эффективность использования всех активов</span> |
| **ROCE** | Return on Capital Employed | EBIT / (активы − краткосрочные обязательства). Показывает, сколько операционной прибыли приносит весь капитал, работающий в компании | <code>ROCE = EBIT / (Активы − Краткосрочные обязательства)</code><br><span class="fx">где: Доходность капитала, задействованного в бизнесе, до налогов</span> |
| **ROE** | Return on Equity | Чистая прибыль / собственный капитал. Показывает доходность денег акционеров. Вложили 100, прибыль 15: ROE равен 15% | <code>ROE = Чистая прибыль / Собственный капитал</code><br><span class="fx">где: Сколько прибыли на рубль капитала акционеров</span> |
| **ROIC** | Return on Invested Capital | NOPAT / инвестированный капитал. Если ROIC > WACC, компания создаёт стоимость. Проще говоря, если бизнес зарабатывает на вложенные деньги больше, чем стоят эти деньги, он выгоден | <code>ROIC = NOPAT / (Долг + Капитал − Деньги)</code><br><span class="fx">где: NOPAT — операционная прибыль после налога. В знаменателе — инвестированный капитал</span> |
| **Run-rate** |  | Годовой показатель, который получают, умножив результат последнего периода (квартал × 4). Например, квартальная выручка 25 даёт run-rate 100 в год. Это грубая оценка «если так пойдёт и дальше» | <code>Run-rate = Показатель за период × (12 / Месяцев в периоде)</code><br><span class="fx">где: Например, выручка за месяц × 12 даёт годовой run-rate</span> |
| **RWA** | Risk-Weighted Assets | Активы банка, взвешенные на риск (чем рискованнее актив, тем больше вес). На них делят капитал при расчёте коэффициентов капитала. Кредит надёжному заёмщику «весит» меньше, чем рискованному | <code>RWA = Σ Актив<sub>i</sub> × Вес риска<sub>i</sub></code><br><span class="fx">где: Каждый актив умножается на вес риска (например, госбумаги 0%, корпоративные кредиты 100%)</span> |
| **Sell-side / Buy-side** |  | Консультирование продавца (sell-side) или покупателя (buy-side) в сделке; также так называют брокеров (sell-side) и фонды (buy-side). Sell-side продаёт услуги и идеи, buy-side покупает ценные бумаги |  |
| **SG&A** | Selling, General & Administrative | Коммерческие и управленческие расходы: на продажи и на содержание офиса и управления. Например, реклама, зарплата менеджеров и бухгалтеров |  |
| **SOTP** | Sum of the Parts | Оценка по частям: каждую часть бизнеса оценивают отдельно и складывают. Как оценить дом, оценив отдельно каждую квартиру | <code>Стоимость = Σ (Метрика<sub>i</sub> × Мультипликатор<sub>i</sub>)</code><br><span class="fx">где: Каждый бизнес-сегмент оценивается своим мультипликатором, результаты суммируются</span> |
| **SPA** | Share Purchase Agreement | Договор купли-продажи акций. Главный документ сделки, в нём цена, условия и гарантии |  |
| **SPO** | Secondary Public Offering | Повторная продажа акций компании, которая уже торгуется на бирже. Например, компания хочет собрать ещё денег и выпускает дополнительные акции |  |
| **Squeeze-out** |  | Принудительный выкуп оставшихся акций покупателем с долей более 95%. Мелкие владельцы обязаны продать свои акции, чтобы не оставалось «хвостика» |  |
| **Synergies** |  | Синергии: дополнительная стоимость, которая появляется от объединения компаний. Например, две компании сливаются и сокращают общие расходы: вместе получается выгоднее, чем по отдельности | <code>Value = PV(экономии затрат + прироста выручки) − Затраты на интеграцию</code><br><span class="fx">где: PV — приведённая стоимость. Эффект от объединения двух компаний</span> |
| **Teaser** |  | Короткое анонимное описание компании, которое рассылают потенциальным покупателям. Название скрыто, нужно лишь, чтобы заинтересовать. Как объявление «продаётся бизнес в сфере…» без адреса |  |
| **Tender offer** |  | Публичное предложение ко всем акционерам: продайте нам свои акции по этой цене. Как объявление «куплю у всех желающих по такой-то цене до такой-то даты» |  |
| **Term Loan A / B** | TLA / TLB | Старший кредит. Кредит A амортизируется (гасится частями) и обычно выдан банками. Кредит B почти не амортизируется и выдан инвесторами. Старший значит, что его возвращают первым. Кредит B дороже, потому что основную сумму отдают в конце |  |
| **TSR** | Total Shareholder Return | Полная доходность акционера: рост цены акции + дивиденды. Это всё, что владелец акции заработал: и на подорожании, и на выплатах | <code>TSR = (P<sub>кон</sub> − P<sub>нач</sub> + Дивиденды) / P<sub>нач</sub></code><br><span class="fx">где: P — цена акции в конце и в начале периода. Совокупный доход акционера: рост цены плюс дивиденды</span> |
| **TV** | Terminal Value | Терминальная (постпрогнозная) стоимость: стоимость бизнеса за пределами прогнозного периода. Прогноз обычно делают на 5–10 лет, а компания живёт дальше, и эту «остальную жизнь» оценивают одной суммой | <code>TV = FCF<sub>n</sub> × (1+g) / (WACC − g)</code><br><span class="fx">где: FCF<sub>n</sub> — поток последнего прогнозного года. g — вечный рост. WACC — ставка дисконтирования (модель Гордона)</span> |
| **VDR** | Virtual Data Room | Виртуальная комната данных: закрытое онлайн-хранилище документов для due diligence. Покупатели заходят туда и изучают документы, а продавец видит, кто что открывал |  |
| **WACC** | Weighted Average Cost of Capital | Средневзвешенная стоимость капитала: средняя цена всех денег компании, и заёмных, и собственных. Заёмные деньги стоят процента по кредиту, собственные — доходности, которую ждут владельцы. Их усредняют по долям | <code>WACC = E/(D+E) × Ke + D/(D+E) × Kd × (1−t)</code><br><span class="fx">где: E — капитал, D — долг. Ke — стоимость капитала, Kd — стоимость долга, t — налог. Средняя цена всех источников финансирования</span> |
| **Waterfall** |  | Очерёдность выплат кредиторам и акционерам, когда делят деньги или компания банкротится. «Водопад»: деньги стекают сверху вниз, и нижние получают только то, что осталось после верхних | <code>Выплата = по очереди: долг → преференции → доходы остальных</code><br><span class="fx">где: Распределение денег по приоритету. Следующий уровень получает деньги, только когда предыдущий полностью выплачен</span> |
| **WC peg** |  | Нормальный уровень оборотного капитала, от которого корректируют цену сделки. Если на момент закрытия оборотных денег меньше нормы, цену снижают, если больше — повышают | <code>Корректировка цены = NWC на закрытие − WC peg</code><br><span class="fx">где: WC peg — согласованный уровень оборотного капитала. Недостаток снижает цену, избыток повышает</span> |
| **YTM** | Yield to Maturity | Доходность к погашению: сколько заработает покупатель облигации, если продержит её до конца срока. Выражается в процентах годовых | <code>P = Σ C / (1+YTM)<sup>t</sup> + N / (1+YTM)<sup>n</sup></code><br><span class="fx">где: P — цена облигации. C — купон. N — номинал. n — срок. YTM — ставка, при которой приведённые платежи равны цене. Подбирается итерациями</span> |
| **Дефолт** |  | Неисполнение обязательств по долгу: компания не выплатила купон или не погасила долг. Купон — регулярный процентный платёж по облигации. Проще говоря, должник не заплатил вовремя |  |
| **КБД** | Кривая бескупонной доходности | Кривая доходности ОФЗ (ЦБ, Мосбиржа): показывает, какую доходность дают госбумаги на разные сроки. Это «эталон» безрисковой ставки для каждого срока, от которого отсчитывают ставки остальных бумаг |  |
| **Квал** | Квалифицированный инвестор | Особый статус, который открывает доступ к сложным инструментам. Его присваивают по критериям ЦБ (размер активов, опыт сделок, образование и др.). Считается, что такой человек лучше понимает риски |  |
| **Н1** | Норматив достаточности капитала | Требование ЦБ к капиталу банков. Банк обязан держать собственных денег не меньше определённой доли от своих рисковых активов, чтобы выдержать потери | <code>Н1 = Капитал банка / RWA</code><br><span class="fx">где: Норматив достаточности капитала ЦБ. Чем выше, тем устойчивее банк</span> |
| **Covenant-lite** | Кредит без финансовых тестов | Кредит без регулярных (maintenance) ковенантов, остаются только условия при действии (incurrence). | |
| **IC memo** | Investment committee memo | Документ для инвестиционного комитета фонда: тезис, оценка, риски, доходность. | |
| **LIFO reserve** | Резерв LIFO | Разница между запасами по FIFO и по LIFO. Нужна, чтобы пересчитать отчёт американской компании в FIFO. | <code>Запасы FIFO = Запасы LIFO + LIFO reserve</code> |
| **Make-whole** | Компенсация при досрочном погашении | Платёж, равный приведённой стоимости всех недополученных платежей по облигации. | |
| **OID** | Original issue discount | Скидка к номиналу при выдаче долга. Добавляет доходность кредитору. | |
| **TAM / SAM / SOM** | Размеры рынка | Весь возможный рынок / часть, которую можно обслужить / часть, которую реально займёшь. | |
| **ИИС** | Индивидуальный инвестиционный счёт | Брокерский счёт с налоговыми льготами для частного инвестора (условия и типы сверять в актуальных правилах). | |
| **НКЦ** | Национальный клиринговый центр | Клиринг и центральный контрагент на Мосбирже: гарантирует исполнение сделок. | |
| **НРД** | Национальный расчётный депозитарий | Хранит ценные бумаги и проводит расчёты по сделкам. | |
| **Спред (bid-ask)** | Разница котировок | Разница между лучшей ценой продажи и покупки: скрытая стоимость сделки. | <code>Spread = Ask − Bid</code> |
| **НКД** | Накопленный купонный доход | Часть купона, которая набежала с последней выплаты до сегодняшнего дня. Если купон платят раз в полгода, то при покупке облигации через три месяца после выплаты покупатель компенсирует продавцу набежавшую половину | <code>НКД = Купон × Дней с даты выплаты / Дней в купонном периоде</code><br><span class="fx">где: Купон — размер выплаты за период. Часть купона, накопленная продавцом облигации</span> |
| **ОФЗ** | Облигации федерального займа | Облигации, которые выпускает государство РФ. Государство берёт у людей и организаций в долг и обещает вернуть с процентами. Считаются самыми надёжными в рублях |  |
| **ПДН** | Показатель долговой нагрузки | Какая доля доходов заёмщика уходит на платежи по кредитам (его регулирует ЦБ). Если человек зарабатывает 100 и платит по кредитам 40, ПДН равен 40%. Чем он выше, тем рискованнее для банка | <code>ПДН = Платежи по долгам в месяц / Доход в месяц</code><br><span class="fx">где: Какую часть дохода клиент тратит на обслуживание всех кредитов</span> |
| **РСБУ** | Российские стандарты бухучёта | Российские правила, по которым компании ведут бухгалтерский учёт и составляют отчётность. Нужны для налогов и отчётов внутри страны, а МСФО — для сравнения с зарубежными компаниями |  |
| **ФСО** | Федеральные стандарты оценки | Стандарты оценочной деятельности РФ. Это обязательные правила, по которым оценщики определяют стоимость имущества и бизнеса |  |
