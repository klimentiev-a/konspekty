# Шпаргалка 4. Акции и рынок
short: Виды акций, дивиденды, оценка акции, доходность, ордера, индексы, short и маржа, корпоративные действия, рыночная эффективность, поведенческие ошибки

> **Суть.** Акция — доля в капитале; её цена отражает ожидаемые денежные потоки и риск. Числа в примерах вымышлены. Подробнее: [Рынки капитала](#learn/rynki-kapitala), [Организация рынков](#learn/organizatsiya-rynkov), [Российский рынок: инфраструктура](#learn/organizatsiya-rynkov).

> **За минуту.**
> 1. Обыкновенные акции дают голос и дивиденды, привилегированные — приоритет в дивидендах и при ликвидации, обычно без голоса.
> 2. Гордон: `P = D₁ / (Re − g)`, Re — стоимость собственного капитала, g — рост дивиденда.
> 3. Доходность = (Цена продажи − Цена покупки + Дивиденды) / Цена покупки.
> 4. Капитализация = Цена × Число акций.
> 5. Короткая продажа (short) — продажа взятых в долг бумаг в расчёте на падение.
> 6. Гипотеза эффективного рынка: цена уже отражает доступную информацию.

## 1. Виды бумаг

| Бумага | Суть |
|---|---|
| Депозитарная расписка (ADR — American depositary receipt, GDR — global depositary receipt) | Представляет акции иностранной компании |
| ETF (exchange traded fund) / БПИФ (биржевой паевой инвестиционный фонд) | Фонд на бирже, повторяет индекс или корзину |
| REIT (real estate investment trust, инвестиционный фонд недвижимости) | Доля в недвижимости |
| Варрант (warrant) | Право купить акцию по фиксированной цене |

## 2. Показатели акции

| Показатель | Формула |
|---|---|
| EPS (earnings per share, прибыль на акцию) | Чистая прибыль / Среднее число акций |
| P/E (price to earnings) | Цена / EPS |
| P/B (price to book) | Цена / Балансовая стоимость на акцию |
| Дивидендная доходность | DPS (dividend per share, дивиденд на акцию) / Цена |
| Коэффициент выплат (payout ratio) | DPS / EPS |
| Free float | Доля акций в свободном обращении |

Пример: цена 250 ₽, EPS 25 ₽, DPS 10 ₽. P/E = 10, дивидендная доходность 4%, выплаты 40%.

## 3. Оценка акции

| Модель | Формула |
|---|---|
| Гордон (постоянный рост) | `P₀ = D₁ / (Re − g)` |
| Через прибыль | `P₀ = EPS × (P/E)` |
| Устойчивый рост | `g = ROE × (1 − коэффициент выплат)` |
| PVGO (present value of growth opportunities, стоимость роста) | `PVGO = P₀ − EPS₁ / Re` |

Пример: D₁ = 12, Re = 14%, g = 4%. P₀ = 12 / 0,10 = 120 ₽.

## 4. Дивиденды и корпоративные действия

**Календарь:** объявление → закрытие реестра → дата отсечки (ex-date: с неё покупатель дивиденд не получает, цена падает примерно на дивиденд) → выплата. (В России отсечка связана с реестром и циклом расчётов, сверить.)

| Действие | Эффект |
|---|---|
| Дробление (split) 1 → N | Цена / N, капитализация та же |
| Допэмиссия | Размывание доли (dilution) |
| Обратный выкуп (buyback) | Меньше акций, выше EPS |
| Спин-офф (spin-off) | Акционеры получают акции выделенной компании |
| Оферта | См. [Сделки в России](#learn/sdelki-v-rossii) |

**Права на допэмиссию (rights issue)** — акционеры покупают новые акции со скидкой пропорционально доле. `TERP = (N × P + n × Pподп) / (N + n)` (TERP, theoretical ex-rights price — теоретическая цена после размещения; N, P — старые акции и цена, n — новые, Pподп — цена подписки).

## 5. Заявки и торговля

| Понятие | Суть |
|---|---|
| Рыночная заявка | Сразу по лучшей цене |
| Лимитная | Не хуже указанной цены, может не исполниться |
| Стоп-заявка | Срабатывает при достижении цены; stop-limit превращается в лимитную |
| Стакан (order book) | Заявки на покупку (bid) и продажу (ask); спред = Ask − Bid |
| Маржинальная торговля | Покупка на деньги брокера (плечо); margin call — требование довнести залог |

**Плечо 2:** вложили 100, заняли 100, купили на 200. Рост на 10% даёт +20% на свои, падение на 10% — −20% (до комиссий и процентов).

## 6. Индексы

| Тип | Как считают |
|---|---|
| По капитализации | Вес = капитализация с учётом free float (IMOEX, S&P 500) |
| По цене | Вес пропорционален цене (Dow Jones) |
| Полной доходности (total return) | С реинвестированием дивидендов; ценовой — без |

## 7. Эффективность рынка

- **Слабая форма:** прошлые цены не предсказывают будущие. **Полусильная:** публичная информация в цене. **Сильная:** и инсайд в цене.
- **Аномалии:** размер, стоимость (value), моментум.
- **Поведенческие ошибки:** чрезмерная уверенность, якорь, неприятие потерь, стадность ([Поведенческие финансы и ESG](#learn/povedencheskie-esg)).

## Типичные ошибки

- Покупать только по низкому P/E: он может отражать риск.
- Забывать про разводнение (опционы, конвертируемые бумаги, допэмиссии).
- Сравнивать дивидендную доходность без налогов и устойчивости выплат.
- Брать плечо без запаса по марже.

## Проверь себя

**1. D₁ = 8, Re = 13%, g = 3%. Цена по Гордону?**
8 / 0,10 = 80.

**2. Цена 120, EPS 15. P/E?**
8.

**3. Что будет с ценой при сплите 1 к 5?**
Цена в 5 раз ниже, акций в 5 раз больше, капитализация та же.

**4. Чем лимитная заявка отличается от рыночной?**
Лимитная — не хуже заданной цены, но может не исполниться; рыночная — сразу по лучшей цене.

**5. Вложили 100, заняли 100, акция −15%. Убыток своих денег?**
30 на 100, то есть −30%.

**6. Что утверждает полусильная форма эффективности?**
Публичная информация уже в цене, анализ отчётов не даёт стабильного превосходства.

**7. Как buyback влияет на EPS?**
Акций меньше, EPS при той же прибыли растёт.
