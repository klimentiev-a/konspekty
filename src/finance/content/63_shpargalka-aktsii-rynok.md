# Шпаргалка 4. Акции и рынок
short: Виды акций, дивиденды, оценка акции, доходность, ордера, индексы, short и маржа, корпоративные действия, рыночная эффективность, поведенческие ошибки

> **Суть.** Акция — доля в капитале компании. Её цена определяется ожиданиями будущих денежных потоков и риском. Здесь основные понятия рынка акций: виды бумаг и сделок, расчёты доходности, дивиденды, корпоративные действия, индексы и теория эффективного рынка. Числа в примерах вымышлены. Подробнее: [Рынки капитала](#learn/rynki-kapitala), [Организация рынков](#learn/organizatsiya-rynkov), [Портфель и CAPM](#learn/portfel-capm), [Российский рынок: инфраструктура](#learn/moex-infrastruktura).

> **За минуту.**
> 1. Обыкновенные акции дают право голоса и дивиденды, привилегированные приоритет в дивидендах и ликвидации (обычно без права голоса).
> 2. Цена акции по Гордону: `P = D₁ / (Re − g)`.
> 3. Доходность акции = (Цена продажи − Цена покупки + Дивиденды) / Цена покупки.
> 4. Рыночная капитализация = Цена × Число акций.
> 5. Ордера: рыночный (по любой цене), лимитный (не хуже указанной цены), стоп.
> 6. Short — продажа взятых в долг бумаг в расчёте на падение.
> 7. Гипотеза эффективного рынка: цена уже отражает доступную информацию.

## 1. Виды акций и бумаг

| Бумага | Суть |
|---|---|
| Обыкновенная акция | Голос на собрании, дивиденды по решению собрания, остаточные права |
| Привилегированная акция | Фиксированный или приоритетный дивиденд, приоритет при ликвидации, обычно без голоса |
| Депозитарная расписка (ДР, ADR, GDR) | Бумага, представляющая акции иностранной компании |
| ETF / БПИФ | Фонд, торгуемый на бирже, повторяет индекс или корзину |
| ПИФ | Паевой инвестиционный фонд, паи |
| REIT / фонд недвижимости | Доля в недвижимости |
| Конвертируемая бумага | Облигация или акция с правом обмена на другие акции |
| Варрант | Право купить акцию по фиксированной цене |

## 2. Основные показатели акции

| Показатель | Формула |
|---|---|
| Рыночная капитализация | `Цена × Число акций в обращении` |
| Разводнённое число акций | Акции + эффект опционов и конвертируемых бумаг |
| EPS | Чистая прибыль / Среднее число акций |
| P/E | Цена / EPS |
| P/B | Цена / Балансовая стоимость на акцию |
| Дивидендная доходность | DPS / Цена |
| Коэффициент выплат | DPS / EPS |
| Доходность акции за период | `(P₁ − P₀ + D) / P₀` |
| Beta | Чувствительность к рынку (см. шпаргалку по портфелю) |
| Free float | Доля акций в свободном обращении |
| Стоимость торгов (оборот) | Цена × Объём |

Пример: цена 250 ₽, EPS 25 ₽, DPS 10 ₽. P/E = 10, дивидендная доходность 4%, коэффициент выплат 40%.

## 3. Оценка акции

| Модель | Формула |
|---|---|
| Дивидендная модель, постоянный рост (Гордон) | `P₀ = D₁ / (Re − g)` |
| Двухфазная модель | `P₀ = Σ Dt/(1 + Re)^t (период роста) + P_N/(1 + Re)^N` |
| Без роста | `P₀ = D / Re` |
| Через прибыль | `P₀ = EPS × (P/E)` |
| Устойчивый рост | `g = ROE × (1 − коэффициент выплат)` |
| Стоимость роста | `PVGO = P₀ − EPS₁ / Re` |

Пример: D₁ = 12, Re = 14%, g = 4%. P₀ = 12 / 0,10 = 120 ₽.

## 4. Дивиденды и корпоративные действия

**Календарь дивиденда:**
- **Дата объявления** — совет директоров рекомендует дивиденд.
- **Дата закрытия реестра** — владельцы на этот день получат дивиденд.
- **Дата отсечки (ex-date)** — с этого дня покупатель не получает дивиденд. Цена обычно падает примерно на размер дивиденда.
- **Дата выплаты.**

(В российской практике дата отсечки связана с реестром и циклом расчётов, сверить.)

| Действие | Суть | Эффект |
|---|---|---|
| Дробление (split) | 1 акция в N акций | Цена делится на N, капитализация не меняется |
| Консолидация (reverse split) | N акций в 1 | Цена умножается на N |
| Допэмиссия | Выпуск новых акций | Размывание доли (dilution) |
| Обратный выкуп (buyback) | Компания выкупает свои акции | Уменьшает число акций, повышает EPS |
| Бонусные акции | Выдача акций акционерам за счёт капитала | Как сплит по сути |
| Спин-офф | Выделение бизнеса в отдельную компанию | Акционеры получают акции новой |
| Оферта | Предложение выкупить акции | См. [Сделки в России](#learn/sdelki-v-rossii) |

**Права на допэмиссию (rights issue).** Текущие акционеры покупают новые акции со скидкой пропорционально доле.

**Теоретическая цена после отсечки (TERP):** `TERP = (N × P + n × Pподп) / (N + n)`.

## 5. Заявки и торговля

| Понятие | Суть |
|---|---|
| Рыночная заявка | Исполнить немедленно по лучшей цене |
| Лимитная заявка | Не хуже указанной цены; может не исполниться |
| Стоп-заявка | Активируется при достижении цены (ограничение убытка) |
| Stop-limit | Стоп, превращающийся в лимитную заявку |
| Стакан (order book) | Список заявок на покупку (bid) и продажу (ask) |
| Спред | Ask − Bid |
| Проскальзывание | Разница между ожидаемой и фактической ценой |
| Маркет-мейкер | Участник, поддерживающий котировки |
| Короткая продажа (short) | Продажа бумаг, взятых в долг, с обязательством вернуть |
| Маржинальная торговля | Покупка с заёмными деньгами брокера (плечо) |
| Margin call | Требование довнести деньги при падении залога |
| Алго-торговля, HFT | Автоматические стратегии, высокие частоты |

**Плечо.** При плече 2 прибыль и убыток удваиваются. Пример: вложили 100, взяли 100 в долг, купили на 200. Цена выросла на 10%: доход 20 на свои 100 = 20%. Цена упала на 10%: убыток 20% (до комиссий и процентов за заём).

## 6. Индексы

| Тип | Как считают |
|---|---|
| Взвешенный по капитализации | Вес = капитализация (с учётом free float), например IMOEX, S&P 500 |
| Равновзвешенный | Все акции с одинаковым весом |
| Взвешенный по цене | Вес пропорционален цене акции (Dow Jones) |
| Ценовой индекс | Не учитывает дивиденды |
| Индекс полной доходности (total return) | Учитывает реинвестирование дивидендов |

Индекс используют как бенчмарк (сравнение результата управляющего) и для индексных фондов.

## 7. Эффективность рынка и поведенческие эффекты

- **Слабая форма:** прошлые цены не помогают предсказывать будущие.
- **Полусильная:** публичная информация уже в цене.
- **Сильная:** вся информация, включая инсайд, в цене.
- **Аномалии:** эффект размера, стоимости (value), моментума, календарные эффекты.
- **Поведенческие ошибки:** чрезмерная уверенность, эффект якоря, неприятие потерь, стадное поведение, избыточная торговля (см. [Поведенческие финансы и ESG](#learn/povedencheskie-esg)).

## 8. Факторы, двигающие цену акции

- Прибыль и прогнозы, дивиденды.
- Ключевая ставка и ставки в экономике.
- Макро и отрасль (цены на сырьё, курсы валют).
- Новости компании (сделки, слияния, судебные споры).
- Потоки денег (покупки фондов, розницы).
- Ликвидность и free float.
- Настроения и геополитика.

## Типичные ошибки

- Покупать только по низкому P/E: низкий мультипликатор может отражать риск.
- Забывать про разводнение и допэмиссии.
- Сравнивать дивидендную доходность без учёта налогов и устойчивости выплат.
- Считать, что после отсечки цена «потеряла» стоимость: часть стоимости выплатили деньгами.
- Использовать плечо без запаса по марже.
- Ориентироваться на ценовой индекс при сравнении с портфелем, получающим дивиденды.

## Проверь себя

**1. Чем обыкновенная акция отличается от привилегированной?**
Обыкновенная даёт право голоса и дивиденд по решению собрания, привилегированная приоритетный или фиксированный дивиденд и приоритет при ликвидации, обычно без голоса.

**2. D₁ = 8, Re = 13%, g = 3%. Чему равна цена по Гордону?**
8 / 0,10 = 80.

**3. Цена 120, EPS 15. Чему равен P/E?**
8.

**4. Что произойдёт с ценой акции при сплите 1 к 5?**
Цена станет в пять раз ниже, число акций в пять раз больше, капитализация не изменится.

**5. Чем лимитная заявка отличается от рыночной?**
Лимитная исполняется не хуже заданной цены, но может не исполниться. Рыночная исполняется сразу по лучшей доступной цене.

**6. Что такое спред?**
Разница между лучшей ценой продажи и лучшей ценой покупки.

**7. Вложили 100, взяли 100 в долг, акция упала на 15%. Каков убыток собственных денег (без процентов)?**
Убыток 30 на 100 собственных, то есть 30%.

**8. Чем индекс полной доходности отличается от ценового?**
Он учитывает реинвестирование дивидендов.

**9. Что утверждает полусильная форма эффективности рынка?**
Вся публичная информация уже отражена в цене, анализ отчётов не даёт стабильного превосходства.

**10. Как buyback влияет на EPS?**
Число акций уменьшается, EPS при той же прибыли растёт.
