# Деньги во времени: NPV, IRR, окупаемость
short: Дисконтирование, аннуитеты, NPV, IRR, payback

> **Суть.** Рубль сегодня дороже рубля завтра: его можно вложить под процент, а инфляция (inflation) и риск (risk) «съедают» будущие деньги. Поэтому будущие потоки **дисконтируют** (discounting) — приводят к сегодняшнему дню по ставке дисконтирования r (discount rate). NPV (net present value — чистая приведённая стоимость), IRR (internal rate of return — внутренняя норма доходности) и окупаемость (payback) — три способа решить, стоит ли вкладывать в проект.

> **За минуту.**
> 1. Рубль сегодня дороже рубля завтра, поэтому будущие деньги дисконтируют.
> 2. NPV — сумма будущих потоков в сегодняшних деньгах минус вложения; больше нуля — проект выгоден.
> 3. IRR — собственная доходность проекта в % годовых; её сравнивают с WACC (средневзвешенной стоимостью капитала).
> 4. Срок окупаемости (payback) — через сколько лет вернутся вложения.

## Базовые формулы

PV (present value) — стоимость сегодня, FV (future value) — в будущем, r — годовая ставка (15% = 0,15), n — число лет.

```f
FV = PV × (1 + r)^n                 — будущая стоимость
PV = FV / (1 + r)^n                 — приведённая (текущая) стоимость
DF = 1 / (1 + r)^t                  — коэффициент дисконтирования
```

DF (discount factor) — множитель, переводящий будущую сумму в сегодняшнюю.

**Пример.** 1 000 ₽ через 3 года при r = 15%: PV = 1 000 / 1,15³ = 1 000 / 1,521 = **657 ₽**.

### Аннуитет и перпетуитет

Аннуитет (annuity) — одинаковые платежи через равные промежутки (ипотека, аренда). Перпетуитет (perpetuity) — такие же платежи бесконечно.

```f
Аннуитет (C каждый год, n лет):   PV = C × [1 − (1 + r)^−n] / r
Перпетуитет (вечно, без роста):   PV = C / r
Перпетуитет с ростом g (Гордон):  PV = C₁ / (r − g)       (только если r > g!)
```

C — платёж, g — темп его роста (growth). В формуле Гордона (Gordon growth formula) в числителе поток **следующего** года: C₁ = C₀ × (1 + g).

Пример C / r: квартира приносит 100 тыс. ₽ в год, вклад даёт 10% → квартира «стоит» 100 / 0,1 = 1 000 тыс. ₽. С ростом g знаменатель меньше и стоимость выше; при g ≥ r формула ломается.

### Номинальные и реальные ставки (Фишер)

Номинальная ставка (nominal rate) — из договора; реальная (real rate) — после инфляции π.

```f
(1 + r_ном) = (1 + r_реал) × (1 + π)
r_реал ≈ r_ном − π                   (для небольших значений)
```

Правило: **номинальные потоки дисконтируй по номинальной ставке, реальные по реальной**. Смешивать нельзя.

### Правило 72

По правилу 72 (Rule of 72) деньги удваиваются примерно за **72 / (ставка в %)** лет: при 12% ~6 лет, при 16% ~4,5 года.

## Критерии инвестиционных решений

### NPV — чистая приведённая стоимость

```f
NPV = Σ CFₜ / (1 + r)^t  − I₀        (t = 1…n)
```

CFₜ — денежный поток (cash flow) года t, I₀ — начальная инвестиция.

- **NPV > 0** → проект создаёт стоимость (принимаем); **NPV < 0** → разрушает.
- NPV показывает, **на сколько рублей сегодня** проект делает компанию дороже.
- NPV **аддитивен**: NPV(A + B) = NPV(A) + NPV(B). Поэтому это главный критерий.

### IRR — внутренняя норма доходности

«Встроенная» доходность проекта в % годовых: ставка, при которой NPV = 0.
```f
0 = Σ CFₜ / (1 + IRR)^t  − I₀
```

- **IRR > WACC** → проект выгоден. WACC (weighted average cost of capital) — средняя цена денег компании (долга и капитала владельцев), минимальная требуемая доходность.
- Считается подбором (в Excel `ВСД` / `IRR`, для неравных дат `ЧИСТВНДОХ` / `XIRR`): общей формулы нет.

**Недостатки IRR (любят спрашивать):**
1. **Несколько IRR**, если знак потоков меняется больше одного раза (например, затраты на рекультивацию в конце горного проекта).
2. **Масштаб**: IRR 50% на 1 млн хуже, чем 20% на 1 млрд. Для взаимоисключающих проектов смотри на NPV.
3. **Реинвестирование** (reinvestment): предполагается, что промежуточные потоки вкладываются по самой IRR — нереалистично при высоких IRR. Решение — **MIRR** (modified IRR, модифицированная IRR) с реалистичной ставкой реинвестирования:
```f
MIRR = (FV положительных потоков по ставке реинвестирования / PV затрат по ставке финансирования)^(1/n) − 1
```

### Срок окупаемости (Payback)

- **Простой**: через сколько лет накопленный поток станет ≥ 0.
- **Дисконтированный** (discounted payback): то же по дисконтированным потокам; всегда дольше простого.
```f
Payback = (последний год с отрицательной накопленной суммой) + |накопленная сумма в этом году| / поток следующего года
```
Минус: игнорирует всё, что приходит после окупаемости.

### PI — индекс прибыльности

PI (profitability index) — сегодняшняя отдача на каждый вложенный рубль.

```f
PI = PV будущих потоков / I₀          (PI > 1 ⇔ NPV > 0)
```
Полезен при **ограниченном бюджете** (capital rationing): ранжируй проекты по убыванию PI.

## Mid-year convention (дисконтирование середины года)

Потоки приходят **в течение года**, а не 31 декабря, поэтому период дисконтирования берут **t − 0,5**: 0,5; 1,5; 2,5… Деньги приходят в среднем раньше, стоимость выше примерно в (1 + r)^0,5 раза.

## Пример расчёта (на пальцах)

Инвестиция 1 000, потоки 300 / 400 / 500 / 300, ставка 12%.

| Год | Поток | DF = 1/1,12^t | PV |
|---|---|---|---|
| 0 | −1 000 | 1,000 | −1 000 |
| 1 | 300 | 0,893 | 268 |
| 2 | 400 | 0,797 | 319 |
| 3 | 500 | 0,712 | 356 |
| 4 | 300 | 0,636 | 191 |
| | | **NPV** | **+133** |

IRR ≈ 18,0% (> 12% → принимаем). Простой payback: после 2-го года накоплено −300, в 3-й год +500 → 2 + 300 / 500 = **2,6 года**.

## Проверь себя

**1. Почему NPV считают главным критерием, а не IRR?**
NPV показывает прирост стоимости в рублях и аддитивен. IRR не видит масштаба, может иметь несколько значений при смене знака потоков и предполагает реинвестирование по самой IRR.

**2. Что стоит в числителе формулы Гордона и когда формула не работает?**
Поток следующего года C₁ = C₀ × (1 + g). Работает только при r > g, иначе стоимость «взрывается»: нельзя вечно расти быстрее, чем стоят деньги.

**3. Сколько сегодня стоят 1 000 ₽, которые придут через 2 года, при ставке 10%? А аннуитет 100 ₽ в год на 5 лет?**
1 000 / 1,21 ≈ 826,4 ₽. Аннуитет: 100 × [1 − 1,1^−5] / 0,1 = 100 × 3,791 ≈ 379,1 ₽ — меньше 500, дальние платежи дешевле.

**4. Поток в этом году 100, рост 4% вечно, ставка 12%. Чему равна стоимость по Гордону?**
C₁ = 104; PV = 104 / 0,08 = 1 300. Типичная ошибка — взять 100 и получить 1 250.

**5. Номинальная ставка 16%, инфляция 6%. Какова реальная ставка точно и приближённо?**
Точно: 1,16 / 1,06 − 1 ≈ 9,4%; приближённо 10%. При высоких ставках, как в России, считай точно.

**6. Инвестиция 1 000, потоки по 400 в течение 3 лет, ставка 10%. Посчитай NPV и оцени IRR.**
400 × 2,487 − 1 000 ≈ −5,3. NPV чуть ниже нуля → IRR чуть ниже 10% (≈ 9,7%), проект отклоняем.

**7. Как спросят на собеседовании: «Что лучше: 100 ₽ сейчас или 115 ₽ через год, если ставка 12%?»**
115 / 1,12 ≈ 102,7 > 100 — лучше 115 через год (или: 100 под 12% дадут лишь 112). Ответ меняется при ставке выше 15%.

**8. Как спросят на собеседовании: «Что такое mid-year convention и как она меняет стоимость?»**
Потоки дисконтируют на середину года (0,5; 1,5; 2,5…), так как деньги приходят в течение года. Каждый поток дороже в (1 + r)^0,5 раза: при 12% ≈ +5,8%.
