# Шпаргалка 6. Деривативы: форварды, фьючерсы, опционы, свопы
short: Форвард и фьючерс, цена по no-arbitrage, опционы call и put, выплаты, паритет, биномиальная модель, Black-Scholes, греки, стратегии, свопы, хеджирование

> **Суть.** Деривативы (derivatives, производные инструменты) — контракты, цена которых зависит от базового актива (акции, валюты, товара, ставки). Нужны для хеджирования (hedging), спекуляции, арбитража. Подробнее: [Деривативы](#learn/derivativy).

> **За минуту.**
> 1. Форвард и фьючерс — обязательство купить или продать актив в будущем по цене, зафиксированной сегодня.
> 2. Цена форварда: `F = S × (1 + r)^T`.
> 3. Колл (call) — право купить, пут (put) — продать по цене исполнения (strike) K; премия — цена права.
> 4. Выплата колла `max(S_T − K, 0)`, пута `max(K − S_T, 0)`.
> 5. Паритет: `C − P = S − K / (1 + r)^T` (без дивидендов).
> 6. Black–Scholes оценивает европейский опцион через волатильность.

## 1. Форварды и фьючерсы

| Понятие | Суть |
|---|---|
| Форвард (forward) | Внебиржевой договор поставки по цене, зафиксированной сегодня |
| Фьючерс (futures) | Биржевой стандартный форвард с клирингом и ежедневной переоценкой |
| Начальная и вариационная маржа | Залог и ежедневный перевод прибыли или убытка |
| Базис (basis) | `Спот − Фьючерс`, к экспирации сходится к нулю |
| Контанго (contango) / бэквордация (backwardation) | Фьючерс дороже / дешевле спота |

**Цена форварда (no-arbitrage):**

```f
Без доходов и хранения:  F = S × (1 + r)^T
С дивидендами/купонами:  F = (S − PV(доходы)) × (1 + r)^T
Непрерывно:              F = S × e^((r + u − q) × T)
Валюта (паритет):        F = S × (1 + r_внутр)^T / (1 + r_иностр)^T
```

u — издержки хранения, q — доходность актива (дивиденд, удобство владения).

Пример: S = 100, r = 10%, T = 1: F = 110.

**Хеджирование:** производитель продаёт фьючерс, потребитель покупает. Коэффициент хеджа `h = ρ × σ_S / σ_F`; базисный риск остаётся.

## 2. Опционы: основы

| Понятие | Суть |
|---|---|
| Европейский / американский | Исполнение в дату экспирации / в любой момент |
| ITM / ATM / OTM (in / at / out of the money, в деньгах / на деньгах / вне денег) | Колл: S > K / S ≈ K / S < K, у пута наоборот |
| Внутренняя стоимость (intrinsic value) | Колл `max(S − K, 0)`, пут `max(K − S, 0)`; остаток премии — временная стоимость (time value) |

**Прибыль на экспирации** (риск покупателя ограничен премией, продавца — может быть большим): длинный колл `max(S − K, 0) − премия`, длинный пут `max(K − S, 0) − премия`; у короткой позиции знак обратный. Безубыточность: колл `K + премия`, пут `K − премия`.

Пример: колл K = 100, премия 5. S = 112: выплата 12, прибыль 7. S = 98: −5 (вся премия).

## 3. Факторы цены опциона

- Колл дорожает при росте S, σ, T и r; дешевеет при росте K и дивидендов.
- Пут дорожает при росте K, σ, T (обычно) и дивидендов; дешевеет при росте S и r.

## 4. Паритет и границы

**Паритет пут-колл (европейские, без дивидендов):**

```f
C + K / (1 + r)^T = P + S    ⇒    C − P = S − K / (1 + r)^T
```

Границы: `C ≥ max(S − K/(1 + r)^T, 0)`, `P ≥ max(K/(1 + r)^T − S, 0)`, `C ≤ S`, `P ≤ K`. Американский колл без дивидендов досрочно исполнять невыгодно.

## 5. Модели оценки

**Биномиальная модель (один шаг):**

```f
u = e^(σ√Δt),  d = 1/u
p = (e^(rΔt) − d) / (u − d)     (рискнейтральная вероятность)
C = e^(−rΔt) × [p × C_u + (1 − p) × C_d]
```

**Black–Scholes–Merton (европейский колл, актив с дивидендной доходностью q):**

```f
C = S e^(−qT) N(d1) − K e^(−rT) N(d2)
P = K e^(−rT) N(−d2) − S e^(−qT) N(−d1)
d1 = [ln(S/K) + (r − q + σ²/2) T] / (σ√T)
d2 = d1 − σ√T
```

N(·) — стандартное нормальное распределение. Допущения: логнормальная цена, постоянные σ и r.

**Подразумеваемая волатильность (implied volatility)** — σ, при которой модель даёт рыночную цену; её зависимость от страйка — улыбка. Индексы страха: VIX (CBOE Volatility Index, опционы на S&P 500), в России RVI (Russian Volatility Index).

## 6. Греки

| Грек | Что измеряет | Смысл |
|---|---|---|
| Дельта (Δ) | Изменение цены опциона при ΔS = 1 | Колл 0…1, пут −1…0, ATM колл ≈ 0,5 |
| Гамма (Γ) | Изменение дельты | Максимальна у ATM |
| Вега (ν) | Чувствительность к σ (на 1 п.п.) | > 0 у длинных |
| Тета (Θ) | Изменение со временем | Обычно < 0 у длинных |
| Ро (ρ) | Чувствительность к ставке | У колла > 0 |

**Дельта-хеджирование:** суммарная дельта = 0, `Число акций = −Δ × число опционов`; из-за гаммы нужна перебалансировка.

## 7. Стратегии

| Стратегия | Состав | Когда |
|---|---|---|
| Покрытый колл (covered call) | Акция + проданный колл | Боковик, берём премию |
| Защитный пут (protective put) | Акция + купленный пут | Страховка от падения |
| Бычий спред (bull spread) | Купить колл K₁, продать колл K₂ > K₁ | Умеренный рост; медвежий — на путах |
| Стрэддл (straddle) / стрэнгл (strangle) | Колл + пут с одним K / с разными OTM | Сильное движение; стрэнгл дешевле |
| Воротник (collar) | Акция + купить пут + продать колл | Дешёвая защита |

## 8. Свопы

- **Процентный (IRS, interest rate swap):** фиксированная ставка на плавающую на один номинал.
- **Валютный (currency swap):** платежи в разных валютах, включая номиналы.
- **CDS (credit default swap, кредитный дефолтный своп):** покупатель платит спред, при дефолте получает компенсацию.

Фиксированная ставка IRS уравнивает ноги на старте: `Фикс = (1 − DF_N) / Σ DF_t`. Должник по плавающей ставке платит фикс, получает плавающую — фиксирует стоимость долга.

## Типичные ошибки

- Считать фьючерс прогнозом: он отражает ставку и издержки хранения.
- Считать покупку колла безопасной: вне денег сгорает вся премия.
- Продавать «голые» опционы с неограниченным риском.

## Проверь себя

**1. Чем форвард отличается от фьючерса?**
Форвард внебиржевой, индивидуальный; фьючерс биржевой, стандартный, с клирингом и ежедневной маржой.

**2. S = 200, r = 8%, T = 1, без дивидендов. Форвард?**
200 × 1,08 = 216.

**3. Колл K = 50, премия 3, S = 60. Прибыль покупателя?**
10 − 3 = 7.

**4. Что такое дельта?**
Изменение цены опциона при росте цены актива на 1.

**5. Чем выгоден стрэддл?**
Сильное движение в любую сторону; убыток не больше двух премий.

**6. Что такое процентный своп?**
Обмен фиксированной ставки на плавающую на условный номинал.
