# Шпаргалка 6. Деривативы: форварды, фьючерсы, опционы, свопы
short: Форвард и фьючерс, цена по no-arbitrage, опционы call и put, выплаты, паритет, биномиальная модель, Black-Scholes, греки, стратегии, свопы, хеджирование

> **Суть.** Деривативы (производные инструменты) — контракты, цена которых зависит от другого актива (базового): акции, валюты, товара, ставки. Их используют для страховки (хеджирования), спекуляции и арбитража. Здесь формулы и логика. Числа в примерах вымышлены. Подробнее: [Деривативы](#learn/derivativy).

> **За минуту.**
> 1. Форвард и фьючерс — обязательство купить или продать актив в будущем по цене, зафиксированной сегодня.
> 2. Цена форварда: `F = S × e^((r − q) × T)` или `F = S × (1 + r)^T`.
> 3. Опцион колл (call) даёт право купить, пут (put) право продать по цене исполнения K. Премия — цена права.
> 4. Выплата колла: `max(S_T − K, 0)`, пута: `max(K − S_T, 0)`.
> 5. Паритет: `C − P = S − K / (1 + r)^T` (без дивидендов).
> 6. Black–Scholes даёт цену европейского опциона через волатильность.
> 7. Греки: дельта, гамма, вега, тета, ро.

## 1. Форварды и фьючерсы

| Понятие | Суть |
|---|---|
| Форвард | Внебиржевой договор на поставку в будущем по цене, зафиксированной сегодня |
| Фьючерс | Биржевой стандартизированный форвард с клирингом и ежедневной переоценкой (маржа) |
| Спот | Сделка с немедленной поставкой |
| Базовый актив | Акция, индекс, валюта, нефть, ставка, облигация |
| Длинная позиция (long) | Покупатель фьючерса, выигрывает при росте |
| Короткая позиция (short) | Продавец, выигрывает при падении |
| Вариационная маржа | Ежедневный перевод прибыли или убытка |
| Начальная маржа (гарантийное обеспечение) | Залог для открытия позиции |
| Базис | `Базис = Спот − Фьючерс` (иногда наоборот), сходится к нулю к экспирации |
| Конвергенция | К дате исполнения цена фьючерса стремится к споту |
| Контанго | Фьючерс дороже спота (кривая растёт) |
| Бэквордация | Фьючерс дешевле спота |
| Поставочный и расчётный | Физическая поставка или расчёт деньгами |

**Цена форварда (no-arbitrage):**

```f
Без доходов и хранения:  F = S × (1 + r)^T
С дивидендами/купонами:  F = (S − PV(доходы)) × (1 + r)^T
Непрерывно:              F = S × e^((r + u − q) × T)
Валюта (паритет):        F = S × (1 + r_внутр)^T / (1 + r_иностр)^T
```

Здесь u — издержки хранения, q — доходность актива (дивиденд, удобство владения). Валютная формула называется паритетом покрытых процентных ставок.

Пример: акция 100, ставка 10%, без дивидендов, срок 1 год. F = 100 × 1,10 = 110.

**Стоимость форварда в момент t:** `V = (F_t − F_0) / (1 + r)^(T − t)` для длинной позиции.

**Хеджирование:**
- Производитель продаёт фьючерс: фиксирует цену продажи.
- Потребитель покупает фьючерс: фиксирует цену покупки.
- Коэффициент хеджа: `h = ρ × σ_S / σ_F`. Число контрактов = `h × Объём позиции / Размер контракта`.
- Базисный риск остаётся.

## 2. Опционы: основы

| Понятие | Суть |
|---|---|
| Колл (call) | Право купить актив по цене K |
| Пут (put) | Право продать актив по цене K |
| Цена исполнения (страйк, K) | Цена, по которой можно купить или продать |
| Премия | Цена опциона |
| Европейский | Исполнение только в дату экспирации |
| Американский | Исполнение в любой момент до даты экспирации |
| ITM (in the money) | Колл: S > K, пут: S < K |
| ATM (at the money) | S ≈ K |
| OTM (out of the money) | Колл: S < K, пут: S > K |
| Внутренняя стоимость | Колл: `max(S − K, 0)`, пут: `max(K − S, 0)` |
| Временная стоимость | Премия − Внутренняя стоимость |
| Покупатель | Платит премию, риск ограничен премией |
| Продавец (writer) | Получает премию, риск может быть большим |

**Выплаты и прибыль на экспирации:**

| Позиция | Выплата | Прибыль |
|---|---|---|
| Длинный колл | `max(S − K, 0)` | `max(S − K, 0) − премия` |
| Короткий колл | `−max(S − K, 0)` | премия − `max(S − K, 0)` |
| Длинный пут | `max(K − S, 0)` | `max(K − S, 0) − премия` |
| Короткий пут | `−max(K − S, 0)` | премия − `max(K − S, 0)` |

Точка безубыточности: колл `K + премия`, пут `K − премия`.

Пример: колл K = 100, премия 5. На экспирации S = 112: выплата 12, прибыль 7. S = 98: выплата 0, убыток 5 (вся премия).

## 3. Факторы цены опциона

| Фактор растёт | Колл | Пут |
|---|---|---|
| Цена актива S | ↑ | ↓ |
| Страйк K | ↓ | ↑ |
| Волатильность σ | ↑ | ↑ |
| Время до экспирации T | ↑ | ↑ (обычно) |
| Безрисковая ставка r | ↑ | ↓ |
| Дивиденды | ↓ | ↑ |

## 4. Паритет и границы

**Паритет пут-колл (европейские, без дивидендов):**

```f
C + K / (1 + r)^T = P + S    ⇒    C − P = S − K / (1 + r)^T
```

Границы: `C ≥ max(S − K/(1 + r)^T, 0)`, `P ≥ max(K/(1 + r)^T − S, 0)`, `C ≤ S`, `P ≤ K`.

Раннее исполнение американского колла на бездивидендной акции невыгодно.

## 5. Модели оценки

**Биномиальная модель (один шаг):**

```f
u = e^(σ√Δt),  d = 1/u
p = (e^(rΔt) − d) / (u − d)     (рискнейтральная вероятность)
C = e^(−rΔt) × [p × C_u + (1 − p) × C_d]
```

**Black–Scholes–Merton (европейский колл, актив с дивидендной доходностью q):**

```f
C = S e^(−qT) N(d1) − K e^(−rT) N(d2)
P = K e^(−rT) N(−d2) − S e^(−qT) N(−d1)
d1 = [ln(S/K) + (r − q + σ²/2) T] / (σ√T)
d2 = d1 − σ√T
```

N(·) — функция стандартного нормального распределения. Допущения: логнормальная цена, постоянная волатильность и ставка, нет транзакционных издержек.

**Подразумеваемая (implied) волатильность** — σ, при которой модель даёт рыночную цену. Улыбка волатильности: implied σ зависит от страйка. Индекс страха (VIX, в РФ RVI) — ожидаемая волатильность по опционам.

## 6. Греки

| Грек | Что измеряет | Диапазон и смысл |
|---|---|---|
| Дельта (Δ) | Изменение цены опциона при изменении S на 1 | Колл 0…1, пут −1…0. ATM колл около 0,5 |
| Гамма (Γ) | Изменение дельты при изменении S | Максимальна у ATM |
| Вега (ν) | Изменение цены при изменении σ на 1 п.п. | Положительна у длинных опционов |
| Тета (Θ) | Изменение цены с течением времени | Обычно отрицательна у длинных опционов |
| Ро (ρ) | Чувствительность к ставке | Колл положительна |

**Дельта-хеджирование:** держать позицию, где суммарная дельта равна нулю. Для опциона: `Число акций = −Δ × число опционов`. Нужно перебалансировать при изменении цены (гамма).

## 7. Стратегии с опционами

| Стратегия | Состав | Когда |
|---|---|---|
| Покрытый колл | Акция + проданный колл | Ожидаете небольшой рост или боковик, получаете премию |
| Защитный пут (protective put) | Акция + купленный пут | Страховка, нижний предел убытка |
| Бычий спред | Купить колл K₁, продать колл K₂ > K₁ | Умеренный рост, ограниченный риск и доход |
| Медвежий спред | Купить пут K₂, продать пут K₁ < K₂ | Умеренное падение |
| Стрэддл | Купить колл и пут с одним K | Ожидаете сильное движение в любую сторону |
| Стрэнгл | Колл и пут с разными K (OTM) | То же, дешевле |
| Бабочка | Купить K₁ и K₃, продать 2×K₂ | Ожидаете, что цена останется рядом с K₂ |
| Воротник (collar) | Акция + купить пут + продать колл | Дёшево ограничить диапазон |

## 8. Свопы

| Своп | Суть |
|---|---|
| Процентный (IRS) | Обмен фиксированной ставки на плавающую на один номинал |
| Валютный (currency swap) | Обмен платежами в разных валютах, включая номиналы |
| Кредитный дефолтный своп (CDS) | Страховка от дефолта: покупатель платит спред, при дефолте получает компенсацию |
| Товарный своп | Фиксированная цена на плавающую |
| Total return swap | Обмен полной доходности актива на фиксированную или плавающую ставку |

**Процентный своп.** Фиксированная ставка свопа делает стоимость фиксированной и плавающей ног равной на старте: `Фикс = (1 − DF_N) / Σ DF_t` (по периодам).

**Использование:** компания с плавающим долгом покупает своп «платить фиксированную, получать плавающую», зафиксировав стоимость долга.

## 9. Деривативы на Московской бирже (кратко)

- Срочный рынок (FORTS): фьючерсы и опционы на индексы, акции, валюту, сырьё.
- Расчётные (деньгами) и поставочные контракты, ГО (гарантийное обеспечение).
- Правила, спецификации и состав инструментов смотрите на сайте биржи (сверить).
- Ограничения для неквалифицированных инвесторов на сложные продукты (сверить).

## Типичные ошибки

- Думать, что фьючерс «прогнозирует» цену: он отражает издержки хранения и ставку.
- Забывать про дивиденды в паритете.
- Считать колл «безопасным»: теряется вся премия.
- Продавать «голые» опционы без понимания неограниченного риска.
- Путать implied и историческую волатильность.
- Игнорировать маржин-коллы по фьючерсам.
- Не учитывать базисный риск в хедже.

## Проверь себя

**1. Чем форвард отличается от фьючерса?**
Форвард внебиржевой, индивидуальный, без ежедневной переоценки. Фьючерс биржевой, стандартный, с клирингом и ежедневной маржой.

**2. S = 200, r = 8%, T = 1 год, нет дивидендов. Чему равна цена форварда?**
200 × 1,08 = 216.

**3. Колл K = 50, премия 3, на экспирации S = 60. Какая прибыль покупателя?**
Выплата 10, прибыль 10 − 3 = 7.

**4. Запишите паритет пут-колл.**
C − P = S − K / (1 + r)^T.

**5. Какие факторы повышают цену и колла, и пута?**
Рост волатильности и (как правило) срока до экспирации.

**6. Что такое дельта опциона?**
Изменение цены опциона при изменении цены базового актива на единицу. ATM колл около 0,5.

**7. Что делает стратегия protective put?**
Ограничивает убыток по акции: пут гарантирует цену продажи не ниже K, цена защиты — премия.

**8. Чем стрэддл выгоден?**
Прибылен при сильном движении цены в любую сторону, убыток ограничен суммой двух премий.

**9. Что такое процентный своп?**
Обмен фиксированной ставки на плавающую на условный номинал, чтобы изменить характер процентного платежа.

**10. Что такое CDS?**
Страховка от дефолта: покупатель платит регулярный спред, при дефолте получает компенсацию.
