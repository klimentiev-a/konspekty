# Шпаргалка 1. Основы: деньги во времени, ставки, доходность
short: Будущая и приведённая стоимость, аннуитет, перпетуитет, NPV, IRR, простые и сложные проценты, номинальные и реальные ставки, доходность и риск, статистика

> **Суть.** Здесь всё, что нужно знать про деньги во времени, на одной странице: формулы, расшифровка, когда применять. Это справочник, а не учебник: за подробностями идите в основные главы. Все числа в примерах вымышлены.

> **За минуту.**
> 1. Деньги сегодня дороже денег завтра, потому что их можно вложить под процент.
> 2. FV = PV × (1 + r)^n. PV = FV / (1 + r)^n.
> 3. NPV = −I + сумма CFt / (1 + r)^t. Если NPV > 0, проект создаёт стоимость.
> 4. IRR — ставка, при которой NPV = 0.
> 5. Реальная ставка ≈ номинальная − инфляция (это приближение; точно по Фишеру: 1 + i = (1 + r)(1 + π)).
> 6. Доходность и риск идут вместе: меряют средним и стандартным отклонением.

Подробнее: [Деньги во времени, NPV, IRR](#learn/npv-irr), [Количественные методы](#learn/kolichestvennye-metody).

## 1. Деньги во времени

| Понятие | Формула | Расшифровка |
|---|---|---|
| Будущая стоимость (FV) | `FV = PV × (1 + r)^n` | Во что превратится сумма PV через n периодов при ставке r |
| Приведённая стоимость (PV) | `PV = FV / (1 + r)^n` | Сколько сегодня стоит сумма FV, которую получим через n периодов |
| Простые проценты | `FV = PV × (1 + r × n)` | Проценты считают только на начальную сумму |
| Сложные проценты | `FV = PV × (1 + r)^n` | Проценты начисляют на проценты |
| Эффективная ставка | `EAR = (1 + r / m)^m − 1` | m — число начислений в год. Чем чаще начисление, тем выше эффективная ставка |
| Непрерывное начисление | `FV = PV × e^(r × n)` | Предел при бесконечно частом начислении |
| Правило 72 | `Лет до удвоения ≈ 72 / (r в %)` | Быстрая прикидка: при 8% удвоение за 9 лет |
| Дисконт-фактор | `DF = 1 / (1 + r)^n` | Множитель, приводящий будущую сумму к сегодняшней |

Пример: 100 ₽ под 10% на 3 года. FV = 100 × 1,1³ = 133,1 ₽.

## 2. Аннуитет и перпетуитет

**Аннуитет** — серия равных платежей через равные промежутки.

| Понятие | Формула |
|---|---|
| PV обыкновенного аннуитета (платёж в конце периода) | `PV = PMT × [1 − (1 + r)^−n] / r` |
| FV обыкновенного аннуитета | `FV = PMT × [(1 + r)^n − 1] / r` |
| Аннуитет «в начале периода» (annuity due) | умножить на `(1 + r)` |
| Перпетуитет (вечная рента) | `PV = PMT / r` |
| Растущий перпетуитет | `PV = PMT₁ / (r − g)`, r > g |
| Растущий аннуитет | `PV = PMT₁ / (r − g) × [1 − ((1 + g) / (1 + r))^n]` |
| Платёж по кредиту (аннуитетный) | `PMT = PV × r / [1 − (1 + r)^−n]` |

Пример: платёж 100 ₽ в год, 5 лет, ставка 10%. PV = 100 × [1 − 1,1^−5] / 0,1 = 379,1 ₽.

Растущий перпетуитет лежит в основе формулы Гордона для терминальной стоимости и оценки акций (см. шпаргалки по оценке и акциям).

## 3. Критерии проектов

| Показатель | Формула | Правило |
|---|---|---|
| NPV (чистая приведённая стоимость) | `NPV = −I₀ + Σ CFt / (1 + r)^t` | NPV > 0 — принять |
| IRR (внутренняя норма доходности) | ставка, при которой `NPV = 0` | IRR > r (требуемой доходности) — принять |
| MIRR | реинвестирование по ставке r, итог одна ставка | Лучше обычной IRR при нестандартных потоках |
| Срок окупаемости (payback) | год, когда накопленный поток становится ≥ 0 | Не учитывает деньги во времени и потоки после окупаемости |
| Дисконтированный срок окупаемости | то же по дисконтированным потокам | Учитывает ставку |
| Индекс прибыльности (PI) | `PI = PV будущих потоков / I₀` | PI > 1 — принять |
| EAA (эквивалентный аннуитет) | `EAA = NPV / фактор аннуитета` | Для сравнения проектов с разным сроком |

Когда IRR подводит: несколько смен знака потоков (несколько IRR), взаимоисключающие проекты разного размера, разные сроки. В спорных случаях доверяют NPV.

## 4. Ставки

| Понятие | Формула и расшифровка |
|---|---|
| Номинальная ставка | Обычная ставка в договоре, без учёта инфляции |
| Реальная ставка (Фишер) | `(1 + i) = (1 + r) × (1 + π)`, откуда `r = (1 + i) / (1 + π) − 1`. Приближённо `r ≈ i − π` |
| Спот-ставка | Доходность бескупонной бумаги на срок t |
| Форвардная ставка | `(1 + s₂)² = (1 + s₁) × (1 + f₁,₂)` |
| Безрисковая ставка (rf) | Доходность государственных облигаций с минимальным риском (в РФ ориентир — ОФЗ) |
| Премия за риск | Дополнительная доходность за риск (рыночная премия: рынок минус rf) |
| Ключевая ставка | Ставка ЦБ, ориентир для кредитов и депозитов |

Правило: денежные потоки и ставка должны быть в одной валюте и с одним учётом инфляции (номинальные потоки с номинальной ставкой, реальные с реальной).

## 5. Доходность и риск

| Показатель | Формула |
|---|---|
| Простая доходность за период | `R = (P₁ − P₀ + D) / P₀` |
| Логарифмическая доходность | `r = ln(P₁ / P₀)` |
| Среднее арифметическое | `R̄ = (1/n) Σ Rt` |
| Среднее геометрическое (CAGR) | `CAGR = (P_конец / P_начало)^(1/n) − 1` |
| Дисперсия | `σ² = Σ (Rt − R̄)² / (n − 1)` |
| Стандартное отклонение (волатильность) | `σ = √σ²` |
| Годовая волатильность из дневной | `σ_год ≈ σ_день × √252` |
| Ковариация | `Cov(X, Y) = Σ (Xt − X̄)(Yt − Ȳ) / (n − 1)` |
| Корреляция | `ρ = Cov(X, Y) / (σX × σY)`, от −1 до +1 |
| Коэффициент вариации | `CV = σ / среднее` (риск на единицу доходности) |

Пример: цена выросла с 100 до 110, дивиденд 5. R = (110 − 100 + 5) / 100 = 15%.

Арифметическое среднее завышает «реальный» рост при волатильности, геометрическое показывает итоговый результат.

## 6. Статистика и распределения (минимум)

- **Нормальное распределение:** около 68% значений в пределах ±1σ, 95% в пределах ±2σ, 99,7% в пределах ±3σ.
- **Z-оценка:** `z = (x − μ) / σ`.
- **Доверительный интервал среднего:** `x̄ ± z × σ / √n`.
- **Регрессия:** `y = α + β x + ε`, β = Cov(x, y) / Var(x), R² — доля объяснённой дисперсии.
- **Асимметрия** показывает перекос хвоста, **эксцесс** — «толстые хвосты» (редкие, но сильные движения чаще, чем в норме).
- **Ожидаемое значение:** `E(X) = Σ pi × xi`.
- **Сценарный анализ:** `E = p₁ × х₁ + p₂ × х₂ + p₃ × х₃`, вероятности в сумме дают 1.

## Типичные ошибки

- Складывать деньги из разных периодов без приведения.
- Использовать номинальные потоки с реальной ставкой и наоборот.
- Путать n (число периодов) и годы, если начисление чаще раза в год: тогда r делят на m, а n умножают на m.
- Считать среднюю доходность арифметически для многолетнего роста.
- Выбирать проект по IRR, когда NPV говорит обратное.

## Проверь себя

**1. 200 ₽ под 8% на 5 лет, сложный процент. Чему равна FV?**
200 × 1,08⁵ ≈ 293,9 ₽.

**2. Сколько сегодня стоит 500 ₽ через 3 года при ставке 10%?**
500 / 1,1³ ≈ 375,7 ₽.

**3. Перпетуитет 50 ₽ в год при ставке 10%. Какова PV?**
50 / 0,10 = 500 ₽.

**4. Что значит NPV > 0 и IRR > r?**
Проект приносит больше, чем требуемая доходность: создаёт стоимость, его стоит принять.

**5. Номинальная ставка 12%, инфляция 5%. Реальная ставка?**
(1,12 / 1,05) − 1 ≈ 6,7% (приближённо 7%).

**6. Правило 72: за сколько лет удвоятся деньги при 6%?**
72 / 6 = 12 лет.

**7. Чем эффективная ставка отличается от номинальной?**
Эффективная учитывает частоту начисления: при начислении чаще раза в год она выше номинальной.

**8. Цена выросла с 80 до 100, дивиденд 4. Чему равна доходность?**
(100 − 80 + 4) / 80 = 30%.

**9. Дневная волатильность 1,5%. Какова приблизительно годовая?**
1,5% × √252 ≈ 23,8%.

**10. Чем плох срок окупаемости?**
Не учитывает деньги во времени (в простом варианте) и потоки после окупаемости.
