ГОЛОС — локальная озвучка с клонированием тембра
================================================
1. Один раз: поставь Python 3.10 или 3.11 (python.org, галка «Add to PATH»), затем запусти install.bat.
2. Каждый раз: run.bat → откроется страница http://localhost:7860
3. «+ Новый голос» → загрузи образец (10–30 с чистой речи человека, чей голос нравится; можно mp3/mp4).
4. Вставь текст → «Озвучить». Первый запуск скачает модель (~2 ГБ).
5. Дубль понравился → «👍 Нравится» — он станет образцом (хранятся последние 3). Так голос подстраивается под тебя.
   Не понравился — поменяй «Выразительность» (ниже = ровнее, выше = живее) и «Темп», озвучь ещё раз.

Файлы: voices\<имя>\*.wav — образцы, out\ — готовые дубли и *.json с таймингами фраз (для монтажа).
Для mp3/mp4-образцов нужен ffmpeg (winget install ffmpeg). С wav он не нужен.

Честно: без видеокарты NVIDIA озвучка идёт медленно (около 1–3 минут на фразу).
Модель XTTS-v2 — для личного использования (лицензия CPML, не для коммерции).
Клонируй только свой голос или голоса, на которые у тебя есть право.
