# История доходности рублёвых облигаций РФ по кредитному качеству, 2016–2026

Дата сбора: 5 ноября 2026. Метод: WebSearch + WebFetch по открытым источникам. Просмотрено около 110 URL (список в разделе 6).

## 0. Главное и ограничения

- **Непрерывного ряда «средняя YTM по AAA/AA/A/BBB/BB/B за каждый год» в открытом доступе найти не удалось.** Историю по рейтинговым группам Cbonds (CBI RU) отдаёт только платный доступ (страницы закрыты логином и robots). Архив индексов Мосбиржи (ISS API `iss.moex.com`) из песочницы недоступен (прокси: 403, `robots_disallowed`).
- **Что нашлось:**
  1. Годовая полная доходность (total return) ОФЗ и корпоративных облигаций за 2016–2025 почти без пропусков.
  2. Полная доходность по рейтингам AAA/AA/A/BBB и по ВДО за 2023–2025 и первое полугодие 2026 (БК «РЕГИОН»), по AAA/AA/A за 2024–2025 (индексы Мосбиржи).
  3. Разрозненные срезы YTM и спредов: октябрь 2017, 30.12.2024 (Cbonds, по рейтинговым группам), 2022–2026 (обзоры банков и рейтинговых агентств).
  4. Спреды «корпоративные к ОФЗ» на конец 2017, 2021, 2022, 2023, 2024, 2025 (где-то по рынку в целом, где-то по эшелонам).
- **Рейтинговые шкалы смешаны.** БК «РЕГИОН» и Мосбиржа считают по национальной шкале (АКРА / «Эксперт РА»). Cbonds-CBI группирует «BBB/ruAA-», «BB/ruBBB», «B/ruB-» (международная или национальная шкала). Индекс Мосбиржи RUCBTRNS включает только бумаги с рейтингом не ниже A- и дюрацией не меньше года.
- **Оценки помечены словом «оценка»** с обоснованием. Всё остальное взято из источника напрямую или посчитано из чисел источника (помечено «расчёт»).
- Для YTM «по рейтингу» годового ряда нет. Для модели честнее использовать годовую полную доходность (раздел 2), где ряд длинный и надёжный, а YTM брать как срезы.

Коды источников S1…S58 (часть строк списка без кода) раскрыты в разделе 6.
